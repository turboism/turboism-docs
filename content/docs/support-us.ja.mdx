title: プロジェクトを支援する
description: Turboism の開発、ドキュメント、テスト、コミュニティ運営を支援する方法。
---

Turboism は独立したオープンソースプロジェクトです。支援は、フレームワーク、ドキュメント、バージョン互換性の確認、テスト、コミュニティサービスの維持に役立ちます。

## スポンサー窓口

- [Afdian（爱发电）](https://ifdian.net/a/raintrap341)

## その他の支援方法

金銭的なスポンサー以外にも、次の方法で支援できます。

- [GitHub Issues](https://github.com/turboism/turboism/issues) で再現可能な問題を報告する
- [GitHub Pull Requests](https://github.com/turboism/turboism/pulls) で対象を絞った改善を提案する
- 専用のテストデータを使い、利用許可のある Preview ビルドを実環境でテストして、環境と結果を報告する
- 英語、簡体字中国語、日本語のドキュメントを改善する
- 公開された境界内で、独立した Java プラグイン、GraalJS スクリプト、MCP 連携を開発する
- [Discord](https://discord.gg/bect4anknH) で他のコミュニティメンバーを支援する

スポンサーに関する質問や、その他の支援方法についての相談は、[contact@turboism.dev](mailto:contact@turboism.dev) までメールでご連絡ください。

## プロジェクトの独立性

プロジェクトへの支援によって、Turboism が Live2D または Cubism の公式製品になることはなく、それぞれの権利者に帰属する権利が移転することもありません。プロジェクトに関するスポンサー、提携、推薦を対外的に説明する前に、[安全性と権利について](./safety-and-rights)を確認してください。
