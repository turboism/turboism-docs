# Turboism 文档

Turboism 是面向 Live2D Cubism Editor 的 Java 17 Runtime 增强工具和插件框架。

## 选择路径

- **使用 Turboism** — 从[安装](./use/installation)、[快速入门](./use/quick-start)和[插件管理](./use/plugin-management)开始。
- **构建插件** — 使用[开发者快速入门](./build-a-plugin/quick-start)创建 Java 插件，然后阅读[插件接口](./build-a-plugin/plugin-interfaces)和 [Manifest 与打包](./build-a-plugin/manifest)。
- **参考** — 阅读 [SDK API 指南](./reference/sdk-api)，或打开[生成的 HTML API 参考文档](/api/sdk/index.html)。
- **项目状态** — 查看[开发状态](./development-status)和[文档 Preview](./documentation-preview)。

Turboism 仍处于 Developer Preview 阶段。本站会标识受版本限制、不可用和未经验证的行为，而不会将它们表述为发布保证。
