Turboism 是面向 Live2D Cubism Editor 的开源增强工具与插件框架。它通过公共 SDK、权限和版本适配边界，为 Cubism 增加可选功能，并保持 Cubism 本身独立安装和授权。

## 文档结构

### 基本

从[基本](./use/overview)开始，查看安装、初次使用、插件管理、第一方插件教程、更新、卸载与恢复。

### 开发

前往[开发](./build-a-plugin/overview)参与 Turboism 开发，或使用三种开发方式之一：

1. Java 插件；
2. 由 Java 调用方显式运行的 GraalJS 脚本；
3. 通过 MCP 进行外部自动化。
