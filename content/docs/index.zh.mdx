请沿着[建模者](./use/overview)路径了解候选安装流程、开始使用 Turboism、管理本地插件，以及规划更新或恢复。可从[安装](./use/installation)和[快速开始](./use/quick-start)开始。

请沿着[开发者](./build-a-plugin/overview)路径参与贡献、构建进程内 Java SDK 插件、了解受限的 GraalJS 脚本边界，或通过 Preview MCP 插件连接外部客户端。[LLM 编程上下文](./build-a-plugin/llm-coding-context)是辅助资料，并非另一种扩展方式。

有关准备状态和发布范围，请参阅[开发状态](./development-status)和[文档 Preview](./documentation-preview)。
