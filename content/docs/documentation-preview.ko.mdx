이 사이트는 호스팅되는 SDK HTML 레퍼런스를 포함한 Turboism 사용자 및 개발자 문서를 제공합니다.

## 다루는 범위

- 설치, 설치 프로그램 모드, 첫 실행, 플러그인 관리, 기본 제공 플러그인, 업데이트, 제거 및 복구;
- Java 17 플러그인 개발, 플러그인 메타데이터 스키마, GraalJS 스크립트 및 MCP 통합 경로;
- 개념, SDK API 가이드 및 생성된 API 레퍼런스의 상태;
- 안전, 라이선스, 피드백 채널 및 현재 개발 상태.

## 언어 정책

영어가 문서 본문의 기준 언어입니다. 중국어 간체, 일본어 및 한국어 페이지는 영어 원본과 의미가 일치하도록 유지됩니다. 번역된 페이지와 영어 페이지가 다르면 영어 페이지를 올바른 것으로 간주하고 차이를 알려 주세요.

## 아직 잠정적인 사항

- **생성된 SDK Javadoc** — 현재 호스팅되는 버전과 남아 있는 차단 요소는 [생성된 API 레퍼런스](./reference/generated-api)를 참고하세요. 생성된 Javadoc에 메서드가 나타난다는 사실만으로 모든 호스트 버전에 호환되는 프로바이더가 있다는 것이 증명되지는 않습니다.
- **서드파티 플러그인 디렉터리** — 디렉터리 클라이언트는 존재하지만 프로덕션 활성화와 서명된 카탈로그 준비 상태는 확립되지 않았으므로, 목록을 공개된 것으로 취급해서는 안 됩니다.
- **플랫폼 범위** — Windows x64가 유일하게 지원되는 Cubism 호스트 플랫폼이며, macOS 패키징은 미리 보기 전용이고 Linux는 설치 프로그램 동작만을 대상으로 합니다.
- **버전별 준비 상태** — 지원되는 Cubism Editor 버전은 5.2.03, 5.3.02, 5.3.03이지만 개별 작업은 여전히 버전별로 다릅니다. 프레임워크 버전이 아니라 작업 단위로 가용성을 확인하세요.
- **자동 업데이트** — 현재 안정 릴리스의 일부가 아니며, 업데이트는 설치 프로그램을 다시 실행하는 것을 의미합니다.

## 제품 정보를 확인하는 방법

- 공개된 버전, 패키지, 크기 및 체크섬: [업데이트 정책](./use/update-policy)에 설명된 채널 피드를 확인하세요.
- 지원되는 호스트 버전과 설치 프로그램 동작: [설치](./use/installation).
- 릴리스 약속이 아닌 구현 상태: [개발 상태](./development-status).

이 사이트, 변경 기록 항목 또는 생성된 API 페이지를 그 자체로 호환성 약속으로 취급하지 마세요.
