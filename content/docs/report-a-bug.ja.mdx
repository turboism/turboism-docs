---

次の窓口からバグを報告したり、Turboism フレームワークやプラグインの機能を提案したりできます。

バグを報告する前に[トラブルシューティング](./troubleshooting)を確認し、使用中のバージョンで問題が引き続き発生することを確認してください。

## バグ報告

できるだけ次の情報を含めてください。

- Turboism のバージョン
- Cubism Editor の正確なバージョン
- オペレーティングシステム
- 関係する機能またはプラグイン
- 問題を再現する手順
- 期待した結果と実際の結果
- 必要に応じて、スクリーンショットまたはプライバシーを確認した短い診断内容

公開する前に、個人情報、認証情報、接続用の秘密情報、ローカルファイルのパス、プロジェクトファイル、ライセンスで保護された Cubism の素材を削除してください。

## 機能要望

Turboism フレームワークへの要望か、特定のプラグインへの要望かを明記してください。解決したい問題、対象となる利用者、期待する結果、現在使っている方法を説明してください。機能要望は提案であり、実装や特定バージョンへの収録を約束するものではありません。

## Discord

[Turboism Discord](https://discord.gg/bect4anknH) で相談できます。バグかどうか判断できない場合や、問題の切り分けに協力が必要な場合に適しています。

## GitHub

再現可能な問題は [GitHub Issue](https://github.com/turboism/turboism/issues) で報告してください。最初に既存の Issue を検索し、分かりやすいタイトルと上記の情報を記載してください。

## メール

最初から公開の場で扱うことが適切でない場合は、[contact@turboism.dev](mailto:contact@turboism.dev) にメールしてください。認証情報、接続用の秘密情報、非公開のプロジェクトファイルは送信しないでください。
