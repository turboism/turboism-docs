---
title: 自動化
description: 繰り返し可能な Editor ワークフローに関する Preview 概念。
---

Turboism では、Editor workflow の automation と replay を検討する可能性があります。そのような capability は project state に影響し得るため、明確な安全境界が必要です。

Automation は experimental concept であり、利用できる feature ではありません。このページを API shape、availability、operational behavior の根拠にしないでください。
