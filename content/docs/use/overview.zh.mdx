## 开始使用

- [安装](./installation) — 安装由可信渠道提供的 Preview 构建。

- [快速开始](./quick-start) — 首次启动 Turboism。

## 插件

- [插件管理](./plugin-management) — 管理本地插件 JAR。
- [第一方插件](./first-party-plugins) — 查看候选第一方功能的独立教程分类。

## 维护或移除 Turboism

- [更新策略](./update-policy) — 准备手动更新。
- [卸载](./uninstall) — 移除 Turboism，并选择是否保留配置。
- [降级与恢复](./downgrade-recovery) — 在更新或安装变更失败时恢复。

## 相关站点

- [SDK 文档](https://turboism.dev/sdk/index.html) — 面向插件开发的 Java API 文档。将其作为当前公共契约前，请先查看 [API 发布状态](../reference/generated-api)。
- [插件目录](https://turboism.dev/plugins) — 查看经过整理的 Turboism 插件信息。公开列表和发布功能以目录当前状态为准。
- [学习站点](https://turboism.dev/learn) — 提供 Turboism 使用方法和相关工作流程的教程与学习资料。
- [聊天](https://chat.turboism.dev) — 用于社区交流和寻求帮助。
- [GitHub](https://github.com/turboism) — 查看源代码、Issue、Pull Request 和项目开发情况。
- [主站](https://turboism.dev) — 查看项目简介及 Turboism 各站点入口。

公开发布、自动更新、在线发现和公开插件目录仍在等待中。如果可用 Preview 的行为与说明不同，请查看[故障排查](../troubleshooting)。
