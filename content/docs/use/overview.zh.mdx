这是待发布的候选指南，面向普通建模者，而非从源代码构建 Turboism 的人员。

## 你的生命周期

1. [安装](./installation) — 了解候选安装边界，并且只从提供你的 Preview 构建的渠道取得安装器。
2. [安装器模式](./installer-modes) — 在选择前了解候选的 Full、Thin 和 Lite Managed Runtime 选项。
3. [快速开始](./quick-start) — 完成你所拥有的 Preview 构建的首次运行流程。
4. [插件管理](./plugin-management) — 重启后管理本地插件 JAR；这不是已发布的插件目录。
5. [第一方插件](./first-party-plugins) — 查看捆绑第一方能力的候选总览。
6. [更新策略](./update-policy) — 在更换构建前规划手动更新并保存重要内容。
7. [降级与恢复](./downgrade-recovery) — 从失败的更改中恢复，不要假定支持降级到旧版本。
8. [卸载](./uninstall) — 使用安装器的卸载器，并选择是否保留个人配置。

## 此路径不承诺的内容

公开发布、部署、自动更新、在线发现和插件目录仍待落实。请将每份候选文档视为与版本和能力相关；如果可用的 Preview 行为与这些说明不同，请使用[故障排查](../troubleshooting)。
