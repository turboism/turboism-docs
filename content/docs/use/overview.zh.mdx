## 开始使用

- [安装](./installation) — 选择安装包，并在 Windows、macOS 或 Linux 上安装 Turboism。
- [安装器模式](./installer-modes) — 比较 Full、Thin 和 Lite 选项。
- [快速开始](./quick-start) — 下载、验证、配置并首次运行 Turboism。

## 插件

- [插件管理](./plugin-management) — 安装、替换、启用、禁用和卸载插件 JAR。
- [第一方插件](./first-party-plugins) — Full 安装中包含的已审查插件捆绑包。

## 维护或移除 Turboism

- [更新策略](./update-policy) — 了解发布渠道，并通过重新运行安装器进行更新。
- [卸载](./uninstall) — 移除 Turboism，并选择是否保留配置。
- [降级与恢复](./downgrade-recovery) — 在更新或安装变更失败时恢复。

## 相关站点

- [下载](https://turboism.dev/download) — stable、beta 和 nightly 渠道的已发布安装包。
- [SDK 文档](https://turboism.dev/sdk/index.html) — 面向插件开发的 Java API 文档。将其作为当前公共契约前，请先查看 [API 发布状态](../reference/generated-api)。
- [插件目录](https://turboism.dev/plugins) — 查看经过整理的 Turboism 插件信息。第三方列表和发布功能以目录当前状态为准。
- [学习站点](https://turboism.dev/learn) — 提供教程与学习资料。
- [GitHub](https://github.com/turboism) — 查看源代码、发行版、Issue 和 Pull Request。
- [主站](https://turboism.dev) — 查看项目简介及 Turboism 各站点入口。

公开发行版和下载已可用。自动框架更新、生产可用的 marketplace 和公开的第三方插件目录尚不可用。如果已安装的构建行为与本文档不同，请查看[故障排查](../troubleshooting)。
