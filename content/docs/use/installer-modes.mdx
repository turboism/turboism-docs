title: Installer Modes
description: Compare the Full, Thin, and Lite installation selections and the optional managed GraalVM component.

Turboism installers and portable archives ship the same runtime with different plugin selections. A mode selects files; it never changes your Cubism installation.

## Modes

- **Full** — the agent plus the reviewed first-party plugin bundle. The installer preselects every approved release plugin and lets you deselect individual plugins.
- **Thin** — the same approved plugin roster without the additional managed native runtime payload. Available in the Java installer, which also accepts an explicit custom executable path.
- **Lite** — the agent and common files only. No first-party plugin JAR is copied.

The Windows `.exe` installer offers **Full** and **Lite**. The cross-platform `.jar` installer offers **Full**, **Thin**, and **Lite**. The portable archives ship as `full` and `lite` variants of the same payload.

## Optional managed GraalVM

The installers offer an optional managed GraalVM component:

- it downloads the pinned archive from the GraalVM official GitHub release and verifies it before use;
- leaving it unchecked keeps the installation valid and complete for the plugin bundle;
- you can install it later from Turboism settings.

The development-only `Turboism with fx` plugin and its managed runtime bytes are not part of any release package.

## What a mode does not change

- The runtime home, configuration, logs, and plugin data are the same in every mode.
- Rerunning the installer applies a different selection to the same home and changes only the managed plugin state.
- Unknown files and third-party plugin JARs are never deleted by a mode change.
- A mode label does not guarantee that a plugin feature is available on your Cubism version. Availability remains capability- and version-specific.

## Before choosing

1. Back up `config.json` and any plugin `config/` or `data/` content that matters.
2. Review [Update Policy](./update-policy) for how installer reruns and release channels work.
3. Use [Downgrade and Recovery](./downgrade-recovery) if a change does not behave as expected.
