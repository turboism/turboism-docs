title: Installer and Portable ZIP
description: Choose between the Windows installer and the portable ZIP, review the installer options, and view package history.
---

Since **0.67.0** Stable, every Turboism release provides exactly two product downloads, each with a matching `.sha256` checksum:

- **Windows installer** — `TurboismInstaller-<version>.exe`, the recommended path on Windows.
- **Portable ZIP** — `turboism-<version>.zip`, for manual setup on Windows and for macOS and Linux.

Both packages contain the same payload: the runtime framework, the configurator (`configure_turboism.ps1`), every bundled [first-party plugin](./first-party-plugins), and the complete offline GraalJS engine. Installing a GraalVM runtime remains a separate, optional step. There is no plugin-free package and no per-plugin selection: plugins are enabled or disabled later in Cubism via **Turboism → Manage Plugins…**.

Neither package alters Cubism JARs, DLLs, or licensing state. Only the optional official BAT integration described below modifies Cubism startup BAT files, using hash-guarded backups.

## Installer vs portable ZIP

| | Windows installer (`.exe`) | Portable ZIP (`.zip`) |
| --- | --- | --- |
| Platforms | Windows x64 | Windows (manual setup), macOS and Linux (preview / runtime-only) |
| Bundled first-party plugins and offline GraalJS | Included | Included |
| Install location | `%LOCALAPPDATA%\Turboism` by default, selectable | Any separate folder you extract into |
| Cubism discovery | Built into the wizard | Run `configure_turboism.ps1` yourself |
| Launch entries | Start-menu and desktop shortcuts (selectable) | Shortcuts generated by the configurator, or `launch-cubism-turboism.bat` |
| Official Cubism BAT integration | Pre-selected, can be unchecked | Not enabled |
| Removal | `uninstall.exe` | Close Cubism and delete the folder |

## Installer options

The Windows installer runs per-user and walks through these pages:

1. **Language** — choose English, Simplified Chinese, Japanese, or Korean before the welcome page. The choice affects only the installer and is never written to `config.json`.
2. **License and acknowledgements** — accept the AGPL-3.0-only license, review the End User Runtime Statement and Disclaimer, and check all four required acknowledgements.
3. **Directory** — the Turboism home, `%LOCALAPPDATA%\Turboism` by default.
4. **GraalVM** — choose **Install later** or **Download and install now** (recommended) for the optional Turboism-managed GraalVM runtime (about 326 MiB). The download is verified (size, SHA-256, and release metadata) and happens only when selected; you can install it later from the Turboism configurator.
5. **Cubism installations** — the installer scans for installed Cubism Editors and lets you add a folder with **Import version**. If no supported installation is found, Turboism can still be installed and configured later with `configure_turboism.ps1`.
6. **Launch options** — choose how Cubism starts with Turboism:
   - **Create Turboism Start-menu shortcuts** (recommended, selected by default);
   - **Create a Turboism desktop shortcut** (selected by default);
   - **Modify the selected official Cubism startup BAT files so existing Cubism shortcuts load Turboism** (recommended, selected by default).

   If you uncheck all three, the installer warns that Turboism will not activate from any normal launch path.
7. **Finish** — optionally launch Turboism.

### Official Cubism BAT integration

Since 0.67.0, the installer pre-selects official Cubism BAT integration. It backs up and modifies the selected `CubismEditor5.bat` launchers so existing Cubism shortcuts, file associations, and other entry points load Turboism without going through the managed launcher.

- You can uncheck it on the launch-options page; Start-menu shortcuts work independently of it.
- It is hash-guarded and idempotent: a BAT file edited after installation is reported as a conflict and never overwritten.
- It is restored on uninstall from the verified backups.
- Silent installs apply it as well.
- Only the integration step elevates through UAC; the rest of the installation runs without administrator rights.

## Upgrades

Run a newer installer against the same Turboism home. It upgrades the existing installation, installs the current bundled first-party plugins, retires obsolete official plugin JARs (identified by their embedded plugin ID, never by filename alone), and preserves existing `disabledPlugins` entries, so plugins you disabled stay disabled. Other valid settings in `config.json` and Cubism installation links in `cubism-installations.json` are preserved.

For a portable ZIP, extract the newer archive as described in [Installation](./installation) and run the configurator again.

The development-only `Turboism with fx` plugin and managed fx runtime bytes are never included in release packages.

## Package history

- **0.67.0-beta.3 to 0.67.0-beta.7** temporarily shipped four downloads across two variants: Full (`TurboismInstaller-<version>-full.exe`, `turboism-<version>-full.zip`) with every first-party plugin, and Thin (`TurboismInstaller-<version>-thin.exe`, `turboism-<version>-thin.zip`) with the runtime only. This layout is retired; running the current installer over a Thin installation installs the bundled plugins while keeping existing `disabledPlugins` disabled.
- **0.44.0 and earlier** used a legacy model: a single Windows installer `TurboismInstaller-<version>.exe` with Full/Lite mode pages and per-plugin checkboxes, a cross-platform IzPack Java installer `TurboismInstaller-<version>.jar` (Java 17 or newer), and portable archives `turboism-<version>-full.zip` and `turboism-<version>-lite.zip`.

The Java installer is no longer published. macOS and Linux use the portable ZIP.
