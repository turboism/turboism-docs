Turboism は、プラグインを管理するための複数の補完的な手段を提供します。

- **Cubism 内のプラグインマーケット**（**Turboism** メニュー → **プラグインマーケット…**）または [turboism.dev/plugins](https://turboism.dev/plugins): ファーストパーティおよびカタログ掲載プラグインの検索と導入。
- 検証済みファーストパーティプラグインの**バックグラウンド自動更新**。
- **プラグイン管理…**: プラグインの有効化・無効化、アンインストール、ローカル JAR のステージング。
- 専用の 2 ペインウィンドウでの**プラグイン設定…**: プラグイン設定の一元的な構成。

Full インストールにはレビュー済みの[ファーストパーティプラグインバンドル](./first-party-plugins)があらかじめ同梱されています。Thin インストールでは、プラグインマーケットから必要なプラグインをいつでも導入できます。

すべてのプラグインライフサイクルとファイルの変更は安全にステージングされて適用されます。ステージングされた変更は Cubism 再起動後に適用され、ホットリロード（hot-reload）対応プラグインは即座に適用されます。

## Turboism トップメニュー

Cubism Editor では、すべてのフレームワークおよびプラグイン機能が最上位の **Turboism** メニュー（以前は「プラグイン」/「插件」）に統合されています。メニュー項目:

1. **プラグインマーケット…** — カタログからファーストパーティおよび厳選プラグインを検索・導入。
2. **プラグイン管理…** — インストール済みプラグインの一覧、有効/無効の切り替え、ローカル JAR の追加、アンインストール。
3. **プラグイン設定…** — 専用の 2 ペイン設定ウィンドウを開き、各プラグインのオプションを設定。
4. **更新を確認** — Turboism フレームワークの新しいリリースを確認。
5. **Turboism 設定…** — フレームワーク全体の設定（更新確認、ランタイムログ、言語ロケール、起動設定）。
6. **キーバインド…** — 各種アクションのショートカットキーを確認・編集。
7. **ログ…** — ランタイムおよび診断ログの保存先フォルダを開く。
8. **プラグインのアクション** — アクティブなプラグインが追加した操作項目。
9. **バージョン情報** — インストールされている Turboism のバージョンとビルド情報を表示。

## プラグインマーケットと自動更新

0.67.0-beta.3 以降、ファーストパーティプラグインはフレームワーク全体を再インストールすることなく個別に導入・更新できます。

- **Turboism → プラグインマーケット…** または [turboism.dev/plugins](https://turboism.dev/plugins) からプラグインを導入できます。
- ファーストパーティプラグインは署名検証を経てバックグラウンドで自動更新されます。
- **ホットリロード**（hot-reload）対応プラグインはモデリング作業を中断することなく即座に反映されます。
- その他のプラグイン更新は次回の Cubism 再起動時に反映されます。
- ユーザーは設定画面から公式プラグインの自動更新をいつでも無効化できます。

## プラグイン設定

プラグインごとの設定を行うには、**Turboism → プラグイン設定…** を選択します。

- 専用の 2 ペインウィンドウが開きます（左ペインにインストール済みプラグイン一覧、右ペインに選択中のプラグイン設定フォーム）。
- 設定値は保存前に検証され、`config/<pluginId>/` に保存されます。
- フレームワーク本体の設定は **Turboism → Turboism 設定…** に分離されています。

## ローカル JAR のマネージドインストール

独自にビルドしたプラグイン JAR を追加する場合:

1. 信頼できるソースからプラグイン JAR を取得またはビルドします。
2. Cubism で **Turboism → プラグイン管理…** を選択します。
3. **JAR からインストール…**（Install from JAR…）をクリックします。
4. ローカルの `.jar` ファイルを選択します。
5. JAR がローカル/未検証のソースであることを示す確認ダイアログを承認します。
6. 操作が保留中（pending）と表示されたことを確認します。
7. Cubism を終了し、同じ Turboism home から再起動します。
8. **プラグイン管理…** とランタイムログで有効な状態を確認します。

ステージング前、Runtime は選択された JAR を未検証の入力として扱います。アーカイブ制限（サイズ、展開サイズ、圧縮比など）の範囲内で単一の記述子とプラグイン内容を検査し、安全に保留状態へとスナップショットします。

## プラグインの置換または更新

- **ファーストパーティプラグイン**: バックグラウンドで自動更新されるか、プラグインマーケットから更新します。
- **ローカル/サードパーティプラグイン**: **プラグイン管理… → JAR からインストール…** で同じプラグイン ID の新しい JAR を導入し、置換操作をステージングします。

ローカルプラグイン更新の推奨手順:

1. 現在の JAR と重要な `config/`・`data/` の内容をバックアップします。
2. プラグイン管理から新しい JAR をインストールします。
3. Cubism を再起動します。
4. 表示バージョン、状態、ログを確認します。

起動時チェックで検証が行われ、適用に失敗した場合は以前のプラグインファイルが自動復元されます。

## プラグインの有効化と無効化

**Turboism → プラグイン管理…** で、任意のプラグインの有効/無効を切り替えられます。

- 設定は `config.json` の `disabledPlugins` に保存され、Cubism 再起動後に反映されます。
- Runtime 所有の `turboism.core` は組み込みコードであり無効化できません。
- 無効化されたプラグインは次回の起動時にロードがスキップされます。
- バリアント間のアップグレード時も `disabledPlugins` の設定は保持されます。Thin 環境に Full を上書きしても、以前無効化したプラグインが勝手に有効化されることはありません。

## プラグインのアンインストール

1. **Turboism → プラグイン管理…** を開きます。
2. 削除するプラグインを選択し、**アンインストール** をクリックします。
3. 保留中の操作を確認します。
4. Cubism を再起動します。
5. プラグインがロードされていないことを確認します。
6. 必要に応じて永続化データを保持または削除します。

プラグイン JAR を削除しても、プラグイン所有のデータがすべて消えるわけではありません:

- 再インストール後に設定やデータが必要な場合は `config/<pluginId>/` や `data/<pluginId>/` を残してください。
- `cache/`、`state/`、`logs/` は Cubism 停止時に安全に削除できます。

## 手動インストール（高度な代替手順）

手動インストールは、UI を介さずにローカル JAR をテストするための代替経路です。`<turboism.home>/plugins/` に直接 JAR を配置します。通常はプラグインマーケットまたはマネージドインストールを推奨します。

プラグイン JAR はプラグインのソースからビルドされたものであり、Turboism のインストーラー実行ファイルやアーカイブとは異なります。

### 手動インストール手順

1. Cubism と Turboism を完全に終了します。
2. 使用している正確な Turboism home を確認します。
3. `<turboism.home>/plugins/` フォルダを開きます。
4. プラグイン JAR を `plugins/` 直下にコピーします（プラグイン ID ごとに 1 ファイル）。
5. 同じ Turboism home で Cubism を再起動します。
6. **プラグイン管理…** とログで状態を確認します。

### 手動インストールしたプラグインのアンインストール

1. Cubism と Turboism を終了します。
2. `<turboism.home>/plugins/` から対象の JAR を削除します。
3. 再起動してプラグインが読み込まれていないことを確認します。

## 現在の制限事項

プラグイン管理では、現時点で以下を提供していません:

- 未検証のサードパーティ署名管理や自由な公開ストアへの登録。
- 過去バージョンの無制限な履歴保存と一括ロールバック。
- 完全な自動復旧 UI。
- Cubism 本体のインストール先や公式ランチャーのシステムレベルの変更。
