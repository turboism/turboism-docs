このページは公開待ちの候補概要です。ファーストパーティ plugin は独立した分類であり、bundle、deployment、公開 plugin directory、または詳細 tutorial page が公開済みであるという主張ではありません。

## 候補 capability family

候補ファーストパーティ plugin set には、次の plugin family が含まれる場合があります。

- parameter の一括操作。
- mesh mirroring。
- clipping mask。
- palette、scene、texture atlas。
- physics。
- backup。
- performance。
- theme。

これらは capability family であり、リリースの約束ではありません。正確な set、availability、behavior、compatibility は保留中で、Preview build ごとに異なる場合があります。詳細な tutorial page は別途後から提供されます。plugin directory にこれらの plugin がすでに存在すると推測しないでください。

## この概要の使い方

- 候補の選択意味は[インストーラーモード](./installer-modes)で確認します。
- 手元の build で利用できるローカル plugin のライフサイクルには[プラグイン管理](./plugin-management)を使用します。
- 選択を変更する前に[更新ポリシー](./update-policy)を読みます。
- 変更が期待どおりに動作しない場合は[ダウングレードと復旧](./downgrade-recovery)を使用します。
