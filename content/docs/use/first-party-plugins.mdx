This page is a candidate overview for publication pending. First-party plugins are a separate classification, not a claim that a bundle, deployment, public plugin directory, or detailed tutorial pages have been published.

## Candidate capability families

The candidate first-party set may include plugin families for:

- bulk parameter operations;
- mesh mirroring;
- clipping masks;
- palettes, scenes, and texture atlases;
- physics;
- backups;
- performance; and
- themes.

These are capability families, not release promises. Their precise set, availability, behavior, and compatibility remain pending and can differ by Preview build. Detailed tutorial pages will follow separately; do not infer that a plugin directory already contains these plugins.
