---
title: First-Party Plugins
description: The reviewed plugin bundle included in Full installations.
---

Full installations ship a reviewed bundle of first-party plugins. They use the same public SDK boundary as third-party plugins, and each one is an independent JAR that can be deselected during installation.

Availability of an individual feature still depends on the Cubism Editor version and the capability Providers that version exposes. A bundled plugin is not a promise that every feature works on every supported version.

## Modeling

| Plugin | What it does |
| --- | --- |
| MaxRects-BSSF Layout Algorithm | Registers a MaxRects-BSSF texture-atlas packing algorithm with parallel search. |
| Mesh Edit Mirror Axis Enhance | Adds mirror-axis rotation and exact-host mirror-tool parity to mesh editing. |
| Parameter Batch Transfer | Batch-transfers the parameter bindings of one ArtMesh or Deformer to other parameters, with optional inversion. |
| Physics Editor | Adds Physics Settings group select-all and reopen retention. |

## Workflow

| Plugin | What it does |
| --- | --- |
| Cubism Tab Filter | Adds keyword filter boxes to the Parameter, Deformer, Scene, and Log palette tabs. |
| PSD Clip Mask Import | Imports ordered PSD clipping relationships into ArtMesh clip-mask assignments with an explicit overwrite policy. |
| History Panel | Projects the active document's native Undo history into a Photoshop-style pane with snapshot-bound Undo/Redo navigation. |
| Recent Preview | Captures bounded preview thumbnails for recent project files in the Recent Files hover popup. |
| WebDAV Auto-Backup Sync | Uploads Cubism auto-backup artifacts to a WebDAV endpoint using the JDK HTTP client. Plugin ID: `dev.turboism.plugin.webdav`. |
| Protected Export | Optional protected runtime-model export: works on a task-owned copy, flattens Warp/Rotation deformers, obfuscates ArtMesh identities, validates the complete staged output, and publishes atomically. Admitted only on reviewed Cubism versions and eligible models. |

## Analysis and performance

| Plugin | What it does |
| --- | --- |
| Clip Mask Viewer | Read-only clip-mask duplicate checker and visualizer with a graph/table inspector and editor selection highlight. |
| Texture Atlas Statistics | Shows total and current-texture model-image counts in the native texture-atlas editor window. |
| Performance Statistics | Real-time CPU, FPS, and JVM memory charts as an embedded panel and a standalone window. |

## Appearance

| Plugin | What it does |
| --- | --- |
| UI Theme | Legacy-compatible theme packages, built-in themes, a theme manager workflow, and exact-version Cubism appearance application. |
| Palette Label Style | Label text and background colors for Deformer, Part, and Parameter palette entries. |
| Scene Palette Enhancer | Sorts and manually reorders items in the Cubism Scene palette. |

## Integration and system

| Plugin | What it does |
| --- | --- |
| Turboism MCP Server | Loopback Model Context Protocol server exposing typed Cubism inspection, editing, history, and Editor-command workflows. Requires bearer authentication; see [MCP](../build-a-plugin/mcp). |

The built-in Turboism menu, settings, logs, About, plugin management, and update hints are not a plugin. They are provided by the runtime-owned framework shell (`dev.turboism.shell`) under the reserved `turboism.core` identity; plugin management lists it as a built-in, non-removable row that cannot be disabled or uninstalled.

## How to manage them

- Deselect individual plugins while running the installer in Full or Thin mode.
- Enable or disable an installed plugin from plugin management; the change applies after Cubism restarts.
- [Plugin Management](./plugin-management) covers install, replacement, enable/disable, uninstall, and the data each plugin keeps.
- [Update Policy](./update-policy) covers how a newer bundle reaches an existing installation.
