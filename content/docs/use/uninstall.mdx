---
title: Uninstall
description: Remove Turboism with its own uninstaller while deciding what personal configuration to keep.
---

Use the uninstaller generated by the installer that installed your build. Do not remove files while Turboism or Cubism is running.

## Uninstall by installation method

- **Windows `.exe` installation** (`TurboismInstaller-<version>-full.exe` or `TurboismInstaller-<version>-thin.exe`): run `uninstall.exe` in the Turboism home directory.
- **Portable ZIP installation** (Windows manual setup, macOS, or Linux): portable archives have no uninstaller and do not enable official-BAT integration. Close Cubism completely and delete the Turboism folder.
- **Legacy installations (before 0.67.0-beta.3)**: installations made with the retired Java IzPack installer ran `java -jar <home>\Uninstaller\uninstaller.jar` on Windows/Linux or `uninstall.command` on macOS.

Procedure for `.exe` installations:

1. Close Turboism and Cubism normally.
2. Run `uninstall.exe` in the Turboism home directory.
3. Follow the confirmation steps.
4. When asked, choose whether to keep `config.json` (user configuration). The checkbox is checked by default; uncheck it if you want to delete `config.json`.
5. After completion, confirm that Cubism no longer starts through Turboism shortcuts or managed launch entries.

## What is removed and what is kept

- The uninstaller removes installer-owned runtime files, managed launch shortcuts, registration state, and runtime `logs`, `state`, and `cache` directories.
- `config.json` is kept by default and is removed only if you explicitly uncheck the retention box.
- The Full uninstaller removes only first-party plugin JARs originally deployed by the installer; unknown files and third-party plugin JARs are preserved. The Thin installer does not deploy plugin JARs and does not delete plugins.
- Persistent plugin data under `data/<pluginId>/` and configuration under `config/<pluginId>/` are not deleted by the uninstaller.

Review the remaining Turboism directory after uninstalling and back up anything you wish to preserve.

## Launcher integration

If you enabled optional integration with the official Cubism startup BAT, the uninstaller automatically restores the original BAT file from its hash-guarded backup. If those files were edited manually after installation, cleanup reports a conflict and preserves both state and backups instead of overwriting your changes.
