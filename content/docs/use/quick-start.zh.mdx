---
title: 快速开始
description: 安装已发布的 Turboism 安装包，进行配置，并验证首次运行。
---

本快速开始从[安装](./installation)中所述的已发布安装包开始。你需要该安装包，以及已安装且合法授权的 Cubism Editor。

## 1. 安全准备

- Windows x64 是受支持的 Cubism 宿主平台。当前稳定版 0.67.4 支持 5.0.00 至 5.3.04 的全部 20 个已审核 Cubism Editor 版本；请参阅[兼容性](/docs/use/compatibility)。
- 旧版 Java 安装器已不再发布；macOS 和 Linux 请使用便携 ZIP 安装包。
- 备份要打开的项目，或使用一次性副本。
- 将 Turboism home 与 Cubism 安装分开。
- 不要编辑 Cubism JAR、DLL、BAT 文件或许可状态。

## 2. 下载与验证

1. 打开 [turboism.dev/download](https://turboism.dev/download) 并选择渠道：**Stable**、**Beta** 或 **Nightly**。
2. 下载一个安装包及其配对的 `.sha256` 文件：
   - `TurboismInstaller-<version>.exe`：Windows 安装器（Windows 上推荐）。
   - `turboism-<version>.zip`：便携归档，用于在 Windows、macOS 或 Linux 上手动配置。

   两种安装包都包含运行时框架、全部随包第一方插件以及完整的离线 GraalJS 引擎。
3. 验证文件哈希，例如在 PowerShell 中：

   ```powershell
   Get-FileHash ".\TurboismInstaller-<version>.exe" -Algorithm SHA256
   ```

安装器未签名，因此校验和是你可以自行完成的完整性检查。

## 3. 安装

### Windows `.exe` 安装器

1. 运行 `TurboismInstaller-<version>.exe`。
2. 选择安装器语言（英语、简体中文、日语或韩语）。
3. 阅读许可协议，并确认全部四项必需确认。
4. 选择安装目录（默认为 `%LOCALAPPDATA%\Turboism`）。安装器没有模式选择页或插件勾选页：会安装全部随包第一方插件。
5. 选择立即下载可选的 Turboism 托管 GraalVM 运行时，或稍后通过配置向导安装。
6. 检查安装器找到的 Cubism 安装，或通过 **导入版本** 添加。即使一个都没找到，Turboism 仍会完成安装，之后可用 `configure_turboism.ps1` 配置 Cubism。
7. 在启动选项页保留或更改开始菜单快捷方式、桌面快捷方式和 Cubism 官方 BAT 集成的选择。BAT 集成默认勾选，使现有 Cubism 快捷方式加载 Turboism；取消勾选则不会改动官方 BAT 文件。
8. 通过 Turboism 快捷方式、现有 Cubism 快捷方式（启用 BAT 集成时）或 `launch-cubism-turboism.bat` 启动 Cubism。

### 便携式 ZIP

1. 将整个归档（`turboism-<version>.zip`）解压到独立文件夹中，不要解压到 Cubism 安装目录。
2. 从该文件夹运行 `configure_turboism.ps1`，并选择 Cubism 安装。
3. 通过生成的快捷方式或 `launch-cubism-turboism.bat` 启动 Cubism。

安装器选项与历史安装包（包括 0.67.0 Beta 期间已退役的 Full/Thin 下载，以及 0.44.0 及更早版本的旧版构件）请参阅[安装器与便携 ZIP](./installer-modes)。

安装器语言只影响安装器。Turboism 在运行时使用的语言来自运行时 `locale` 设置，插件界面语言跟随 Cubism Editor 的 **File → Environment Settings → General → Language**。

## 4. 验证首次运行

检查以下各项：

- Cubism 正常启动；
- Turboism runtime 报告启动成功；
- runtime 使用预期的 Turboism home；
- 顶部菜单名称为 **Turboism**（原为“插件”/Plugins 菜单）；
- **Turboism** 菜单包含：**插件市场…**、**管理插件…**、**插件设置…**（专用双栏窗口）、**检查更新**、**Turboism 设置…**、**快捷键…**、**日志…**、各插件操作以及**关于**；
- 已安装的插件出现在插件管理器和运行时诊断中；
- 不可用的宿主能力会安全地失败关闭，而不是导致 Cubism 崩溃；
- 关闭 Cubism 后，插件 scope 和框架所有的 executor 都会释放。

## 5. 添加与管理插件

每个安装包都已预装全部随包第一方插件。如需添加更多插件或进行管理：

- 打开 Cubism，点击 **Turboism → 插件市场…**（或访问 [turboism.dev/plugins](https://turboism.dev/plugins)）浏览并安装插件。
- 第一方插件在通过签名验证后会在后台自动更新。标记为热更新（hot-reload）的插件立即生效；其他插件在重启 Cubism 后生效。用户可在设置中关闭官方插件自动更新。
- 随时通过 **Turboism → 管理插件…** 启用或停用已安装的插件；变更在重启 Cubism 后生效。
- 通过 **Turboism → 插件设置…** 专用的双栏窗口集中配置各插件选项。

### 本地插件 JAR 安装

如需添加本地或第三方插件 JAR：

1. 打开 Turboism，选择 **Turboism → 管理插件…**。
2. 选择 **从 JAR 安装…**（Install from JAR…）。
3. 选择本地 `.jar` 文件。
4. 确认将 JAR 标记为本地/未验证来源的对话框。
5. 当操作显示为 pending 时重启 Cubism。

确认后插件 JAR 会被暂存，并在重启后生效。插件变更不会热切换当前已加载的插件实例。插件 JAR 与 Turboism 安装程序是相互独立的。

### 手动安装（备选）

作为高级备用路径——例如在本地测试构建出的 JAR——你可以直接放置插件 JAR：

1. 完全关闭 Cubism 和 Turboism。
2. 将受信任的插件 JAR 直接复制到 `<turboism.home>/plugins/` 根下。
3. 保持每个 plugin ID 最多一个 JAR。
4. 使用同一个 Turboism home 重启。
5. 验证插件状态和运行时日志。

手动安装会绕过托管保护。完整流程请参见[插件管理](./plugin-management)。

## 6. 查找日志

使用已安装的 Turboism home 的 `logs/` 目录，或点击顶部菜单中的 **Turboism → 日志…**。报告启动、JAR、依赖、权限或 Provider 故障时，请保留日志。
