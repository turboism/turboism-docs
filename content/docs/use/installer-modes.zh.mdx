---
title: 安装器模式
description: 比较 Full、Thin 和 Lite 安装选项以及可选的托管 GraalVM 组件。
---

Turboism 安装器和便携归档随附相同的 runtime，但插件选择不同。模式选择的是文件；它绝不会更改你的 Cubism 安装。

## 模式

- **Full** — agent 加上已审查的第一方插件捆绑包。安装器会预先选中所有已批准的发行插件，并允许取消勾选单个插件。
- **Thin** — 相同的已批准插件清单，但不包含额外的托管原生 runtime payload。可在 Java 安装器中使用，该安装器还接受显式的自定义可执行文件路径。
- **Lite** — 仅 agent 和公共文件。不会复制任何第一方插件 JAR。

Windows `.exe` 安装器提供 **Full** 和 **Lite**。跨平台 `.jar` 安装器提供 **Full**、**Thin** 和 **Lite**。便携归档以同一 payload 的 `full` 和 `lite` 变体提供。

## 可选的托管 GraalVM

安装器提供可选的托管 GraalVM 组件：

- 它从 GraalVM 官方 GitHub release 下载固定的归档，并在使用前进行验证；
- 不勾选它会保持安装对插件捆绑包而言有效且完整；
- 你可以稍后从 Turboism 设置中安装它。

仅用于开发的 `Turboism with fx` 插件及其托管 runtime 字节不属于任何发行安装包。

## 模式不会改变什么

- 每种模式下的 runtime home、配置、日志和插件数据都相同。
- 重新运行安装器会对同一个 home 应用不同的选择，并且只更改托管的插件状态。
- 模式变更绝不会删除未知文件和第三方插件 JAR。
- 模式标签并不保证某个插件功能在你的 Cubism 版本上可用。可用性仍与 capability 和版本相关。

## 选择之前

1. 备份 `config.json` 以及任何重要的插件 `config/` 或 `data/` 内容。
2. 查看[更新策略](./update-policy)，了解安装器重跑和发布渠道的工作方式。
3. 如果变更的行为不符合预期，请使用[降级与恢复](./downgrade-recovery)。
