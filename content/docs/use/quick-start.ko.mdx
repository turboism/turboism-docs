---
title: 빠른 시작
description: 공개된 Turboism 패키지를 설치하고 구성한 뒤 첫 실행을 검증합니다.
---

이 빠른 시작은 [설치](./installation)에서 설명한 공개 릴리스 패키지에서 시작합니다. 패키지와 적법한 라이선스를 취득해 설치된 Cubism Editor가 필요합니다.

## 1. 안전하게 준비하기

- Windows x64가 지원되는 Cubism 호스트 플랫폼입니다. 현재 안정판 0.67.4는 5.0.00부터 5.3.04까지 검토된 Cubism Editor 20개 버전 전체를 지원합니다([호환성](/docs/use/compatibility) 참고).
- 기존 Java 설치 프로그램은 더 이상 게시되지 않습니다. macOS 및 Linux 사용자는 포터블 ZIP 패키지를 사용합니다.
- 열어 볼 프로젝트를 백업하거나 일회용 복사본을 사용하세요.
- Turboism home을 Cubism 설치와 분리해 유지하세요.
- Cubism JAR, DLL, BAT 파일 또는 라이선스 상태를 편집하지 마세요.

## 2. 다운로드 및 검증

1. [turboism.dev/download](https://turboism.dev/download)를 열고 채널을 선택하세요: **Stable**, **Beta** 또는 **Nightly**.
2. 패키지 하나와 그에 맞는 `.sha256` 파일을 다운로드하세요:
   - `TurboismInstaller-<version>.exe`: Windows 설치 프로그램(Windows에서 권장).
   - `turboism-<version>.zip`: Windows, macOS 또는 Linux에서 수동 설정하기 위한 포터블 아카이브.

   두 패키지 모두 런타임 프레임워크, 모든 기본 제공 퍼스트 파티 플러그인, 완전한 오프라인 GraalJS 엔진을 포함합니다.
3. 예를 들어 PowerShell에서 파일 해시를 검증하세요:

   ```powershell
   Get-FileHash ".\TurboismInstaller-<version>.exe" -Algorithm SHA256
   ```

설치 프로그램에는 서명이 없으므로 체크섬이 직접 수행할 수 있는 무결성 검사입니다.

## 3. 설치

### Windows `.exe` 설치 프로그램

1. `TurboismInstaller-<version>.exe`를 실행하세요.
2. 설치 프로그램 언어(영어, 중국어 간체, 일본어 또는 한국어)를 선택하세요.
3. 라이선스를 읽고 네 가지 필수 확인 항목을 모두 확인하세요.
4. 설치 디렉터리를 선택하세요(기본값 `%LOCALAPPDATA%\Turboism`). 모드 선택이나 플러그인 선택 페이지는 없으며, 모든 기본 제공 퍼스트 파티 플러그인이 설치됩니다.
5. 선택적 Turboism 관리형 GraalVM 런타임을 지금 다운로드할지, 나중에 설정 도구에서 설치할지 선택하세요.
6. 설치 프로그램이 찾은 Cubism 설치를 확인하거나 **버전 가져오기**로 추가하세요. 하나도 찾지 못해도 Turboism은 설치되며, 나중에 `configure_turboism.ps1`로 Cubism을 구성할 수 있습니다.
7. 시작 옵션 페이지에서 시작 메뉴 바로 가기, 바탕 화면 바로 가기, Cubism 공식 BAT 통합 선택을 유지하거나 변경하세요. BAT 통합은 기본 선택되어 있어 기존 Cubism 바로 가기에서 Turboism이 로드됩니다. 해제하면 공식 BAT 파일은 변경되지 않습니다.
8. Turboism 바로 가기, 기존 Cubism 바로 가기(BAT 통합 시) 또는 `launch-cubism-turboism.bat`으로 Cubism을 시작하세요.

### 포터블 ZIP

1. 압축 파일 전체(`turboism-<version>.zip`)를 Cubism 설치 디렉터리가 아닌 별도 폴더에 풀어 주세요.
2. 해당 폴더에서 `configure_turboism.ps1`을 실행하고 Cubism 설치를 선택하세요.
3. 생성된 바로 가기 또는 `launch-cubism-turboism.bat`으로 Cubism을 시작하세요.

설치 프로그램 옵션과 패키지 이력(0.67.0 베타에서 폐지된 Full/Thin 다운로드와 0.44.0 이하의 레거시 자산 포함)은 [설치 프로그램과 포터블 ZIP](./installer-modes)을 참고하세요.

설치 프로그램 언어는 설치 프로그램에만 영향을 줍니다. Turboism이 실행 시 사용하는 언어는 `config.json`의 `locale` 설정으로 결정되며, 플러그인 인터페이스 언어는 Cubism Editor의 **File → Environment Settings → General → Language**를 따릅니다.

## 4. 첫 실행 검증

다음을 확인하세요:

- Cubism이 정상적으로 시작됩니다;
- Turboism 런타임이 시작을 보고합니다;
- 런타임이 의도한 Turboism home을 사용합니다;
- 상단 메뉴 이름이 **Turboism**입니다(이전에는 "플러그인"/Plugins);
- **Turboism** 메뉴에 다음 항목이 나열됩니다: **플러그인 마켓…**, **플러그인 관리…**, **플러그인 설정…**(전용 2열 창), **업데이트 확인**, **Turboism 설정…**, **키 바인딩…**, **로그…**, 플러그인 액션, **정보**;
- 설치된 플러그인이 플러그인 관리자와 런타임 진단에 나타납니다;
- 사용할 수 없는 호스트 기능은 Cubism을 충돌시키지 않고 안전하게 실패(fail closed)합니다;
- Cubism을 닫으면 플러그인 스코프와 프레임워크가 소유한 실행기가 해제됩니다.

## 5. 플러그인 추가 및 관리

모든 패키지에는 기본 제공 퍼스트 파티 플러그인이 이미 포함되어 있습니다. 플러그인을 추가하거나 관리하려면:

- Cubism을 열고 **Turboism → 플러그인 마켓…**(또는 [turboism.dev/plugins](https://turboism.dev/plugins))에서 플러그인을 찾아 설치하세요.
- 퍼스트 파티 플러그인은 서명 검증을 거쳐 백그라운드에서 자동 업데이트됩니다. 핫 리로드(hot-reload)로 표시된 플러그인은 즉시 적용되며 기타 업데이트는 Cubism 재시작 후 적용됩니다. 사용자는 설정에서 공식 플러그인 자동 업데이트를 끌 수 있습니다.
- 설치된 플러그인은 **Turboism → 플러그인 관리…**에서 언제든지 사용 여부를 전환할 수 있습니다(변경 사항은 재시작 후 적용).
- 각 플러그인 옵션은 **Turboism → 플러그인 설정…**의 전용 2열 창에서 설정할 수 있습니다.

### 로컬 플러그인 JAR 설치

로컬 또는 서드파티 플러그인 JAR을 추가하려면:

1. Turboism을 열고 **Turboism → 플러그인 관리…**를 선택하세요.
2. **JAR에서 설치…**(Install from JAR…)를 선택하세요.
3. 로컬 `.jar` 파일을 선택하세요.
4. JAR을 로컬/미검증 소스로 표시하는 대화 상자를 확인하세요.
5. 작업이 보류 중(pending)으로 표시되면 Cubism을 재시작하세요.

확인 후 JAR이 스테이징되며 재시작 후 적용됩니다. 플러그인 변경은 현재 로드된 플러그인 인스턴스를 핫 스왑하지 않습니다. 플러그인 JAR은 Turboism 설치 프로그램 파일과 별개입니다.

### 수동 설치(대체 방법)

로컬에서 빌드한 JAR을 테스트하는 등의 고급 대체 방법으로 플러그인 JAR을 직접 배치할 수도 있습니다:

1. Cubism과 Turboism을 완전히 종료하세요.
2. 신뢰할 수 있는 플러그인 JAR을 `<turboism.home>/plugins/` 루트에 직접 복사하세요.
3. 각 플러그인 ID당 최대 하나의 JAR만 유지하세요.
4. 같은 Turboism home으로 다시 시작하세요.
5. 플러그인 상태와 런타임 로그를 확인하세요.

수동 설치는 관리형 보호를 우회합니다. 전체 절차는 [플러그인 관리](./plugin-management)를 참고하세요.

## 6. 로그 찾기

설치된 Turboism home의 `logs/` 디렉터리를 사용하거나 상단 메뉴에서 **Turboism → 로그…**를 선택하세요. 시작, JAR, 종속성, 권한 또는 Provider 오류를 보고할 때 로그를 보관하세요.
