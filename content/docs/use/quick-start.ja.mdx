このクイックスタートは、[インストール](./installation) で説明している公開リリースパッケージから始めます。必要なのは、パッケージと、適法にライセンスされた Cubism Editor がインストールされていることです。

## 1. 安全に準備する

- Windows x64 が対応する Cubism ホストプラットフォームです。現在の安定版 0.67.4 は、5.0.00 から 5.3.04 までのレビュー済み全 20 の Cubism Editor バージョンに対応しています（[互換性](/docs/use/compatibility)を参照）。
- 従来の Java インストーラーは現在公開されていません。macOS および Linux ではポータブル ZIP パッケージを使用します。
- 開くプロジェクトをバックアップするか、使い捨てのコピーを使用します。
- Turboism home を Cubism のインストール先から分離しておきます。
- Cubism JAR、DLL、BAT ファイル、ライセンス状態を編集しないでください。

## 2. ダウンロードと検証

1. [turboism.dev/download](https://turboism.dev/download) を開き、**Stable**、**Beta**、**Nightly** のいずれかのチャンネルを選びます。
2. パッケージを 1 つと、対応する `.sha256` ファイルをダウンロードします:
   - `TurboismInstaller-<version>.exe`: Windows インストーラー（Windows で推奨）。
   - `turboism-<version>.zip`: Windows、macOS、Linux で手動セットアップするためのポータブルアーカイブ。

   どちらのパッケージにも、ランタイムフレームワーク、すべての同梱ファーストパーティプラグイン、完全なオフライン GraalJS エンジンが含まれます。
3. ファイルのハッシュを検証します。たとえば PowerShell では:

   ```powershell
   Get-FileHash ".\TurboismInstaller-<version>.exe" -Algorithm SHA256
   ```

インストーラーは署名されていないため、チェックサムが自分で実行できる完全性の確認手段です。

## 3. インストール

### Windows `.exe` インストーラー

1. `TurboismInstaller-<version>.exe` を実行します。
2. インストーラーの言語（英語、簡体字中国語、日本語、韓国語）を選択します。
3. ライセンスを読み、4 つの必須の確認事項すべてを承諾します。
4. インストールディレクトリ（既定では `%LOCALAPPDATA%\Turboism`）を選びます。モード選択やプラグイン選択画面はなく、すべての同梱ファーストパーティプラグインがインストールされます。
5. 任意の Turboism 管理 GraalVM ランタイムを今すぐダウンロードするか、後で設定ツールからインストールするかを選びます。
6. インストーラーが見つけた Cubism インストールを確認するか、**バージョンを追加** で追加します。見つからない場合でも Turboism はインストールされ、後から `configure_turboism.ps1` で Cubism を設定できます。
7. 起動オプションページで、スタートメニューのショートカット、デスクトップのショートカット、Cubism 公式 BAT 統合の選択を確認・変更します。BAT 統合は既定で選択されており、既存の Cubism ショートカットで Turboism が読み込まれます。解除すると公式 BAT ファイルは変更されません。
8. Turboism のショートカット、既存の Cubism ショートカット（BAT 統合時）、または `launch-cubism-turboism.bat` で Cubism を起動します。

### ポータブル ZIP

1. アーカイブ全体（`turboism-<version>.zip`）を、Cubism のインストールディレクトリではない専用のフォルダに展開します。
2. そのフォルダで `configure_turboism.ps1` を実行し、Cubism インストールを選択します。
3. 生成されたショートカット、または `launch-cubism-turboism.bat` から Cubism を起動します。

インストーラーのオプションとパッケージ履歴（0.67.0 ベータ版で廃止された Full/Thin ダウンロードや 0.44.0 以前の従来の配布資産を含む）については、[インストーラーとポータブル ZIP](./installer-modes)を参照してください。

インストーラーの言語はインストーラーにのみ影響します。Turboism が実行時に使用する言語は `config.json` の `locale` 設定から決まり、プラグインのインターフェース言語は Cubism Editor の **ファイル → 環境設定 → 一般 → 言語** に従います。

## 4. 初回起動を確認する

次を確認してください。

- Cubism が通常どおり起動する。
- Turboism ランタイムが起動を報告する。
- ランタイムが意図した Turboism home を使用する。
- トップメニュー名が **Turboism** になっている（以前は「プラグイン」/「插件」）。
- **Turboism** メニューに、**プラグインマーケット…**、**プラグイン管理…**、**プラグイン設定…**（専用の 2 ペインウィンドウ）、**更新を確認**、**Turboism 設定…**、**キーバインド…**、**ログ…**、プラグインアクション、**バージョン情報** が一覧表示される。
- インストール済みのプラグインがプラグイン管理とランタイム診断に表示される。
- 利用できないホスト機能が Cubism をクラッシュさせず安全に停止（fail closed）する。
- Cubism を閉じるとプラグインのスコープとフレームワーク所有の executor が解放される。

## 5. プラグインの追加と管理

どのパッケージにもすべての同梱ファーストパーティプラグインが含まれています。プラグインを追加・管理する場合:

- Cubism を開き、**Turboism → プラグインマーケット…**（または [turboism.dev/plugins](https://turboism.dev/plugins)）からプラグインを導入します。
- ファーストパーティプラグインは署名検証を経てバックグラウンドで自動更新されます。ホットリロード（hot-reload）対応プラグインは即座に反映され、その他の更新は Cubism 再起動後に反映されます。設定で公式プラグインの自動更新を無効化できます。
- インストール済みプラグインは **Turboism → プラグイン管理…** からいつでも有効化・無効化できます（反映には Cubism の再起動が必要）。
- 各プラグインの詳細設定は、専用の 2 ペインウィンドウ **Turboism → プラグイン設定…** で行えます。

### ローカルプラグイン JAR のインストール

ローカルまたはサードパーティのプラグイン JAR を追加する場合:

1. Turboism を開き、**Turboism → プラグイン管理…** を選択します。
2. **JAR からインストール…**（Install from JAR…）を選択します。
3. ローカルの `.jar` ファイルを選択します。
4. JAR をローカル/未検証のソースとしてマークするダイアログを確認します。
5. 操作が保留中（pending）と表示されたら、Cubism を再起動します。

確認後、JAR はステージングされ、再起動後に適用されます。プラグイン変更によって、実行中のプラグインインスタンスがホットスワップされることはありません。プラグイン JAR は Turboism のインストーラーファイルとは別物です。

### 手動セットアップ（代替手順）

ローカルでビルドした JAR をテストするなどの高度な代替経路として、直接ファイルを配置することも可能です:

1. Cubism と Turboism を完全に終了します。
2. 信頼できるプラグイン JAR を `<turboism.home>/plugins/` の直下にコピーします。
3. 各プラグイン ID ごとに最大 1 つの JAR を配置します。
4. 同じ Turboism home を使って再起動します。
5. プラグインの状態とランタイムログを確認します。

手動配置は管理上の保護を迂回します。詳細な手順は[プラグイン管理](./plugin-management)を参照してください。

## 6. ログを確認する

インストール先の Turboism home の `logs/` ディレクトリを使用するか、トップメニューの **Turboism → ログ…** を選択します。起動、JAR、依存関係、権限、Provider の障害を報告する際はログを保存してください。
