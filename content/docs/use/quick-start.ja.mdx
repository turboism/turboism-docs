title: クイックスタート
description: 公開された Turboism パッケージをインストールし、設定して、初回起動を確認する。
---

このクイックスタートは、[インストール](./installation) で説明している公開リリースパッケージから始めます。必要なのは、パッケージと、適法にライセンスされた Cubism Editor がインストールされていることです。

## 1. 安全に準備する

- Windows x64 が対応する Cubism ホストプラットフォームです。対応する Editor バージョンは 5.2.03、5.3.02、5.3.03 です。
- `.jar` インストーラーには Java 17+ ランタイムが必要です。
- 開く project を backup するか、使い捨ての copy を使用します。
- Turboism home を Cubism installation から分離しておきます。
- Cubism JAR、DLL、BAT file、licensing state を編集しないでください。

## 2. ダウンロードと検証

1. [turboism.dev/download](https://turboism.dev/download) を開き、**Stable**、**Beta**、**Nightly** のいずれかのチャンネルを選びます。
2. パッケージを 1 つと、対応する `.sha256` ファイルをダウンロードします。
3. ファイルのハッシュを検証します。たとえば PowerShell では:

   ```powershell
   Get-FileHash ".\TurboismInstaller-<version>.exe" -Algorithm SHA256
   ```

インストーラーは署名されていないため、チェックサムが自分で実行できる完全性の確認手段です。

## 3. インストール

### Windows `.exe` インストーラー

1. `TurboismInstaller-<version>.exe` を実行します。
2. インストーラーの言語（英語、簡体字中国語、日本語、韓国語）を選択します。
3. ライセンスを読み、4 つの必須の確認事項すべてを承諾します。
4. **Full** または **Lite** を選択し、インストールディレクトリ（既定では `%LOCALAPPDATA%\Turboism`）を選びます。Full モードでは個々のプラグインの選択を解除できます。
5. オプションのマネージド GraalVM コンポーネントをダウンロードするかどうかを決めます。
6. インストーラーが `configure_turboism.ps1` を開いたら、使用する Cubism インストールを選択して保存します。設定をキャンセルしても、フレームワークのみの有効なインストールが残ります。
7. Cubism ルートの管理ランチャー（`launch-cubism-turboism.bat`）で Cubism を起動します。

### クロスプラットフォーム `.jar` インストーラー

1. インストーラーを実行します:

   ```bash
   java -jar TurboismInstaller-<version>.jar
   ```

   `-language eng|chn|jpn|kor` を渡すと、インストーラーの言語を事前選択できます。
2. 宣言を完了し、**Full**、**Thin**、**Lite** のいずれかと対象ディレクトリを選択します。
3. Windows では、インストール済みの `configure_turboism.ps1` を実行し、Cubism インストールを選択して、管理ランチャーで起動します。macOS では、このインストーラーはインストールとアンインストールのみを対象とします。macOS の Cubism ホスト対応は未検証で、macOS ランチャーもインストールされません。

### ポータブル ZIP

1. アーカイブ全体を専用のフォルダに展開します。
2. そのフォルダで `configure_turboism.ps1` を実行し、Cubism インストールを選択します。
3. 生成されたショートカット、または `launch-cubism-turboism.bat` から Cubism を起動します。

インストーラーの言語はインストーラーにのみ影響します。Turboism が実行時に使用する言語はランタイムの `locale` 設定から決まり、プラグインのインターフェース言語は Cubism Editor の **ファイル → 環境設定 → 一般 → 言語**（File → Environment Settings → General → Language）に従います。

## 4. 初回起動を確認する

次を確認してください。

- Cubism が通常どおり起動する。
- Turboism ランタイムが起動を報告する。
- ランタイムが意図した Turboism home を使用する。
- インストール済みの plugin がプラグインマネージャーと runtime diagnostics に表示される。
- 利用できない host capability が Cubism をクラッシュさせず fail closed する。
- Cubism を閉じると plugin scope と framework 所有の executor が解放される。

## 5. プラグインを追加する

Full の選択では、レビュー済みのファーストパーティプラグインバンドルが既にインストールされています。ローカルプラグイン JAR を追加するには:

1. Turboism を開き、**プラグイン管理**（Plugin Management）を選択します。
2. **JAR からインストール…**（Install from JAR…）を選択します。
3. ローカル `.jar` file を選択します。
4. JAR をローカル/未検証ソースと示すダイアログを確認します。
5. operation が pending と表示されたら Cubism を再起動します。

確認後、プラグイン JAR はステージングされ、再起動後に適用されます。プラグインの変更は、ロード中の plugin instance を hot-swap しません。プラグイン JAR は Turboism インストーラー JAR とは別物です。

### 手動インストール（代替）

上級のフォールバック経路として（例：ローカルで build した JAR のテスト）、プラグイン JAR を直接配置できます:

1. Cubism と Turboism を完全に閉じます。
2. 信頼できる plugin JAR を `<turboism.home>/plugins/` の直下に直接コピーします。
3. plugin ID ごとに JAR を最大 1 つにします。
4. 同じ Turboism home で再起動します。
5. plugin state と runtime logs を確認します。

手動インストールはマネージドの保護を迂回します。手順の全体は [プラグイン管理](./plugin-management) を参照してください。

## 6. ログを見つける

インストール済みの Turboism home の `logs/` ディレクトリを使用します。起動、JAR、dependency、permission、Provider の失敗を報告するときはログを保持してください。
