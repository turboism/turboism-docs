**0.67.0-beta.3** 以降、Turboism はウィザード形式のモード選択を廃止し、2 つのバリアントに分かれた 4 つの正式リリース資産を提供しています。

- **Full**（`TurboismInstaller-<version>-full.exe`、`turboism-<version>-full.zip`）— ランタイムフレームワークとすべての同梱ファーストパーティープラグイン。
- **Thin**（`TurboismInstaller-<version>-thin.exe`、`turboism-<version>-thin.zip`）— ランタイムフレームワークのみ（ファーストパーティープラグインは含まれません）。

Thin バリアントでは、プラグインは後から Cubism 内のプラグインマーケット（**Turboism** メニュー → **プラグインマーケット…**）または [turboism.dev/plugins](https://turboism.dev/plugins) から導入します。

どちらのバリアントも Cubism のインストールファイルやライセンス状態を変更しません。

## Full と Thin の機能境界

| 機能 | Full バリアント | Thin バリアント |
| --- | --- | --- |
| ランタイムフレームワーク & Java Agent | 含む | 含む |
| 設定ツール（`configure_turboism.ps1`） | 含む | 含む |
| 同梱ファーストパーティープラグイン | `plugins/` にすべて含む | なし |
| プラグインの導入方法 | インストール済み | プラグインマーケットまたは Web ディレクトリから |
| プラグイン管理と有効化/無効化 | **Turboism → プラグイン管理…** | **Turboism → プラグイン管理…** |
| バックグラウンド自動更新 | 署名検証付きのファーストパーティ更新 | 署名検証付きのファーストパーティ更新 |

### モード選択およびプラグイン選択ウィザード画面の廃止

インストーラーにはモード選択や個別プラグイン選択の画面はありません。

- `TurboismInstaller-<version>-full.exe` は個別選択なしですべてのファーストパーティープラグインをインストールします。
- `TurboismInstaller-<version>-thin.exe` はフレームワークファイルのみをインストールします。
- プラグインは Cubism 起動後に **Turboism → プラグイン管理…** で有効化・無効化を切り替えることができ、Cubism 再起動後に反映されます。
- 署名検証済みのファーストパーティープラグインはバックグラウンドで自動更新されます。ホットリロード（hot-reload）対応プラグインは即座に適用され、その他の更新は Cubism 再起動後に適用されます。設定で公式プラグインの自動更新を無効化することもできます。

## バリアント間の安全なアップグレード

異なるバリアント間の上書き更新は安全かつ冪等です。

- **Thin を Full に上書き**: 既存の Full 環境に Thin インストーラーを適用すると、既存の `plugins/` ディレクトリはそのまま保持され、ユーザー設定も保護されます。
- **Full を Thin に上書き**: 既存の Thin 環境に Full インストーラーを適用すると、`config.json` 内の既存の `disabledPlugins`（無効化設定）を維持しながら、すべての同梱ファーストパーティープラグインが導入または更新されます。

どちらの場合も、`config.json` 内のユーザー設定および `cubism-installations.json` の Cubism 連携情報は保持されます。

## オプションのスクリプトエンジンと GraalVM

Windows インストーラーは、JavaScript エンジンおよび GraalVM 依存関係を取得するオプションコンポーネントを提供します。

- 選択しない場合でも、基本フレームワークと Java プラグインは完全かつ正常に動作します。
- 後から `install-script-engine.ps1` スクリプトまたは設定画面からインストールできます。
- 開発専用の `Turboism with fx` プラグインおよびマネージド fx ランタイムは、どのリリースパッケージにも含まれません。

## 以前のパッケージ（0.67.0-beta.3 未満）

**0.67.0-beta.3** より前のリリースでは、従来の配布構成が使用されていました。

- Full と Lite のモード選択画面および個別コンポーネント選択画面を持つ単一の Windows インストーラー `TurboismInstaller-<version>.exe`。
- Full、Thin、Lite モードを提供するクロスプラットフォームの IzPack Java インストーラー `TurboismInstaller-<version>.jar`（Java 17 以降が必要）。
- `turboism-<version>-full.zip` と `turboism-<version>-lite.zip` として配布されるポータブルアーカイブ。

0.67.0-beta.3 以降:
- Java インストーラー JAR は廃止されました。macOS および Linux ではポータブル ZIP を使用します。
- 旧「Lite」モードは Thin バリアント（`-thin.exe` および `-thin.zip`）に置き換わりました。
- インストーラーでのプラグイン個別選択は、アプリ内のプラグインマーケットおよびプラグイン管理に移行しました。
