**0.67.0** 安定版以降、Turboism の各リリースが提供する製品ダウンロードは次の 2 つだけで、それぞれに対応する `.sha256` チェックサムが付きます。

- **Windows インストーラー** — `TurboismInstaller-<version>.exe`。Windows での推奨手段です。
- **ポータブル ZIP** — `turboism-<version>.zip`。Windows での手動セットアップおよび macOS・Linux 向けです。

どちらのパッケージも内容は同じです。ランタイムフレームワーク、設定ツール（`configure_turboism.ps1`）、すべての同梱[ファーストパーティープラグイン](./first-party-plugins)、そして完全なオフライン GraalJS エンジンを含みます。GraalVM ランタイムのインストールは引き続き別の任意手順です。プラグインを含まないパッケージや個別プラグイン選択はありません。プラグインは後から Cubism 内の **Turboism → プラグイン管理…** で有効化・無効化します。

どちらのパッケージも Cubism の JAR、DLL、ライセンス状態を変更しません。Cubism の起動 BAT ファイルを変更するのは後述の任意の公式 BAT 統合だけで、ハッシュで保護されたバックアップを使用します。

## インストーラーとポータブル ZIP の比較

| | Windows インストーラー（`.exe`） | ポータブル ZIP（`.zip`） |
| --- | --- | --- |
| プラットフォーム | Windows x64 | Windows（手動セットアップ）、macOS と Linux（プレビュー / ランタイムのみ） |
| 同梱ファーストパーティープラグインとオフライン GraalJS | 含む | 含む |
| インストール先 | 既定は `%LOCALAPPDATA%\Turboism`、変更可 | 展開先の任意の独立フォルダー |
| Cubism の検出 | ウィザードに内蔵 | `configure_turboism.ps1` を自分で実行 |
| 起動エントリ | スタートメニューとデスクトップのショートカット（選択可） | 設定ツールが生成するショートカット、または `launch-cubism-turboism.bat` |
| Cubism 公式 BAT 統合 | 既定で選択済み、解除可 | 有効化されない |
| 削除 | `uninstall.exe` | Cubism を終了してフォルダーを削除 |

## インストーラーのオプション

Windows インストーラーはユーザー単位で実行され、次のページを順に進みます。

1. **言語** — ようこそ画面の前に英語、簡体字中国語、日本語、韓国語から選択します。この選択はインストーラーにのみ影響し、`config.json` には書き込まれません。
2. **ライセンスと確認事項** — AGPL-3.0-only ライセンスに同意し、エンドユーザー向けランタイム声明および免責事項を確認したうえで、4 つの必須確認事項すべてにチェックします。
3. **ディレクトリ** — Turboism ホーム。既定は `%LOCALAPPDATA%\Turboism` です。
4. **GraalVM** — 任意の Turboism 管理 GraalVM ランタイム（約 326 MiB）について、**後でインストール** または **今すぐダウンロードしてインストール**（推奨）を選びます。ダウンロードはサイズ、SHA-256、リリースメタデータで検証され、選択した場合にのみ行われます。後から Turboism の設定ツールでインストールすることもできます。
5. **Cubism インストール** — インストーラーがインストール済みの Cubism Editor をスキャンし、**バージョンを追加** でフォルダーを追加できます。サポート対象のインストールが見つからなくても Turboism はインストールでき、後から `configure_turboism.ps1` で設定できます。
6. **起動オプション** — Cubism を Turboism とともに起動する方法を選びます。
   - **Turboism のスタートメニューショートカットを作成**（推奨、既定で選択）
   - **Turboism のデスクトップショートカットを作成**（既定で選択）
   - **選択した Cubism 公式起動 BAT を変更し、既存の Cubism ショートカットで Turboism を読み込む**（推奨、既定で選択）

   3 つすべてを解除すると、通常の起動経路のいずれからも Turboism が有効にならないことをインストーラーが警告します。
7. **完了** — 必要に応じて Turboism を起動します。

### Cubism 公式 BAT 統合

0.67.0 以降、インストーラーは Cubism 公式 BAT 統合を既定で選択します。選択した `CubismEditor5.bat` ランチャーをバックアップして変更し、既存の Cubism ショートカット、ファイル関連付け、その他の入口がマネージドランチャーを経由せずに Turboism を読み込むようにします。

- 起動オプションページで解除できます。スタートメニューのショートカットはこれとは独立して動作します。
- ハッシュで保護され冪等です。インストール後に編集された BAT ファイルは競合として報告され、上書きされることはありません。
- アンインストール時に検証済みバックアップから復元されます。
- サイレントインストールでも適用されます。
- UAC による昇格が行われるのはこの統合手順だけで、それ以外のインストールは管理者権限なしで実行されます。

## アップグレード

同じ Turboism ホームに対して新しいインストーラーを実行します。既存のインストールをアップグレードし、現在の同梱ファーストパーティープラグインを導入し、廃止された公式プラグイン JAR を（ファイル名だけでなく埋め込まれたプラグイン ID で判定して）撤去し、既存の `disabledPlugins` を保持するため、無効化したプラグインは無効のままです。`config.json` のその他の有効な設定と `cubism-installations.json` の Cubism 連携情報も保持されます。

ポータブル ZIP の場合は、[インストール](./installation)の説明に従って新しいアーカイブを展開し、設定ツールを再度実行します。

開発専用の `Turboism with fx` プラグインおよびマネージド fx ランタイムは、どのリリースパッケージにも含まれません。

## パッケージ履歴

- **0.67.0-beta.3 〜 0.67.0-beta.7** では、一時的に 2 つのバリアントに分かれた 4 つのダウンロードを提供していました。Full（`TurboismInstaller-<version>-full.exe`、`turboism-<version>-full.zip`）はすべてのファーストパーティープラグインを含み、Thin（`TurboismInstaller-<version>-thin.exe`、`turboism-<version>-thin.zip`）はランタイムのみでした。この構成は廃止されています。Thin 環境に現在のインストーラーを実行すると、既存の `disabledPlugins` を維持したまま同梱プラグインが導入されます。
- **0.44.0 以前**は従来の構成でした。Full/Lite のモード選択画面と個別プラグインのチェックボックスを持つ単一の Windows インストーラー `TurboismInstaller-<version>.exe`、クロスプラットフォームの IzPack Java インストーラー `TurboismInstaller-<version>.jar`（Java 17 以降が必要）、ポータブルアーカイブ `turboism-<version>-full.zip` と `turboism-<version>-lite.zip` です。

Java インストーラーは現在公開されていません。macOS と Linux ではポータブル ZIP を使用します。
