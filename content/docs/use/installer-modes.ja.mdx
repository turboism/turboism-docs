title: インストーラーモード

Turboism のインストーラーとポータブルアーカイブは、同じランタイムを異なるプラグイン選択とともに配布します。モードが選択するのはファイルであり、Cubism のインストールを変更することはありません。

## モード

- **Full** — agent と、レビュー済みのファーストパーティプラグインバンドル。インストーラーは承認済みのリリースプラグインをすべて事前選択し、個々のプラグインを選択解除できます。
- **Thin** — 同じ承認済みプラグイン構成から、追加のマネージドネイティブランタイムペイロードを除いたもの。Java インストーラーで利用でき、明示的なカスタム実行ファイルパスも受け付けます。
- **Lite** — agent と common file のみ。ファーストパーティの plugin JAR はコピーされません。

Windows の `.exe` インストーラーは **Full** と **Lite** を提供します。クロスプラットフォームの `.jar` インストーラーは **Full**、**Thin**、**Lite** を提供します。ポータブルアーカイブは同じ payload の `full` と `lite` バリアントとして配布されます。

## オプションのマネージド GraalVM

インストーラーは、オプションのマネージド GraalVM コンポーネントを提供します。

- GraalVM 公式 GitHub リリースから固定されたアーカイブをダウンロードし、使用前に検証します。
- 選択しないままでも、プラグインバンドルにとってインストールは有効かつ完全なままです。
- 後から Turboism の設定でインストールできます。

開発専用の `Turboism with fx` plugin とそのマネージドランタイムバイトは、どのリリースパッケージにも含まれません。

## モードが変更しないもの

- ランタイム home、設定、ログ、プラグインデータはどのモードでも同じです。
- インストーラーを再実行すると、同じ home に異なる選択が適用され、管理対象のプラグイン状態だけが変わります。
- 不明なファイルとサードパーティの plugin JAR は、モード変更によって削除されることはありません。
- モード名は、使用中の Cubism バージョンでプラグイン機能が利用できることを保証しません。利用可否は capability とバージョンに依存します。

## 選択前に

1. `config.json` と、重要な plugin の `config/`・`data/` の内容を backup します。
2. インストーラーの再実行とリリースチャンネルの仕組みは[更新ポリシー](./update-policy)を確認してください。
3. 変更が想定どおりに動作しない場合は[ダウングレードと復旧](./downgrade-recovery)を使用してください。
