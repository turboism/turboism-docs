title: アンインストール
description: Turboism をインストーラーで削除し、個人設定を保持するか選択する。

これは公開待ちの候補ガイドです。使用中の Preview build をインストールしたインストーラーに付属するアンインストーラーを使用してください。Turboism または host application が実行中の間は file を削除しないでください。

## インストーラーのアンインストーラーを使う

1. Turboism と host application を通常どおり終了します。
2. インストーラーが登録した uninstall entry を開くか、そのインストールに付属する生成済みアンインストーラーを使用します。
3. アンインストーラーの確認手順に従います。
4. 表示されたら、configuration を保持するか選択します。再インストールする可能性がある、または同じ preference が後で必要なら保持します。不要であり重要な内容を保存済みの場合にだけ削除してください。
5. 完了後、削除したインストールを通じて application が起動しなくなったことを確認します。

## 保持されるもの

アンインストーラーは自らが所有する file を削除します。安全に特定できない material を破壊しないため、不明な file と third-party plugin JAR は保持されます。configuration の保持も、自動削除ではなく意図的な選択です。

保持された material を削除したい場合は、アンインストール後に自分で確認し、後で必要になるものを backup してください。無関係な host file や project を削除する手段としてアンインストールを使わないでください。

## アンインストール前後

インストールを置き換える前に[更新ポリシー](./update-policy)を読んでください。更新またはモード変更に失敗した場合は、以前の build を安全に復元できると仮定せず、まず[ダウングレードと復旧](./downgrade-recovery)を確認します。
