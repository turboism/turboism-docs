title: 설치
description: Cubism 설치를 수정하지 않고 공개된 릴리스 패키지에서 Turboism을 설치합니다.
---

Turboism은 [GitHub Releases](https://github.com/turboism/Turboism/releases)와 [turboism.dev/download](https://turboism.dev/download)의 공식 다운로드 미러를 통해 배포됩니다. 모든 패키지에는 일치하는 `.sha256` 체크섬 파일이 함께 제공됩니다. 소스에서 Turboism을 빌드하는 것은 개발자와 유지 관리자의 작업이며 일반적인 사용에는 필요하지 않습니다.

어떤 패키지도 Cubism JAR, DLL, 라이선스 상태 또는 기존 프로젝트를 수정하지 않습니다. Cubism 공식 시작 BAT 파일은 Windows 설치 프로그램의 공식 BAT 통합 옵션을 통해서만 변경되며, 이 옵션은 기본 선택되어 있고 해시로 보호되며 제거 시 복원됩니다.

설치 프로그램에는 현재 서명이 없습니다. 실행하기 전에 다운로드한 파일을 체크섬과 비교해 검증하세요.

## 패키지 선택

**0.67.0** 안정판부터 Turboism은 정확히 두 가지 제품 다운로드를 제공합니다:

| 패키지 | 플랫폼 | 용도 |
| --- | --- | --- |
| `TurboismInstaller-<version>.exe` | Windows | 안내 방식 NSIS 설치 프로그램. Windows에서 권장. |
| `turboism-<version>.zip` | Windows(수동 설정), macOS, Linux | 수동 설정용 포터블 아카이브. |

두 패키지 모두 런타임, 모든 기본 제공 퍼스트 파티 플러그인, 완전한 오프라인 GraalJS 엔진을 포함합니다. GraalVM 런타임 설치는 여전히 별도의 선택 단계입니다. 비교와 설치 프로그램 옵션은 [설치 프로그램과 포터블 ZIP](./installer-modes)을 참고하세요.

0.67.0 베타 릴리스(0.67.0-beta.3 ~ 0.67.0-beta.7)는 일시적으로 Full/Thin 네 가지 다운로드 구성을 사용했으며, 이 구성은 폐지되었습니다. 0.44.0 이하 릴리스에서는 기존 레거시 자산(단일 Windows 설치 프로그램 `TurboismInstaller-<version>.exe`, Java 설치 프로그램 `TurboismInstaller-<version>.jar`, 포터블 아카이브 `turboism-<version>-full.zip` 및 `turboism-<version>-lite.zip`)을 사용했습니다. Java 설치 프로그램은 더 이상 게시되지 않으며 macOS와 Linux에서는 포터블 ZIP을 사용합니다.

모든 형식은 같은 릴리스 버전을 가집니다. 빌드를 제공한 채널을 사용하세요: [릴리스 채널](./update-policy)과 `api.turboism.dev`의 세 가지 JSON 피드를 참고하세요.

## 지원 환경

- **Windows x64**가 지원되는 Cubism 호스트 플랫폼입니다.
- 현재 안정판 **0.67.4**는 **5.0.00부터 5.3.04**까지 검토된 Cubism Editor 20개 버전 전체를 지원합니다([호환성](/docs/use/compatibility) 참고). 목록에 없는 Editor 버전은 호환성을 주장하지 않으며, 사용할 수 없는 어댑터나 기능은 안전하게 실패합니다.
- Editor 버전이 지원된다고 해서 모든 플러그인 기능을 그 버전에서 사용할 수 있는 것은 아닙니다.
- macOS 패키징은 미리 보기 전용입니다. macOS Cubism 호스트 지원은 검증되지 않았고 macOS 런처는 설치되지 않습니다.
- Linux 지원 범위는 설치 프로그램과 런타임 파일 배포 동작으로 제한되며, Linux는 지원되는 Cubism 호스트가 아닙니다.

## 설치 프로그램 언어

모든 Turboism 설치 프로그램은 **영어, 중국어 간체, 일본어 및 한국어**로 제공됩니다.

- EXE 마법사는 환영 페이지 전에 언어 선택 창을 표시하며 호스트 언어와 관계없이 모든 언어를 나열합니다.
- 설치 프로그램 언어는 설치 프로그램 자체의 인터페이스에만 적용되며 `config.json`에 기록되지 않습니다.
- Turboism이 실행 시 사용하는 언어는 `config.json`의 `locale` 설정으로 결정되며, 플러그인 인터페이스 언어는 Cubism Editor의 **File → Environment Settings → General → Language**를 따릅니다.

## 기본 제공 플러그인

모든 패키지는 기본 제공 퍼스트 파티 플러그인을 전부 설치하며, 모드 선택이나 개별 플러그인 선택 페이지는 없습니다. 플러그인은 나중에 Cubism의 **Turboism → 플러그인 관리…**에서 사용 여부를 변경할 수 있으며, 추가 플러그인은 Cubism 내 플러그인 마켓(**Turboism** 메뉴 → **플러그인 마켓…**) 또는 [turboism.dev/plugins](https://turboism.dev/plugins)에서 설치할 수 있습니다.

서명 검증된 퍼스트 파티 플러그인은 백그라운드에서 자동 업데이트됩니다. 핫 리로드(hot-reload)로 표시된 플러그인은 즉시 적용되며 기타 업데이트는 Cubism 재시작 후 적용됩니다. 사용자는 설정에서 공식 플러그인 자동 업데이트를 끌 수 있습니다.

개발 전용 Turboism with fx 플러그인과 관리형 fx 런타임 바이트는 어떤 릴리스 패키지에도 포함되지 않습니다.

## 필수 확인 항목

설치 프로그램은 네 가지 명시적 확인 항목과 전체 현지화된 런타임 선언을 거쳐야 설치를 진행합니다. 확인 항목은 Turboism의 독립적인 서드파티 정체성, 적법한 Cubism 라이선스, 허가된 콘텐츠 변경 자동화 전의 독립적인 백업, 그리고 호환성이나 복구 보장이 없는 오픈 소스 있는 그대로의 동작을 다룹니다.

## Windows `.exe` 설치 프로그램

`TurboismInstaller-<version>.exe`를 실행하세요. Windows에서 권장되는 방식입니다:

- 사용자 단위로 실행됩니다. UAC로 권한을 상승하는 것은 Cubism 공식 BAT 통합 단계뿐입니다.
- 기본적으로 `%LOCALAPPDATA%\Turboism`에 설치하며 다른 디렉터리를 선택할 수 있습니다.
- 선택적 Turboism 관리형 GraalVM 런타임 다운로드(지금 설치 또는 나중에 설치)를 제공합니다.
- 설치된 Cubism Editor를 검색하고 다른 설치 폴더를 가져올 수 있습니다. 찾지 못해도 Turboism은 설치되며 나중에 구성할 수 있습니다.
- 시작 메뉴 바로 가기, 바탕 화면 바로 가기, Cubism 공식 BAT 통합을 선택할 수 있습니다. BAT 통합은 기본 선택되어 있고 해제할 수 있으며, 해시로 보호되고 멱등적이며 제거 시 복원됩니다.
- 현재 사용자의 프로그램 및 기능에 제거 항목을 등록합니다.
- 기존 설치를 업그레이드합니다. 새 설치 프로그램을 다시 실행하면 현재 퍼스트 파티 플러그인을 설치하고 기존 `disabledPlugins` 설정을 유지합니다.
- 나중에 제거할 수 있도록 `uninstall.exe`를 기록합니다.
- Cubism JAR, DLL 또는 라이선스 상태를 수정하지 않습니다.

## 포터블 ZIP 패키지

Windows(수동 설정), macOS 및 Linux의 경우:

1. 런타임과 모든 기본 제공 퍼스트 파티 플러그인이 포함된 `turboism-<version>.zip`을 다운로드하세요.
2. **압축 파일 전체**를 별도의 Turboism 폴더에 풀어 주세요. Cubism 설치 디렉터리에는 절대 풀지 마세요.
3. Windows의 경우 압축을 푼 폴더에서 설정 도구를 실행하세요:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File ".\configure_turboism.ps1"
   ```

   실행 정책 옵션은 해당 PowerShell 프로세스에만 적용됩니다. 사용할 Cubism 설치 경로와 플러그인을 선택한 뒤 저장하세요.
4. 생성된 Turboism 바로 가기 또는 해당 폴더의 `launch-cubism-turboism.bat`으로 Cubism을 실행하세요.

ZIP 수동 설정에는 제거 프로그램이 없으며 공식 BAT 통합도 활성화되지 않습니다. 제거하려면 Cubism을 종료하고 Turboism 폴더를 삭제하세요.

## 다운로드 검증

각 패키지에는 같은 파일 이름에 `.sha256`이 붙은 체크섬 파일이 함께 제공됩니다. 예를 들어 PowerShell에서는 다음과 같습니다:

```powershell
Get-FileHash ".\TurboismInstaller-<version>.exe" -Algorithm SHA256
```

결과를 공개된 값과 비교하세요. SHA-256 체크섬은 파일 무결성을 증명하지만 코드 서명 인증서는 아닙니다.

## 설치 후

1. Windows의 경우 Turboism home의 `configure_turboism.ps1`(또는 시작 메뉴의 **Turboism_Configurator**)로 Cubism 설치를 추가하거나 변경하세요. 선택한 루트마다 하나의 관리형 시작 항목이 생성됩니다. 0개를 선택하고 저장해도 유효한 프레임워크 단독 설치가 유지됩니다.
2. 해제하지 않았다면 Windows 설치 프로그램이 Cubism 공식 BAT 통합을 적용합니다. 해시 검증 백업을 기록하며, 이후 사용자가 해당 파일을 편집하면 충돌로 처리되고 재시도를 위해 상태가 보존됩니다. ZIP 수동 설치에서는 활성화되지 않습니다.
3. Turboism 바로 가기, BAT 통합이 적용된 경우 기존 Cubism 바로 가기, 또는 선택한 Cubism 루트의 관리형 런처(Windows의 경우 `launch-cubism-turboism.bat`)로 실행하세요.
4. Turboism이 정상적으로 시작되고 Turboism home에 진단 로그가 기록되는지 확인하세요.
5. Cubism 실행 후 상단 **Turboism** 메뉴에서 **플러그인 마켓…**, **플러그인 관리…**, **플러그인 설정…**, **업데이트 확인** 등의 기능을 사용할 수 있습니다.

## 제거

- **`.exe` 설치 프로그램으로 설치한 경우**: Turboism home 디렉터리의 `uninstall.exe`를 실행하세요. Turboism이 기록한 관리형 바로 가기, 상태 및 파일만 정리합니다. 제거 확인 창에서 `config.json` 유지 여부를 선택할 수 있습니다(기본값: 유지). 설치 프로그램이 배포한 퍼스트 파티 플러그인 JAR만 삭제하며, 알 수 없는 파일이나 서드파티 플러그인 JAR은 보존합니다. 적용된 공식 BAT 통합은 해시로 보호된 백업에서 복원됩니다.
- **ZIP 수동 설치**: Cubism을 종료하고 Turboism 폴더를 삭제하세요.
- **0.44.0 이하의 기존 설치**: 폐지된 Java 설치 프로그램으로 생성된 설치본은 Windows/Linux에서 `java -jar <home>\Uninstaller\uninstaller.jar`를, macOS에서 `uninstall.command`를 실행했습니다.

## 현재 제한 사항

- 설치 패키지는 코드 서명되거나 공증되지 않았습니다.
- macOS의 Cubism 호스트 지원은 검증되지 않았으며 macOS 런처는 제공되지 않습니다.
- 프레임워크 설치 프로그램 자체의 자동 업데이트는 없습니다. Turboism은 업데이트를 확인하고 알림을 제공하지만, 프레임워크 업데이트는 최신 설치 프로그램을 실행하거나 최신 ZIP 압축을 풀어야 합니다.
- 기능 가용성은 기능 및 버전별로 다릅니다.
