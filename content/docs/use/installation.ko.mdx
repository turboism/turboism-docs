---
title: 설치
description: Cubism 설치를 수정하지 않고 공개된 릴리스 패키지에서 Turboism을 설치합니다.
---

Turboism은 [GitHub Releases](https://github.com/turboism/Turboism/releases)와 [turboism.dev/download](https://turboism.dev/download)의 공식 다운로드 미러를 통해 배포됩니다. 모든 패키지에는 일치하는 `.sha256` 체크섬 파일이 함께 제공됩니다. 소스에서 Turboism을 빌드하는 것은 개발자와 유지 관리자의 작업이며 일반적인 사용에는 필요하지 않습니다.

어떤 패키지도 Cubism JAR, DLL, 공식 런처 파일, 라이선스 상태 또는 기존 프로젝트를 수정하지 않습니다.

설치 프로그램에는 현재 서명이 없습니다. 실행하기 전에 다운로드한 파일을 체크섬과 비교해 검증하세요.

## 패키지 선택

**0.67.0-beta.3**부터 Turboism은 두 가지 변형으로 나뉜 네 가지 정식 릴리스 자산을 제공합니다:

| 패키지 | 플랫폼 | 용도 |
| --- | --- | --- |
| `TurboismInstaller-<version>-full.exe` | Windows | Full 안내 방식 NSIS 설치 프로그램. 런타임 프레임워크와 모든 기본 제공 퍼스트 파티 플러그인 포함. |
| `TurboismInstaller-<version>-thin.exe` | Windows | Thin 안내 방식 NSIS 설치 프로그램. 런타임 프레임워크 전용(플러그인 없음). |
| `turboism-<version>-full.zip` | Windows, macOS, Linux(수동) | Full 포터블 아카이브. 런타임과 모든 기본 제공 퍼스트 파티 플러그인 포함. |
| `turboism-<version>-thin.zip` | Windows, macOS, Linux(수동) | Thin 포터블 아카이브. 런타임 프레임워크 전용(플러그인 없음). |

**0.67.0-beta.3** 이전 릴리스에서는 기존 레거시 자산(단일 Windows 설치 프로그램 `TurboismInstaller-<version>.exe`, Java 설치 프로그램 `TurboismInstaller-<version>.jar`, 포터블 아카이브 `turboism-<version>-full.zip` 및 `turboism-<version>-lite.zip`)을 사용했습니다. Java 설치 프로그램 JAR은 폐지되었으며 macOS와 Linux에서는 포터블 ZIP 패키지를 사용합니다.

네 가지 형식 모두 같은 릴리스 버전을 가집니다. 빌드를 제공한 채널을 사용하세요: [릴리스 채널](./update-policy)과 `api.turboism.dev`의 세 가지 JSON 피드를 참고하세요.

## 지원 환경

- **Windows x64**가 지원되는 Cubism 호스트 플랫폼입니다.
- 지원되는 Cubism Editor 버전은 Turboism 릴리스에 따라 다릅니다. Stable **0.44.0**은 **5.2.03**, **5.3.02**, **5.3.03**을 지원하며, Beta **0.67.0-beta.1**은 **5.0.00부터 5.3.04**까지의 검토된 20개 버전 전체를 지원합니다([호환성](/docs/use/compatibility) 참고). 목록에 없는 Editor 버전은 호환성을 주장하지 않으며, 사용할 수 없는 어댑터나 기능은 안전하게 실패합니다.
- Editor 버전이 지원된다고 해서 모든 플러그인 기능을 그 버전에서 사용할 수 있는 것은 아닙니다.
- macOS 패키징은 미리 보기 전용입니다. macOS Cubism 호스트 지원은 검증되지 않았고 macOS 런처는 설치되지 않습니다.
- Linux 지원 범위는 설치 프로그램과 런타임 파일 배포 동작으로 제한되며, Linux는 지원되는 Cubism 호스트가 아닙니다.

## 설치 프로그램 언어

모든 Turboism 설치 프로그램은 **영어, 중국어 간체, 일본어 및 한국어**로 제공됩니다.

- EXE 마법사는 환영 페이지 전에 언어 선택 창을 표시하며 호스트 언어와 관계없이 모든 언어를 나열합니다.
- 설치 프로그램 언어는 설치 프로그램 자체의 인터페이스에만 적용되며 `config.json`에 기록되지 않습니다.
- Turboism이 실행 시 사용하는 언어는 `config.json`의 `locale` 설정으로 결정되며, 플러그인 인터페이스 언어는 Cubism Editor의 **File → Environment Settings → General → Language**를 따릅니다.

## 설치 변형(Full 및 Thin)

Turboism은 편의성과 경량성을 위해 두 가지 변형을 제공합니다:

- **Full**(`-full.exe`, `-full.zip`) — 런타임 프레임워크와 모든 기본 제공 퍼스트 파티 플러그인.
- **Thin**(`-thin.exe`, `-thin.zip`) — 런타임 프레임워크만 포함되며 플러그인은 포함되지 않음. 플러그인은 나중에 Cubism 내 플러그인 마켓(**Turboism** 메뉴 → **플러그인 마켓…**) 또는 [turboism.dev/plugins](https://turboism.dev/plugins)에서 설치합니다.

설치 마법사에는 더 이상 모드 선택이나 개별 플러그인 선택 페이지가 없습니다. Full 설치 프로그램은 개별 선택 없이 모든 퍼스트 파티 플러그인을 설치하며, Thin 설치 프로그램은 플러그인을 설치하지 않습니다. 플러그인은 Cubism 실행 후 **Turboism → 플러그인 관리…**에서 언제든지 사용 여부를 변경할 수 있습니다.

서명 검증된 퍼스트 파티 플러그인은 백그라운드에서 자동 업데이트됩니다. 핫 리로드(hot-reload)로 표시된 플러그인은 즉시 적용되며 기타 업데이트는 Cubism 재시작 후 적용됩니다. 사용자는 설정에서 공식 플러그인 자동 업데이트를 끌 수 있습니다.

개발 전용 Turboism with fx 플러그인과 관리형 fx 런타임 바이트는 어떤 릴리스 패키지에도 포함되지 않습니다. 자세한 내용은 [Full 및 Thin 변형](./installer-modes)을 참고하세요.

## 필수 확인 항목

설치 프로그램은 네 가지 명시적 확인 항목과 전체 현지화된 런타임 선언을 거쳐야 설치를 진행합니다. 확인 항목은 Turboism의 독립적인 서드파티 정체성, 적법한 Cubism 라이선스, 허가된 콘텐츠 변경 자동화 전의 독립적인 백업, 그리고 호환성이나 복구 보장이 없는 오픈 소스 있는 그대로의 동작을 다룹니다.

## Windows `.exe` 설치 프로그램

`TurboismInstaller-<version>-full.exe`(Full) 또는 `TurboismInstaller-<version>-thin.exe`(Thin)를 실행하세요. Windows에서 권장되는 방식입니다:

- 사용자 단위로 실행되며 관리자 권한 상승을 요청하지 않습니다.
- 기본적으로 `%LOCALAPPDATA%\Turboism`에 설치하며 다른 디렉터리를 선택할 수 있습니다.
- 사용자 단위 시작 메뉴 항목을 추가하고 현재 사용자의 프로그램 및 기능에 제거 항목을 등록합니다.
- 안전한 업그레이드: Full 설치 환경에 Thin을 덮어써도 기존 `plugins/` 디렉터리는 유지되며, Thin 설치 환경에 Full을 덮어쓰면 기존 `disabledPlugins` 설정을 유지하면서 모든 퍼스트 파티 플러그인을 설치하거나 업데이트합니다.
- 설치 후 `configure_turboism.ps1`을 열어 Cubism 루트와 관리형 실행 항목을 구성할 수 있습니다.
- 나중에 제거할 수 있도록 `uninstall.exe`를 기록합니다.
- Cubism 설치 파일을 수정하지 않습니다.

## 포터블 ZIP 패키지

Windows(수동 설정), macOS 및 Linux의 경우:

1. 기본 제공 플러그인이 필요하면 `turboism-<version>-full.zip`을, 플러그인 없는 런타임만 필요하면 `turboism-<version>-thin.zip`을 선택하세요.
2. **압축 파일 전체**를 별도의 Turboism 폴더에 풀어 주세요. Cubism 설치 디렉터리에는 절대 풀지 마세요.
3. Windows의 경우 압축을 푼 폴더에서 설정 도구를 실행하세요:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File ".\configure_turboism.ps1"
   ```

   실행 정책 옵션은 해당 PowerShell 프로세스에만 적용됩니다. 사용할 Cubism 설치 경로와 플러그인을 선택한 뒤 저장하세요.
4. 생성된 Turboism 바로 가기 또는 해당 폴더의 `launch-cubism-turboism.bat`으로 Cubism을 실행하세요.

ZIP 수동 설정에는 제거 프로그램이 없으며 공식 BAT 통합도 활성화되지 않습니다. 제거하려면 Cubism을 종료하고 Turboism 폴더를 삭제하세요.

## 다운로드 검증

각 패키지에는 같은 파일 이름에 `.sha256`이 붙은 체크섬 파일이 함께 제공됩니다. 예를 들어 PowerShell에서는 다음과 같습니다:

```powershell
Get-FileHash ".\TurboismInstaller-<version>-full.exe" -Algorithm SHA256
```

결과를 공개된 값과 비교하세요. SHA-256 체크섬은 파일 무결성을 증명하지만 코드 서명 인증서는 아닙니다.

## 설치 후

1. Windows의 경우 Turboism home에서 `configure_turboism.ps1`을 실행하세요. 해당 릴리스가 정확히 지원하는 Cubism Editor 설치 경로만 표시되며 선택한 루트마다 하나의 관리형 시작 항목이 생성됩니다. 0개를 선택하고 저장해도 유효한 프레임워크 단독 설치가 유지됩니다.
2. 선택 사항으로 공식 Cubism 시작 BAT와의 통합을 활성화할 수 있습니다. 해시 검증 백업을 기록하며 임의로 적용되지 않습니다.
3. 선택한 Cubism 루트의 관리형 런처(Windows의 경우 `launch-cubism-turboism.bat`)로 실행하세요.
4. Turboism이 정상적으로 시작되고 Turboism home에 진단 로그가 기록되는지 확인하세요.
5. Cubism 실행 후 상단 **Turboism** 메뉴에서 **플러그인 마켓…**, **플러그인 관리…**, **플러그인 설정…**, **업데이트 확인** 등의 기능을 사용할 수 있습니다.

## 제거

- **`.exe` 설치 프로그램으로 설치한 경우**: Turboism home 디렉터리의 `uninstall.exe`를 실행하세요. Turboism이 기록한 관리형 바로 가기, 상태 및 파일만 정리합니다. 제거 확인 창에서 `config.json` 유지 여부를 선택할 수 있습니다(기본값: 유지). Full 제거 프로그램은 설치 프로그램이 배포한 퍼스트 파티 플러그인 JAR만 삭제하며, 알 수 없는 파일이나 서드파티 플러그인 JAR은 보존합니다. Thin 설치 프로그램은 플러그인을 삭제하지 않습니다.
- **ZIP 수동 설치**: Cubism을 종료하고 Turboism 폴더를 삭제하세요.
- **0.67.0-beta.3 이전의 기존 설치**: 폐지된 Java 설치 프로그램으로 생성된 설치본은 Windows/Linux에서 `java -jar <home>\Uninstaller\uninstaller.jar`를, macOS에서 `uninstall.command`를 실행했습니다.

## 현재 제한 사항

- 설치 패키지는 코드 서명되거나 공증되지 않았습니다.
- macOS의 Cubism 호스트 지원은 검증되지 않았으며 macOS 런처는 제공되지 않습니다.
- 프레임워크 설치 프로그램 자체의 자동 업데이트는 없습니다. Turboism은 업데이트를 확인하고 알림을 제공하지만, 프레임워크 업데이트는 최신 설치 프로그램을 실행하거나 최신 ZIP 압축을 풀어야 합니다.
- 기능 가용성은 기능 및 버전별로 다릅니다.
