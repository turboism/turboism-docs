---
title: 설치
description: Cubism 설치를 수정하지 않고 공개된 릴리스 패키지에서 Turboism을 설치합니다.
---

Turboism은 [GitHub Releases](https://github.com/turboism/Turboism/releases)와 [turboism.dev/download](https://turboism.dev/download)의 공식 다운로드 미러를 통해 배포됩니다. 모든 패키지에는 일치하는 `.sha256` 체크섬 파일이 함께 제공됩니다. 소스에서 Turboism을 빌드하는 것은 개발자와 유지 관리자의 작업이며 일반적인 사용에는 필요하지 않습니다.

어떤 패키지도 Cubism JAR, DLL, 공식 런처 파일, 라이선스 상태 또는 기존 프로젝트를 수정하지 않습니다.

설치 프로그램에는 현재 서명이 없습니다. 실행하기 전에 다운로드한 파일을 체크섬과 비교해 검증하세요.

## 패키지 선택

| 패키지 | 플랫폼 | 용도 |
| --- | --- | --- |
| `TurboismInstaller-<version>.exe` | Windows | 안내 방식 NSIS 설치 프로그램. Windows에서 권장됩니다. |
| `TurboismInstaller-<version>.jar` | Windows, macOS, Linux | 안내 방식 IzPack 설치 프로그램. Java 17 이상이 필요합니다. |
| `turboism-<version>-full.zip` | 수동 설정 | 런타임과 검토된 기본 제공 플러그인 번들. |
| `turboism-<version>-lite.zip` | 수동 설정 | 런타임만 제공. 직접 만든 플러그인 JAR을 추가하세요. |

네 가지 형식 모두 같은 릴리스 버전을 가집니다. 빌드를 제공한 채널을 사용하세요: [릴리스 채널](./update-policy)과 `api.turboism.dev`의 세 가지 JSON 피드를 참고하세요.

## 지원 환경

- **Windows x64**가 지원되는 Cubism 호스트 플랫폼입니다.
- 지원되는 Cubism Editor 버전은 **5.2.03**, **5.3.02**, **5.3.03**이며 각각 정확한 버전의 어댑터를 가집니다. 목록에 없는 Editor 버전은 호환성을 주장하지 않으며, 사용할 수 없는 어댑터나 기능은 안전하게 실패합니다.
- Editor 버전이 지원된다고 해서 모든 플러그인 기능을 그 버전에서 사용할 수 있는 것은 아닙니다.
- macOS 패키징은 미리 보기 전용입니다. 설치 프로그램이 설치와 제거를 수행할 수 있지만 macOS Cubism 호스트 지원은 검증되지 않았고 macOS 런처는 설치되지 않습니다.
- Linux 지원 범위는 설치 프로그램과 페이로드 동작으로 제한되며, Linux는 지원되는 Cubism 호스트가 아닙니다.

## 설치 프로그램 언어

모든 Turboism 설치 프로그램은 **영어, 중국어 간체, 일본어 및 한국어**로 제공됩니다.

- EXE 마법사는 환영 페이지 전에 언어 선택 단계를 표시하며 호스트 언어와 관계없이 모든 언어를 계속 나열합니다.
- JAR 마법사는 언어 선택 대화 상자로 시작합니다. `-language eng|chn|jpn|kor`를 전달하면 언어를 미리 선택하고 이 대화 상자를 건너뜁니다.
- 설치 프로그램 언어는 설치 프로그램 범위에만 적용되며 `config.json`에 기록되지 않습니다. Turboism이 실행 시 사용하는 언어는 런타임 `locale` 설정에서 결정되며, 플러그인 인터페이스 언어는 Cubism Editor의 **File → Environment Settings → General → Language**를 따릅니다.

## 설치 모드

설치 프로그램은 세 가지 플러그인 선택을 제공합니다. ZIP 패키지는 같은 페이로드의 이식 가능한 `full` 및 `lite` 변형으로 제공됩니다:

- **Full** — 에이전트와 검토된 기본 제공 플러그인 번들. 설치 프로그램에서 개별 플러그인을 선택 해제할 수 있습니다.
- **Thin** — 추가 관리형 네이티브 런타임 페이로드가 없는 동일한 플러그인 목록. Thin은 명시적인 사용자 지정 실행 파일 경로도 허용합니다.
- **Lite** — 에이전트와 공통 파일만 제공하며 기본 제공 플러그인 JAR이 없습니다.

개발 전용 Turboism with fx 플러그인과 관리형 fx 런타임 바이트는 어떤 릴리스 패키지에도 포함되지 않습니다. 자세한 내용은 [설치 프로그램 모드](./installer-modes)를 참고하세요.

## 필수 확인 항목

두 설치 프로그램 모두 네 가지 명시적 확인 항목과 전체 현지화된 런타임 선언을 통과해야 설치를 진행합니다. 확인 항목은 Turboism의 독립적인 서드파티 정체성, 적법한 Cubism 라이선스, 허가된 콘텐츠 변경 자동화 전의 독립적인 백업, 그리고 호환성이나 복구 보장이 없는 오픈 소스 있는 그대로의 동작을 다룹니다. 이 게이트는 그래픽, 콘솔 및 자동화 모드에서 동일하게 동작합니다.

## Windows `.exe` 설치 프로그램

`TurboismInstaller-<version>.exe`는 Windows 네이티브 NSIS 설치 프로그램이며 Windows에서 권장되는 방식입니다.

- 사용자 단위로 실행되며 관리자 권한 상승을 요청하지 않습니다.
- 기본적으로 `%LOCALAPPDATA%\Turboism`에 설치하며 다른 디렉터리를 선택할 수 있습니다.
- 사용자 단위 시작 메뉴 항목을 추가하고 현재 사용자의 프로그램 및 기능에 제거 항목을 등록합니다.
- 설치 후 `configure_turboism.ps1`을 열어 Cubism 루트와 관리형 실행 항목을 구성할 수 있게 합니다.
- 나중에 제거할 수 있도록 `uninstall.exe`를 기록합니다.
- Cubism 설치 파일을 수정하지 않습니다.

## 크로스 플랫폼 `.jar` 설치 프로그램

`TurboismInstaller-<version>.jar`는 IzPack 기반 설치 프로그램입니다. Java 17 이상이 필요합니다:

```bash
java -jar TurboismInstaller-<version>.jar
```

- 기본 설치 위치: Windows는 `%LOCALAPPDATA%\Turboism`, macOS는 `~/Library/Application Support/Turboism`, Linux는 `${XDG_DATA_HOME:-~/.local/share}/Turboism`이며 다른 디렉터리를 선택할 수 있습니다.
- 설치 프로그램을 다시 실행하면 관련 없는 구성을 덮어쓰지 않고 같은 Turboism home과 플러그인 선택을 업데이트합니다.
- 제거를 위해 Turboism home 아래에 `Uninstaller/uninstaller.jar`를 생성합니다.

macOS 또는 Linux에 파일을 설치할 수 있다고 해서 해당 플랫폼에서 Cubism 호스트 호환성이 보장되는 것은 아닙니다.

## ZIP 패키지

1. 압축 파일 전체를 별도의 Turboism 폴더에 풀어 주세요. Cubism 설치 디렉터리에는 절대 풀지 마세요.
2. 압축을 푼 폴더에서 설정 도구를 실행하세요:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File ".\configure_turboism.ps1"
   ```

   실행 정책 옵션은 해당 PowerShell 프로세스에만 적용됩니다.
3. 사용할 Cubism 설치와 플러그인을 선택한 뒤 저장하세요.
4. 생성된 Turboism 바로 가기 또는 해당 폴더의 `launch-cubism-turboism.bat`으로 Cubism을 실행하세요.

## 다운로드 검증

각 패키지에는 같은 파일 이름에 `.sha256`이 붙은 체크섬 파일이 함께 제공됩니다. 예를 들어 PowerShell에서는 다음과 같습니다:

```powershell
Get-FileHash ".\TurboismInstaller-<version>.exe" -Algorithm SHA256
```

결과를 공개된 값과 비교하세요. SHA-256 체크섬은 파일 무결성을 증명하지만 코드 서명 인증서는 아닙니다.

## 설치 후

1. Windows에서는 Turboism home의 `configure_turboism.ps1`을 실행하세요. 이 스크립트는 정확히 지원되는 Cubism Editor 5.2.03, 5.3.02 및 5.3.03 설치만 나열하고 선택한 루트마다 관리형 실행 항목을 하나씩 만듭니다. 설정 도구를 취소하면 유효한 프레임워크 전용 설치가 남습니다.
2. 선택한 설치에 대해 공식 Cubism 시작 BAT와의 통합을 선택적으로 사용할 수 있습니다. 이 통합은 해시로 보호되는 백업을 기록하며 암묵적으로 적용되지 않습니다. 이후 사용자가 해당 파일을 편집하면 충돌이 되고 재시도를 위해 상태가 보존됩니다.
3. Cubism 루트에 맞는 관리형 런처(Windows에서는 `launch-cubism-turboism.bat`)를 통해 Turboism을 시작하세요.
4. Turboism이 시작되고 Turboism home에 진단을 기록하는지 확인하세요.
5. [플러그인 관리](./plugin-management)를 통해 추가 플러그인을 설치하세요. 이 과정은 JAR을 스테이징하고 Cubism 재시작 후에 적용합니다.

## 제거

- `.exe` 설치 프로그램으로 만든 Windows 설치: Turboism home 디렉터리의 `uninstall.exe`를 실행하세요. 확인 대화 상자에서 `config.json`을 유지할지 묻습니다.
- `.jar` 설치 프로그램으로 만든 Windows 설치: 다음을 실행하세요.

  ```text
  java -jar <home>\Uninstaller\uninstaller.jar
  ```

- `.jar` 설치 프로그램으로 만든 macOS 설치: home 디렉터리의 `uninstall.command`를 두 번 클릭하거나 터미널에서 실행하세요.

제거 프로그램은 설치 프로그램이 소유한 파일과 런타임 `logs`, `state`, `cache` 데이터를 삭제합니다. Java 제거 프로그램은 NSIS 제거 프로그램과 동일하게 기본적으로 `config.json`을 유지합니다. 알 수 없는 파일과 서드파티 플러그인 JAR은 보존됩니다.

## 현재 제한 사항

- 설치 프로그램 패키지에는 서명이나 공증이 없습니다.
- macOS Cubism 호스트 지원은 검증되지 않았으며 macOS 런처는 설치되지 않습니다.
- 설치 프로그램 자동 업데이트는 없습니다. Turboism은 안정 채널 업데이트를 확인하고 알려 주지만, 업데이트는 더 새로운 설치 프로그램을 다시 실행하는 것입니다.
- 실패한 플러그인 교체는 내부 백업/복원으로 보호되지만, 완전한 사용자 대상 복구 또는 기록 UI는 아직 없습니다.
- 기능 준비 상태는 기능과 버전에 따라 다릅니다.
