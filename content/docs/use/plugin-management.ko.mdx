description: Turboism 플러그인을 안전하게 찾고, 구성하고, 사용 설정하거나 해제하고 관리합니다.
---

Turboism은 플러그인을 관리하기 위한 상호 보완적인 여러 방법을 제공합니다:

- **Cubism 내 플러그인 마켓**(**Turboism** 메뉴 → **플러그인 마켓…**) 또는 [turboism.dev/plugins](https://turboism.dev/plugins): 퍼스트 파티 및 카탈로그 플러그인 탐색 및 설치;
- 검증된 퍼스트 파티 플러그인을 위한 **백그라운드 자동 업데이트**;
- **플러그인 관리…**: 플러그인 사용 설정/해제, 제거 또는 로컬 JAR 스테이징;
- 전용 2열 창의 **플러그인 설정…**: 플러그인 옵션 통합 구성.

Full 설치에는 검토된 [퍼스트 파티 플러그인 번들](./first-party-plugins)이 이미 포함되어 있습니다. Thin 설치에서는 플러그인 마켓에서 필요에 따라 플러그인을 설치할 수 있습니다.

모든 플러그인 수명 주기 및 파일 변경 사항은 안전하게 스테이징되어 적용됩니다. 스테이징된 변경 사항은 Cubism 재시작 후 적용되며, 핫 리로드(hot-reload)를 지원하는 플러그인은 즉시 적용될 수 있습니다.

## Turboism 상단 메뉴

Cubism Editor에서 모든 프레임워크 및 플러그인 제어 기능은 최상위 **Turboism** 메뉴(이전에는 "플러그인"/Plugins)에 통합되어 있습니다. 메뉴 항목:

1. **플러그인 마켓…** — 카탈로그에서 퍼스트 파티 및 추천 플러그인을 검색하고 설치합니다.
2. **플러그인 관리…** — 설치된 플러그인 확인, 사용 여부 토글, 로컬 JAR 추가 및 플러그인을 제거합니다.
3. **플러그인 설정…** — 전용 2열 설정 창을 열어 설치된 모든 플러그인의 옵션을 구성합니다.
4. **업데이트 확인** — 새로운 Turboism 프레임워크 릴리스를 확인합니다.
5. **Turboism 설정…** — 프레임워크 기본 설정(업데이트, 런타임 로그, 언어 로캘, 실행 옵션)을 구성합니다.
6. **키 바인딩…** — 작업 단축키를 확인하고 사용자 정의합니다.
7. **로그…** — 런타임 및 진단 로그 디렉터리를 엽니다.
8. **플러그인 액션** — 활성 플러그인이 제공하는 작업 항목입니다.
9. **정보** — 설치된 Turboism 버전 및 빌드 식별자를 확인합니다.

## 플러그인 마켓 및 자동 업데이트

0.67.0-beta.3부터 퍼스트 파티 플러그인은 프레임워크를 다시 설치하지 않고도 개별적으로 설치하고 최신 상태로 유지할 수 있습니다:

- **Turboism → 플러그인 마켓…** 또는 [turboism.dev/plugins](https://turboism.dev/plugins)에서 플러그인을 탐색할 수 있습니다.
- 퍼스트 파티 플러그인은 서명 검증을 거쳐 백그라운드에서 자동 업데이트됩니다.
- **핫 리로드**(hot-reload)로 표시된 플러그인은 모델링 작업을 방해하지 않고 즉시 적용됩니다.
- 기타 플러그인 업데이트는 다음 Cubism 재시작 시 적용됩니다.
- 사용자는 프레임워크 설정에서 공식 플러그인 자동 업데이트를 언제든지 끌 수 있습니다.

## 플러그인 설정

플러그인별 설정을 구성하려면 **Turboism → 플러그인 설정…**을 선택하세요:

- 전용 2열 창이 열립니다(왼쪽 열: 설치된 플러그인 목록, 오른쪽 열: 선택한 플러그인의 설정 양식).
- 설정 값은 저장 전 검증되며 `config/<pluginId>/`에 저장됩니다.
- 프레임워크 자체의 기본 설정은 **Turboism → Turboism 설정…**에 분리되어 있습니다.

## 로컬 JAR 관리형 설치

로컬에서 직접 빌드한 플러그인 JAR을 추가하려면:

1. 신뢰할 수 있는 소스에서 플러그인 JAR을 가져오거나 빌드하세요.
2. Cubism에서 **Turboism → 플러그인 관리…**를 선택하세요.
3. **JAR에서 설치…**(Install from JAR…)를 클릭하세요.
4. 로컬 `.jar` 파일을 선택하세요.
5. 해당 JAR이 로컬/미검증 소스임을 알리는 확인 대화 상자를 승인하세요.
6. 작업이 보류 중(pending)으로 표시되는지 확인하세요.
7. Cubism을 완전히 종료하고 같은 Turboism home으로 다시 시작하세요.
8. **플러그인 관리…**와 런타임 로그에서 적용 상태를 확인하세요.

스테이징 전, Runtime은 선택된 JAR을 미검증 입력으로 처리합니다. 유계 아카이브 제한 범위 내에서 단일 디스크립터와 플러그인 콘텐츠를 검사하고 페이로드를 보류 상태로 스냅샷합니다.

## 플러그인 교체 또는 업데이트

- **퍼스트 파티 플러그인**: 백그라운드에서 자동 업데이트되거나 플러그인 마켓을 통해 업데이트합니다.
- **로컬/서드파티 플러그인**: **플러그인 관리… → JAR에서 설치…**를 통해 동일한 플러그인 ID의 새 JAR을 설치하여 교체 의도를 스테이징합니다.

로컬 플러그인 업데이트 권장 절차:

1. 현재 JAR과 중요한 `config/` 및 `data/` 내용을 백업하세요.
2. 플러그인 관리 창을 통해 새 JAR을 설치하세요.
3. Cubism을 재시작하세요.
4. 버전, 상태 및 로그를 확인하세요.

## 플러그인 사용 설정 및 해제

**Turboism → 플러그인 관리…**에서 설치된 플러그인의 활성화 여부를 언제든지 전환할 수 있습니다:

- 설정은 `config.json`의 `disabledPlugins`에 저장되며 Cubism 재시작 후 적용됩니다.
- Runtime 소유의 `turboism.core`는 내장 프레임워크 코드이므로 비활성화할 수 없습니다.
- 비활성화된 플러그인은 다음 시작 시 로드가 건너뛰어집니다.
- 변형 간 업그레이드 시에도 `disabledPlugins` 설정은 유지됩니다. Thin 환경에 Full을 설치해도 이전에 비활성화한 플러그인이 임의로 다시 활성화되지 않습니다.

## 플러그인 제거

1. **Turboism → 플러그인 관리…**를 엽니다.
2. 제거할 플러그인을 선택하고 **제거**를 클릭하세요.
3. 보류 중인 작업을 확인하세요.
4. Cubism을 재시작하세요.
5. 플러그인이 로드되지 않았는지 확인하세요.
6. 필요에 따라 영구 데이터를 유지할지 삭제할지 결정하세요.

## 수동 설치(고급 대체 방법)

수동 설치는 UI 외부에서 로컬 JAR을 테스트하기 위한 대체 방법입니다. `<turboism.home>/plugins/`에 JAR을 직접 복사합니다. 일반 사용자는 플러그인 마켓이나 관리형 설치를 사용하는 것이 좋습니다.

플러그인 JAR은 플러그인 소스에서 빌드된 것이며, Turboism 설치 프로그램 실행 파일이나 아카이브와 다릅니다.

### 수동 설치 절차

1. Cubism과 Turboism을 완전히 종료하세요.
2. 사용하는 정확한 Turboism home을 확인하세요.
3. `<turboism.home>/plugins/` 폴더를 엽니다.
4. 플러그인 JAR을 `plugins/` 루트에 직접 복사하세요(플러그인 ID당 최대 하나의 JAR).
5. 같은 Turboism home으로 Cubism을 다시 시작하세요.
6. **플러그인 관리…**와 로그에서 상태를 확인하세요.

## 현재 제한 사항

플러그인 관리는 현재 다음을 제공하지 않습니다:

- 임의의 미검증 서드파티 서명 기관이나 비공인 공개 스토어 등록;
- 과거 버전의 무제한 롤백;
- 완전한 사용자 대상 복구 UI;
- Cubism 설치 파일이나 공식 런처의 시스템 수준 수정.
