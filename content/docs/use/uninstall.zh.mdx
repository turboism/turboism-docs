---
title: 卸载
description: 使用 Turboism 自带的卸载器移除它，并决定是否保留个人配置。
---

请使用安装你的构建时所用安装器生成的卸载器。在 Turboism 或 Cubism 仍在运行时，不要删除文件。

## 使用安装器的卸载器

- **Windows，`.exe` 安装** — 运行 Turboism home 目录中的 `uninstall.exe`。
- **Windows，`.jar` 安装** — 运行：

  ```text
  java -jar <home>\Uninstaller\uninstaller.jar
  ```

- **macOS，`.jar` 安装** — 双击 home 目录中的 `uninstall.command`，或在终端中运行它。

然后：

1. 正常关闭 Turboism 和 Cubism。
2. 启动对应的卸载器。
3. 按照其确认步骤操作。
4. 出现提示时，选择是否保留配置。若可能重新安装或之后还需要相同的偏好设置，请保留；只有在确实不再需要且已保存重要内容时才删除。
5. 完成后，确认 Cubism 不会再通过已移除的安装启动。

## 会移除什么、会保留什么

- 卸载器会移除安装器所有的文件以及 runtime 的 `logs`、`state` 和 `cache` 数据。
- `config.json` 只在你选择删除时才会被移除。NSIS 和 Java 卸载器都默认保留它。
- 未知文件和第三方插件 JAR 会被保留，因为卸载器不会删除无法识别为自有的材料。
- `data/<pluginId>/` 下的插件数据不会被静默丢弃。

卸载后请检查剩余的 Turboism home，并备份你可能需要的任何内容。不要把卸载当作删除无关宿主文件或项目的方式。

## 启动器集成

如果你启用了与官方 Cubism 启动 BAT 的集成，该集成会在移除期间从其带哈希保护的备份恢复。如果托管文件此后被编辑过，清理会报告冲突，并保留状态和备份，而不是覆盖你的更改。

## 卸载前后

替换安装前请阅读[更新策略](./update-policy)。如果更新或模式变更失败，请先查看[降级与恢复](./downgrade-recovery)，不要假定旧构建能够安全还原。
