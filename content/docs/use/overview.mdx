This section documents the currently implemented Developer Preview workflow rather than a future system installer.

## Learning path

1. [Installation](./installation) — build or obtain the isolated Preview directory and understand its safety boundary.
2. [Quick Start](./quick-start) — launch Turboism and verify the first run.
3. [Plugin Management](./plugin-management) — install, replace, enable, disable, and uninstall local `.tplugin` packages.
4. [Update Policy](./update-policy) — understand the difference between package replacement and a future automatic update system.
5. [Troubleshooting](../troubleshooting) — diagnose manifest, lifecycle, package, and Provider failures.

## Current boundary

Turboism currently has:

- an isolated Java Agent Preview bundle;
- a version-routed Runtime and SDK;
- local plugin JAR discovery;
- strict local `.tplugin` inspection and staged plugin management;
- capability-specific fail-closed host integration.

Turboism does not currently have a production system installer, marketplace, automatic online updater, signing service, or global Cubism launcher integration.
