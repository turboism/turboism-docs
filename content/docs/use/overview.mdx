## Plugins

## Maintain or remove Turboism

- [Update Policy](./update-policy) — review release channels and update by rerunning an installer.
- [Uninstall](./uninstall) — remove Turboism and choose whether to keep configuration.
- [Downgrade and Recovery](./downgrade-recovery) — recover when an update or installation change fails.

## Related sites

- [Downloads](https://turboism.dev/download) — published packages for the stable, beta, and nightly channels.
- [SDK documentation](https://turboism.dev/sdk/index.html) — generated Java API documentation for plugin development. Check the [API publication status](../reference/generated-api) before relying on it as the current public contract.
- [Plugin Directory](https://turboism.dev/plugins) — curated information about Turboism plugins. Third-party listings and publication remain subject to the directory's current status.
- [Learning site](https://turboism.dev/learn) — tutorials and learning materials.
- [GitHub](https://github.com/turboism) — source code, releases, issues, and pull requests.
- [Main website](https://turboism.dev) — project overview and links to Turboism services.

Public releases and downloads are available. Automatic framework updates, a production-enabled marketplace, and a public third-party plugin directory are not. If the installed build behaves differently from this documentation, use [Troubleshooting](../troubleshooting).
