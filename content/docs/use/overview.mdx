This is candidate guidance for publication pending. It is written for ordinary modelers, not for people building Turboism from source.

## Your lifecycle

1. [Installation](./installation) — review the candidate installation boundary and obtain an installer only from the channel that supplied your Preview build.
2. [Installer Modes](./installer-modes) — understand the candidate Full, Thin, and Lite Managed Runtime choices before selecting one.
3. [Quick Start](./quick-start) — complete the first-run workflow for the Preview build you have.
4. [Plugin Management](./plugin-management) — manage local plugin JARs after a restart; this is not a published plugin directory.
5. [First-party plugins](./first-party-plugins) — see the candidate overview of bundled first-party capabilities.
6. [Update Policy](./update-policy) — plan manual updates and preserve what matters before changing builds.
7. [Downgrade and Recovery](./downgrade-recovery) — recover from a failed change without assuming that an older-version downgrade is supported.
8. [Uninstall](./uninstall) — use the installer’s uninstaller and choose whether to keep personal configuration.

## What this path does not promise

Public release, deployment, automatic updates, online discovery, and a plugin directory are all pending. Treat each candidate document as version- and capability-sensitive, and use [Troubleshooting](../troubleshooting) when the available Preview behavior differs from these directions.
