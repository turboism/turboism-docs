## Related sites

- [SDK documentation](https://turboism.dev/docs/sdk/index.html) — generated Java API documentation for plugin development. Check the [API publication status](../reference/generated-api) before relying on it as the current public contract.
- [Plugin Directory](https://turboism.dev/plugins) — curated information about available Turboism plugins. Public listings and publication remain subject to the directory's current status.
- [Learning site](https://turboism.dev/learn) — tutorials and learning materials for using Turboism and related workflows.
- [Chat](https://chat.turboism.dev) — community conversation and help.
- [GitHub](https://github.com/turboism) — source code, issues, pull requests, and project development.
- [Main website](https://turboism.dev) — project overview and links to Turboism services.

Public release, automatic updates, online discovery, and a public plugin directory remain pending. If the available Preview behaves differently, use [Troubleshooting](../troubleshooting).
