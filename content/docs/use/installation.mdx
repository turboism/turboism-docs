---
title: Installation
description: Run the current isolated Turboism Developer Preview without modifying a Cubism installation.
---

Turboism does not currently provide a production system installer. The available product path is an isolated Developer Preview bundle for Windows and Live2D Cubism Editor 5.3.02.

The bundle does not modify Cubism JARs, DLLs, official launcher files, licensing state, or existing projects.

## Build the Preview bundle

From the Turboism source repository:

```bash
./gradlew previewBundle checkPreviewBundleLayout \
  --no-daemon --console=plain
```

The output is written to:

```text
build/preview/<worktreeId>/
├── turboism-agent.jar
├── run-preview.bat
├── launch-cubism-turboism.bat
├── launch-cubism-turboism.ps1
├── plugins/
├── plugin-data/
├── state/
└── logs/
```

## Run the Preview

1. Copy the entire Preview directory to the Windows machine that has the matching Cubism installation.
2. Keep the directory intact.
3. Double-click `run-preview.bat` or use the bundle's launcher script and README.
4. Confirm that Turboism starts and writes diagnostics in the Preview-owned directory.

The current Preview launcher searches supported 5.3.02 locations and `CUBISM_ROOT`, then starts Cubism with the Turboism Java Agent without permanently rewriting the Cubism installation.

## Choose a Turboism home

Runtime uses an isolated home selected by a Java system property or agent option:

```text
-Dturboism.home=/absolute/path/to/turboism-home
```

```text
-javaagent:turboism-agent.jar=home=/absolute/path/to/turboism-home
```

The home contains:

```text
<turboism.home>/
├── config.json
├── plugins/
├── config/<pluginId>/
├── data/<pluginId>/
├── cache/<pluginId>/
├── state/<pluginId>/
└── logs/<pluginId>/
```

Do not edit or clear the home while Turboism is running.

## Remove the Preview

1. Close Cubism.
2. Confirm the Preview-owned process has exited.
3. Delete the Preview directory.

No Cubism installation file should need restoration because the Preview path does not modify it.

## Plugin installation

Turboism plugin packages are managed separately from the framework Preview. See [Plugin Management](./plugin-management) for `.tplugin` install, replacement, enable, disable, and uninstall behavior.

## Safety and compatibility

- Use a backup or disposable Cubism project for Preview testing.
- Do not replace Cubism JARs, DLLs, official BAT files, or licensing components.
- A mismatched or unverified host artifact leaves host adapters unavailable instead of using an unsafe fallback.
- The public Preview workflow is not the same as the project's strict real-host validation procedure.

## Current limitations

- Windows Preview wrapper only.
- Cubism Editor 5.3.02 Preview envelope.
- No production automatic install, update, rollback, recovery, marketplace, signing, or global launcher integration.
- Feature readiness remains capability- and version-specific.
