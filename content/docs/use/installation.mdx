The installation path below is the documented workflow shape for the release stage. This
site is still a preview and many steps are intentionally pending public release facts.

## What you need before installing

- A stable Turboism download source (available from the product site when public release
  is announced).
- A Cubism Editor environment that matches the same compatibility envelope as your
  release channel.
- A backup of active Cubism projects.

## Installation checklist (preview)

1. **Obtain the package**
   - Go to the official Turboism download entry point from the product site.
   - Verify you downloaded the artifact for your platform.
2. **Prepare Java Agent binaries**
   - Keep the downloaded archive unchanged until checksums and signatures are validated.
3. **Attach to Cubism**
   - Follow the in-product onboarding steps to register the Java Agent.
4. **Run first verification check**
   - Start the first test project and confirm the agent reports loaded version metadata.

## Verify your install

- Confirm the plugin manager detects the Agent runtime.
- Confirm the documentation route `docs.turboism.dev` is reachable from within your
  environment.
- Confirm no unexpected changes are applied to existing projects during first launch.

> **Preview status**
> Public install commands, checksums, exact OS package names, and the minimum Java/Cubism
> baseline are not yet published on this documentation site. This page intentionally tracks
> the intended install flow, not finalized contract details.

When public artifacts are available, this page will be replaced with exact commands,
checksums, and compatibility tables.
