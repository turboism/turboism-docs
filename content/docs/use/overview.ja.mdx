## はじめに

- [インストール](./installation) — パッケージを選び、Windows、macOS、Linux に Turboism をインストールします。
- [互換性](./compatibility) — リリース、プラグイン、ケイパビリティライン別の対応 Cubism Editor バージョンを確認します。
- [Full / Thin バリアント](./installer-modes) — Full と Thin のパッケージおよび安全なアップグレードを比較します。
- [クイックスタート](./quick-start) — ダウンロード、検証、設定を行い、Turboism を初めて起動します。

## プラグイン

- [プラグイン管理](./plugin-management) — Turboism トップメニューからプラグインの検索、設定、有効化、無効化、アンインストールを行います。
- [ファーストパーティプラグイン](./first-party-plugins) — Full インストールに含まれるレビュー済みのプラグインバンドル。

## 更新と削除

- [更新ポリシー](./update-policy) — リリースチャンネルを確認し、インストーラーの再実行で更新します。
- [アンインストール](./uninstall) — Turboism を削除し、設定を保持するか選択します。
- [ダウングレードと復旧](./downgrade-recovery) — 更新やインストール変更に失敗した場合に復旧します。

## 関連サイト

- [ダウンロード](https://turboism.dev/download) — stable、beta、nightly チャンネルの公開パッケージ。
- [SDK ドキュメント](https://turboism.dev/sdk/index.html) — プラグイン開発向けの Java API ドキュメントです。現在の public contract として利用する前に、[API 公開状況](../reference/generated-api)を確認してください。
- [プラグインディレクトリ](https://turboism.dev/plugins) — 整理された Turboism プラグイン情報を確認できます。サードパーティの掲載と公開は、ディレクトリの現在の状況に従います。
- [学習サイト](https://turboism.dev/learn) — チュートリアルと学習資料。
- [GitHub](https://github.com/turboism) — ソースコード、リリース、Issue、Pull Request を確認できます。
- [メインサイト](https://turboism.dev) — プロジェクト概要と Turboism の各サイトへの入口です。

公開リリースとダウンロードは利用できます。Turboism は更新を確認し、署名検証済みのファーストパーティプラグインをバックグラウンドで自動更新します。また Cubism 内のプラグインマーケットや [turboism.dev/plugins](https://turboism.dev/plugins) からプラグインを導入できます。フレームワークインストーラー自体の自動更新や未検証のサードパーティディレクトリは利用できません。インストールされたビルドの動作がこのドキュメントと異なる場合は[トラブルシューティング](../troubleshooting)を確認してください。
