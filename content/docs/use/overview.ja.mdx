これは公開待ちの候補ガイドです。Turboism をソースから構築する人ではなく、一般的なモデラーを対象にしています。

## ライフサイクル

1. [インストール](./installation) — 候補となるインストール境界を確認し、インストーラーは使用中の Preview build を提供したチャネルからのみ入手します。
2. [インストーラーモード](./installer-modes) — 選択前に、候補の Full、Thin、Lite Managed Runtime を理解します。
3. [クイックスタート](./quick-start) — 手元の Preview build の初回実行フローを完了します。
4. [プラグイン管理](./plugin-management) — 再起動後にローカル plugin JAR を管理します。これは公開済みの plugin directory ではありません。
5. [ファーストパーティプラグイン](./first-party-plugins) — 同梱されるファーストパーティ capability の候補概要を確認します。
6. [更新ポリシー](./update-policy) — build を変更する前に、手動更新を計画し必要なものを保存します。
7. [ダウングレードと復旧](./downgrade-recovery) — 以前の version への downgrade がサポートされていると仮定せず、失敗した変更から復旧します。
8. [アンインストール](./uninstall) — インストーラーのアンインストーラーを使用し、個人の configuration を保持するか選択します。

## このパスが約束しないこと

公開リリース、deployment、自動更新、オンライン discovery、plugin directory はすべて保留中です。各候補ドキュメントは version と capability に依存するものとして扱い、利用できる Preview の動作が説明と異なる場合は[トラブルシューティング](../troubleshooting)を使用してください。
