## はじめに

- [インストール](./installation) — 信頼できる提供元から入手した Preview build をインストールします。
- [インストーラーモード](./installer-modes) — 候補の Full、Thin、Lite を比較します。
- [クイックスタート](./quick-start) — Turboism を初めて起動します。

## プラグイン

- [プラグイン管理](./plugin-management) — ローカルのプラグイン JAR を管理します。
- [ファーストパーティプラグイン](./first-party-plugins) — 候補となるファーストパーティ機能の独立したガイド分類を確認します。

## 更新と削除

- [更新ポリシー](./update-policy) — 手動更新の準備をします。
- [アンインストール](./uninstall) — Turboism を削除し、設定を保持するか選択します。
- [ダウングレードと復旧](./downgrade-recovery) — 更新やインストール変更に失敗した場合に復旧します。

## 関連サイト

- [SDK ドキュメント](https://turboism.dev/docs/api/sdk/index.html) — プラグイン開発向けの Java API ドキュメントです。現在の public contract として利用する前に、[API 公開状況](../reference/generated-api)を確認してください。
- [プラグインディレクトリ](https://turboism.dev/plugins) — 整理された Turboism プラグイン情報を確認できます。公開一覧と公開機能は、ディレクトリの現在の状況に従います。
- [学習サイト](https://turboism.dev/learn) — Turboism の使い方や関連ワークフローのチュートリアルと学習資料を提供します。
- [チャット](https://chat.turboism.dev) — コミュニティでの交流やサポートに利用できます。
- [GitHub](https://github.com/turboism) — ソースコード、Issue、Pull Request、プロジェクト開発を確認できます。
- [メインサイト](https://turboism.dev) — プロジェクト概要と Turboism の各サイトへの入口です。

公開、自動更新、オンライン discovery、公開 plugin directory は保留中です。利用可能な Preview の動作が説明と異なる場合は[トラブルシューティング](../troubleshooting)を確認してください。
