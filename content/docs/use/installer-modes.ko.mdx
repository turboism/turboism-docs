**0.67.0** 안정판부터 Turboism의 각 릴리스는 정확히 두 가지 제품 다운로드만 제공하며, 각각 일치하는 `.sha256` 체크섬이 함께 제공됩니다:

- **Windows 설치 프로그램** — `TurboismInstaller-<version>.exe`. Windows에서 권장되는 방법입니다.
- **포터블 ZIP** — `turboism-<version>.zip`. Windows 수동 설정과 macOS 및 Linux용입니다.

두 패키지의 내용은 동일합니다. 런타임 프레임워크, 설정 도구(`configure_turboism.ps1`), 모든 기본 제공 [퍼스트 파티 플러그인](./first-party-plugins), 그리고 완전한 오프라인 GraalJS 엔진이 포함됩니다. GraalVM 런타임 설치는 여전히 별도의 선택 단계입니다. 플러그인이 없는 패키지나 개별 플러그인 선택은 없습니다. 플러그인은 나중에 Cubism의 **Turboism → 플러그인 관리…**에서 사용 여부를 바꿉니다.

두 패키지 모두 Cubism JAR, DLL, 라이선스 상태를 수정하지 않습니다. Cubism 시작 BAT 파일을 수정하는 것은 아래에 설명된 선택적 공식 BAT 통합뿐이며, 해시로 보호된 백업을 사용합니다.

## 설치 프로그램과 포터블 ZIP 비교

| | Windows 설치 프로그램(`.exe`) | 포터블 ZIP(`.zip`) |
| --- | --- | --- |
| 플랫폼 | Windows x64 | Windows(수동 설정), macOS 및 Linux(미리 보기 / 런타임 전용) |
| 기본 제공 퍼스트 파티 플러그인과 오프라인 GraalJS | 포함 | 포함 |
| 설치 위치 | 기본값 `%LOCALAPPDATA%\Turboism`, 변경 가능 | 압축을 푼 임의의 별도 폴더 |
| Cubism 검색 | 설치 마법사에 내장 | `configure_turboism.ps1`을 직접 실행 |
| 시작 항목 | 시작 메뉴 및 바탕 화면 바로 가기(선택 가능) | 설정 도구가 생성한 바로 가기 또는 `launch-cubism-turboism.bat` |
| Cubism 공식 BAT 통합 | 기본 선택, 해제 가능 | 활성화되지 않음 |
| 제거 | `uninstall.exe` | Cubism을 닫고 폴더 삭제 |

## 설치 프로그램 옵션

Windows 설치 프로그램은 사용자 단위로 실행되며 다음 페이지를 차례로 진행합니다:

1. **언어** — 시작 페이지 전에 영어, 중국어 간체, 일본어, 한국어 중에서 선택합니다. 이 선택은 설치 프로그램에만 영향을 주며 `config.json`에 기록되지 않습니다.
2. **라이선스 및 확인 사항** — AGPL-3.0-only 라이선스에 동의하고, 최종 사용자 런타임 성명 및 면책 조항을 검토한 뒤 네 가지 필수 확인 사항을 모두 선택합니다.
3. **디렉터리** — Turboism 홈입니다. 기본값은 `%LOCALAPPDATA%\Turboism`입니다.
4. **GraalVM** — 선택적 Turboism 관리형 GraalVM 런타임(약 326 MiB)에 대해 **나중에 설치** 또는 **지금 다운로드하여 설치**(권장)를 선택합니다. 다운로드는 크기, SHA-256, 릴리스 메타데이터로 검증되며 선택한 경우에만 진행됩니다. 나중에 Turboism 설정 도구에서 설치할 수도 있습니다.
5. **Cubism 설치** — 설치 프로그램이 설치된 Cubism Editor를 검색하며, **버전 가져오기**로 폴더를 추가할 수 있습니다. 지원되는 설치를 찾지 못해도 Turboism은 설치되며, 나중에 `configure_turboism.ps1`로 설정할 수 있습니다.
6. **시작 옵션** — Cubism이 Turboism과 함께 시작되는 방식을 선택합니다:
   - **Turboism 시작 메뉴 바로 가기 만들기**(권장, 기본 선택)
   - **Turboism 바탕 화면 바로 가기 만들기**(기본 선택)
   - **선택한 Cubism 공식 시작 BAT를 수정하여 기존 Cubism 바로 가기에서 Turboism을 로드하도록 합니다**(권장, 기본 선택)

   세 항목을 모두 해제하면 설치 프로그램은 일반적인 시작 경로 어디에서도 Turboism이 활성화되지 않는다고 경고합니다.
7. **완료** — 원하면 Turboism을 바로 시작합니다.

### Cubism 공식 BAT 통합

0.67.0부터 설치 프로그램은 Cubism 공식 BAT 통합을 기본으로 선택합니다. 선택한 `CubismEditor5.bat` 실행기를 백업하고 수정하여, 기존 Cubism 바로 가기, 파일 연결 및 기타 진입점이 관리형 실행기를 거치지 않고도 Turboism을 로드하도록 합니다.

- 시작 옵션 페이지에서 해제할 수 있으며, 시작 메뉴 바로 가기는 이와 별개로 동작합니다.
- 해시로 보호되며 멱등적입니다. 설치 후 편집된 BAT 파일은 충돌로 보고되며 절대 덮어쓰지 않습니다.
- 제거 시 검증된 백업에서 복원됩니다.
- 자동(무인) 설치에서도 적용됩니다.
- UAC로 권한을 상승하는 것은 통합 단계뿐이며, 나머지 설치는 관리자 권한 없이 진행됩니다.

## 업그레이드

같은 Turboism 홈을 대상으로 새 설치 프로그램을 실행합니다. 기존 설치를 업그레이드하고, 현재 기본 제공 퍼스트 파티 플러그인을 설치하며, 폐지된 공식 플러그인 JAR를 (파일 이름만이 아니라 내장된 플러그인 ID로 판별하여) 정리하고, 기존 `disabledPlugins` 항목을 유지하므로 비활성화한 플러그인은 계속 비활성 상태로 남습니다. `config.json`의 다른 유효한 설정과 `cubism-installations.json`의 Cubism 연결 정보도 유지됩니다.

포터블 ZIP의 경우 [설치](./installation)의 안내에 따라 새 아카이브의 압축을 풀고 설정 도구를 다시 실행합니다.

개발 전용 `Turboism with fx` 플러그인과 관리형 fx 런타임 바이트는 어떤 릴리스 패키지에도 포함되지 않습니다.

## 패키지 이력

- **0.67.0-beta.3 ~ 0.67.0-beta.7**에서는 두 가지 변형으로 나뉜 네 가지 다운로드를 일시적으로 제공했습니다. Full(`TurboismInstaller-<version>-full.exe`, `turboism-<version>-full.zip`)은 모든 퍼스트 파티 플러그인을 포함했고, Thin(`TurboismInstaller-<version>-thin.exe`, `turboism-<version>-thin.zip`)은 런타임만 포함했습니다. 이 구성은 폐지되었습니다. Thin 설치 위에 현재 설치 프로그램을 실행하면 기존 `disabledPlugins` 설정을 유지하면서 기본 제공 플러그인이 설치됩니다.
- **0.44.0 이하**에서는 기존 패키징 모델을 사용했습니다. Full/Lite 모드 선택 페이지와 개별 플러그인 확인란이 있는 단일 Windows 설치 프로그램 `TurboismInstaller-<version>.exe`, 크로스 플랫폼 IzPack Java 설치 프로그램 `TurboismInstaller-<version>.jar`(Java 17 이상 필요), 포터블 아카이브 `turboism-<version>-full.zip` 및 `turboism-<version>-lite.zip`입니다.

Java 설치 프로그램은 더 이상 게시되지 않습니다. macOS와 Linux에서는 포터블 ZIP을 사용합니다.
