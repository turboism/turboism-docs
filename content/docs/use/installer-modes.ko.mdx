title: Full 및 Thin 변형
description: Full 및 Thin 다운로드 변형을 비교하고, 안전한 업그레이드와 기존 패키지 이력을 확인합니다.
---

**0.67.0-beta.3**부터 Turboism은 마법사 기반 설치 모드 대신 두 가지 변형으로 나뉜 네 가지 정식 릴리스 자산을 제공합니다:

- **Full**(`TurboismInstaller-<version>-full.exe`, `turboism-<version>-full.zip`) — 런타임 프레임워크와 모든 기본 제공 퍼스트 파티 플러그인.
- **Thin**(`TurboismInstaller-<version>-thin.exe`, `turboism-<version>-thin.zip`) — 런타임 프레임워크만 포함되며 퍼스트 파티 플러그인은 포함되지 않음.

Thin 변형의 경우 플러그인은 나중에 Cubism 내 플러그인 마켓(**Turboism** 메뉴 → **플러그인 마켓…**) 또는 [turboism.dev/plugins](https://turboism.dev/plugins)에서 설치합니다.

두 변형 모두 Cubism 설치 파일이나 라이선스 상태를 수정하지 않습니다.

## Full 및 Thin 경계

| 기능 | Full 변형 | Thin 변형 |
| --- | --- | --- |
| 런타임 프레임워크 및 Java Agent | 포함 | 포함 |
| 설정 도구(`configure_turboism.ps1`) | 포함 | 포함 |
| 기본 제공 퍼스트 파티 플러그인 | `plugins/`에 모두 포함 | 포함되지 않음 |
| 플러그인 설치 방식 | 사전 설치됨 | 인앱 플러그인 마켓 또는 웹 디렉터리 |
| 플러그인 관리 및 활성화 토글 | **Turboism → 플러그인 관리…** | **Turboism → 플러그인 관리…** |
| 백그라운드 자동 업데이트 | 서명 검증된 퍼스트 파티 업데이트 | 서명 검증된 퍼스트 파티 업데이트 |

### 설치 마법사의 모드 및 플러그인 선택 페이지 제거

설치 프로그램에는 더 이상 설치 모드 선택이나 플러그인 개별 선택 페이지가 없습니다:

- `TurboismInstaller-<version>-full.exe`는 개별 확인란 없이 모든 퍼스트 파티 플러그인을 설치합니다.
- `TurboismInstaller-<version>-thin.exe`는 프레임워크 파일만 설치합니다.
- 플러그인은 Cubism 실행 후 **Turboism → 플러그인 관리…**에서 사용 여부를 변경할 수 있으며 변경 사항은 Cubism 재시작 후 적용됩니다.
- 서명 검증된 퍼스트 파티 플러그인은 백그라운드에서 자동 업데이트됩니다. 핫 리로드(hot-reload)로 표시된 플러그인은 즉시 적용되며 기타 업데이트는 Cubism 재시작 후 적용됩니다. 사용자는 설정에서 공식 플러그인 자동 업데이트를 끌 수 있습니다.

## 변형 간의 안전한 업그레이드

변형 간 덮어쓰기 업데이트는 안전하고 멱등성을 가집니다:

- **Full 위에 Thin 설치**: 기존 Full 설치 환경에 Thin 설치 프로그램을 실행해도 기존 `plugins/` 디렉터리는 그대로 유지되며 사용자 설정도 보호됩니다.
- **Thin 위에 Full 설치**: 기존 Thin 설치 환경에 Full 설치 프로그램을 실행하면 `config.json`의 기존 `disabledPlugins` 설정을 존중하면서 모든 기본 제공 퍼스트 파티 플러그인을 설치하거나 업데이트합니다.

두 경우 모두 `config.json`의 사용자 설정과 `cubism-installations.json`의 Cubism 연결 정보가 유지됩니다.

## 선택적 스크립트 엔진 및 GraalVM

Windows 설치 프로그램은 JavaScript 엔진 및 GraalVM 종속성을 가져오는 선택적 구성 요소를 제공합니다:

- 선택하지 않아도 기본 프레임워크와 Java 플러그인은 완전하며 정상 동작합니다.
- 나중에 `install-script-engine.ps1` 스크립트나 설정 창에서 설치할 수 있습니다.
- 개발 전용 `Turboism with fx` 플러그인과 관리형 fx 런타임 바이트는 어떤 릴리스 패키지에도 포함되지 않습니다.

## 이전 패키지(0.67.0-beta.3 이전)

**0.67.0-beta.3** 이전 릴리스에서는 기존 패키징 모델이 사용되었습니다:

- Full 및 Lite 설치 모드 선택 페이지와 개별 컴포넌트 선택 페이지가 포함된 단일 Windows 설치 프로그램 `TurboismInstaller-<version>.exe`.
- Full, Thin 및 Lite 모드를 제공하는 크로스 플랫폼 IzPack Java 설치 프로그램 `TurboismInstaller-<version>.jar`(Java 17 이상 필요).
- `turboism-<version>-full.zip` 및 `turboism-<version>-lite.zip`으로 배포된 포터블 아카이브.

0.67.0-beta.3부터:
- Java 설치 프로그램 JAR은 폐지되었습니다. macOS 및 Linux 사용자는 포터블 ZIP 패키지를 사용합니다.
- 기존 "Lite" 모드는 Thin 변형(`-thin.exe` 및 `-thin.zip`)으로 대체되었습니다.
- 설치 프로그램의 개별 플러그인 선택은 앱 내 플러그인 마켓과 플러그인 관리 창으로 전환되었습니다.
