description: Full, Thin 및 Lite 설치 선택과 선택적 관리형 GraalVM 구성 요소를 비교합니다.
---

Turboism 설치 프로그램과 이식 가능한 아카이브는 서로 다른 플러그인 선택과 함께 같은 런타임을 제공합니다. 모드는 파일을 선택할 뿐이며 Cubism 설치를 변경하지 않습니다.

## 모드

- **Full** — 에이전트와 검토된 기본 제공 플러그인 번들. 설치 프로그램은 승인된 모든 릴리스 플러그인을 미리 선택하며 개별 플러그인을 선택 해제할 수 있습니다.
- **Thin** — 추가 관리형 네이티브 런타임 페이로드가 없는 동일한 승인 플러그인 목록. Java 설치 프로그램에서 사용할 수 있으며 명시적인 사용자 지정 실행 파일 경로도 허용합니다.
- **Lite** — 에이전트와 공통 파일만 제공. 기본 제공 플러그인 JAR은 복사되지 않습니다.

Windows `.exe` 설치 프로그램은 **Full**과 **Lite**를 제공합니다. 크로스 플랫폼 `.jar` 설치 프로그램은 **Full**, **Thin**, **Lite**를 제공합니다. 이식 가능한 아카이브는 같은 페이로드의 `full` 및 `lite` 변형으로 제공됩니다.

## 선택적 관리형 GraalVM

설치 프로그램은 선택적 관리형 GraalVM 구성 요소를 제공합니다:

- GraalVM 공식 GitHub 릴리스에서 고정된 아카이브를 다운로드하고 사용 전에 검증합니다;
- 선택하지 않아도 플러그인 번들을 위한 설치가 유효하고 완전하게 유지됩니다;
- 나중에 Turboism 설정에서 설치할 수 있습니다.

개발 전용 `Turboism with fx` 플러그인과 그 관리형 런타임 바이트는 어떤 릴리스 패키지에도 포함되지 않습니다.

## 모드가 변경하지 않는 것

- 런타임 home, 구성, 로그 및 플러그인 데이터는 모든 모드에서 동일합니다.
- 설치 프로그램을 다시 실행하면 같은 home에 다른 선택을 적용하고 관리형 플러그인 상태만 변경합니다.
- 모드 변경으로 알 수 없는 파일이나 서드파티 플러그인 JAR이 삭제되지 않습니다.
- 모드 레이블은 사용 중인 Cubism 버전에서 플러그인 기능을 사용할 수 있음을 보장하지 않습니다. 가용성은 기능과 버전에 따라 다릅니다.

## 선택하기 전에

1. `config.json`과 중요한 플러그인 `config/` 또는 `data/` 내용을 백업하세요.
2. 설치 프로그램 재실행과 릴리스 채널의 동작 방식은 [업데이트 정책](./update-policy)을 확인하세요.
3. 변경 사항이 예상대로 동작하지 않으면 [다운그레이드 및 복구](./downgrade-recovery)를 사용하세요.
