빌드를 설치한 설치 프로그램이 생성한 제거 프로그램을 사용하세요. Turboism 또는 Cubism이 실행 중일 때 파일을 삭제하지 마세요.

## 설치 프로그램의 제거 프로그램 사용

- **Windows, `.exe` 설치** — Turboism home 디렉터리의 `uninstall.exe`를 실행하세요.
- **Windows, `.jar` 설치** — 다음을 실행하세요:

  ```text
  java -jar <home>\Uninstaller\uninstaller.jar
  ```

- **macOS, `.jar` 설치** — home 디렉터리의 `uninstall.command`를 두 번 클릭하거나 터미널에서 실행하세요.

그런 다음:

1. Turboism과 Cubism을 정상적으로 종료하세요.
2. 해당 제거 프로그램을 시작하세요.
3. 확인 단계를 따르세요.
4. 구성 유지 여부를 물으면 선택하세요. 재설치하거나 같은 기본 설정이 나중에 필요할 수 있으면 유지하세요. 더 이상 필요하지 않고 중요한 항목을 저장해 두었을 때만 삭제하세요.
5. 완료 후 Cubism이 제거된 설치를 통해 더 이상 시작되지 않는지 확인하세요.

## 제거되는 것과 유지되는 것

- 제거 프로그램은 설치 프로그램이 소유한 파일과 런타임 `logs`, `state`, `cache` 데이터를 삭제합니다.
- `config.json`은 삭제를 선택한 경우에만 제거됩니다. NSIS와 Java 제거 프로그램 모두 기본적으로 이를 유지합니다.
- 알 수 없는 파일과 서드파티 플러그인 JAR은 보존됩니다. 제거 프로그램은 자신의 것으로 식별할 수 없는 자료를 삭제하지 않습니다.
- `data/<pluginId>/` 아래의 플러그인 데이터는 조용히 삭제되지 않습니다.

제거 후 남은 Turboism home을 검토하고 필요할 수 있는 항목을 백업하세요. 제거를 관련 없는 호스트 파일이나 프로젝트를 지우는 수단으로 취급하지 마세요.

## 런처 통합

공식 Cubism 시작 BAT와의 통합을 활성화했다면, 제거 중에 그 통합이 해시로 보호되는 백업에서 복원됩니다. 이후 관리형 파일이 편집되었다면 정리는 충돌을 보고하고 변경 사항을 덮어쓰지 않고 상태와 백업을 보존합니다.

## 전후 확인

설치를 교체하기 전에 [업데이트 정책](./update-policy)을 읽어 주세요. 업데이트나 모드 변경이 실패했다면 이전 빌드를 안전하게 복원할 수 있다고 가정하지 말고 [다운그레이드 및 복구](./downgrade-recovery)부터 시작하세요.
