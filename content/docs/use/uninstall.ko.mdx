빌드를 설치한 설치 프로그램이 생성한 제거 프로그램을 사용하세요. Turboism 또는 Cubism이 실행 중일 때 파일을 삭제하지 마세요.

## 설치 방식별 제거

- **Windows `.exe` 설치**(`TurboismInstaller-<version>.exe`): Turboism home 디렉터리의 `uninstall.exe`를 실행하세요.
- **포터블 ZIP 설치**(Windows 수동 설정, macOS 또는 Linux): 포터블 아카이브에는 제거 프로그램이 없으며 공식 BAT 통합도 활성화되지 않습니다. Cubism을 완전히 종료하고 Turboism 폴더를 삭제하세요.
- **레거시 설치(0.44.0 이하)**: 폐지된 Java IzPack 설치 프로그램으로 생성된 설치본은 Windows/Linux에서 `java -jar <home>\Uninstaller\uninstaller.jar`, macOS에서 `uninstall.command`를 실행했습니다.

`.exe` 설치본의 제거 절차:

1. Turboism과 Cubism을 정상적으로 종료하세요.
2. Turboism home 디렉터리의 `uninstall.exe`를 실행하세요.
3. 확인 단계를 따르세요.
4. "config.json(사용자 설정) 유지" 확인란이 표시되면 선택을 확인하세요. 기본적으로 선택되어 있으며 구성을 완전히 삭제하려면 선택을 해제하세요.
5. 완료 후 Turboism 바로 가기나 관리형 실행 항목을 통해 Cubism이 더 이상 실행되지 않는지 확인하세요.

## 제거되는 것과 유지되는 것

- 제거 프로그램은 Turboism이 기록한 관리형 바로 가기, 상태 및 설치 파일, 런타임 `logs`, `state`, `cache` 디렉터리를 정리합니다.
- `config.json`은 기본적으로 유지되며 확인란 선택을 해제한 경우에만 삭제됩니다.
- 제거 프로그램은 설치 프로그램이 배포한 퍼스트 파티 플러그인 JAR만 삭제하며, 알 수 없는 파일과 서드파티 플러그인 JAR은 보존합니다.
- `data/<pluginId>/` 아래의 영구 데이터와 `config/<pluginId>/` 아래의 설정은 제거 프로그램이 삭제하지 않습니다.

제거 후 남은 Turboism 디렉터리를 검토하고 필요한 항목을 백업하세요.

## 런처 통합

Cubism 공식 시작 BAT 통합은 Windows 설치 프로그램에서 기본으로 선택되어 있습니다. 통합이 적용된 경우 제거 프로그램이 해시 검증 백업에서 원래 BAT 파일을 자동으로 복원합니다. 설치 후 파일이 수동으로 편집된 경우 정리는 충돌을 보고하고 변경 사항을 덮어쓰지 않고 상태와 백업을 보존합니다.

## 전후 확인

설치를 교체하기 전에 [업데이트 정책](./update-policy)을 읽어 주세요. 업데이트나 설치 변경에 실패했다면 [다운그레이드 및 복구](./downgrade-recovery)를 먼저 참고하세요.
