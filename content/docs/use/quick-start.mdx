This guide shows the intended first-run flow when public release artifacts are available.

## 1) Prepare and verify environment

- Install or update to a published Turboism release.
- Open a copy of a non-critical Cubism project.
- Ensure your local project is backed up.

## 2) Start with the default workflow

1. Install the Agent following the installation steps.
2. Open Cubism.
3. Confirm the Agent endpoint is active in the plugin tooling.
4. Trigger a health check from the workspace tooling.
5. Open the same project in documentation mode and verify navigation links.

## 3) Minimal sanity checks

- The documentation surface should show this site in the agent context.
- A no-op extension action should complete without modifying model data.
- You should be able to open a preview workflow from the default template.

## 4) Next steps

- Read [Update and maintenance](./update-policy) to understand release behavior.
- Move to [Troubleshooting and feedback](../troubleshooting) if anything is unexpected.

## What is still not final

- Exact startup UI actions,
- exact CLI flags,
- and official baseline versions.

These are still withheld until release artifacts are published.
