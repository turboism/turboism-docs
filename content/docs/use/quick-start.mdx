This quick start assumes you have built or received the current Developer Preview directory described in [Installation](./installation).

## 1. Prepare safely

- Use Windows with the supported Cubism 5.3.02 Preview envelope.
- Back up the project you intend to open, or use a disposable copy.
- Keep the Preview directory separate from the Cubism installation.
- Do not edit Cubism JARs, DLLs, BAT files, or licensing state.

## 2. Start Turboism

1. Open the Preview directory.
2. Double-click `run-preview.bat`.
3. If automatic discovery cannot find Cubism, use the provided launcher and select the matching Cubism root according to the bundle README.
4. Wait for Cubism and Turboism diagnostics to initialize.

## 3. Verify the first run

Check that:

- Cubism starts normally;
- the Turboism Java Agent reports startup;
- the Runtime uses the intended Turboism home;
- bundled plugins appear in the plugin/runtime diagnostics;
- unavailable host capabilities fail closed rather than crashing Cubism;
- closing Cubism releases plugin scopes and framework-owned executors.

## 4. Add a plugin

Use [Plugin Management](./plugin-management) to install a local `.tplugin`. Plugin changes apply after Cubism restarts.

## 5. Find logs

Use the Preview-owned log directory or the selected Turboism home's `logs/` directory. Keep logs when reporting startup, package, dependency, permission, or Provider failures.
