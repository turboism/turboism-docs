title: Quick Start

This quick start begins from a published release package as described in [Installation](./installation). You need the package and an installed, lawfully licensed Cubism Editor.

## 1. Prepare safely

- Windows x64 is the supported Cubism host platform. Supported Editor versions depend on the Turboism release: Stable 0.44.0 supports 5.2.03, 5.3.02, and 5.3.03, while Beta 0.67.0-beta.3 supports 5.0.00–5.3.04; see [Compatibility](/docs/use/compatibility).
- Starting with 0.67.0-beta.3, the legacy Java installer JAR is retired; macOS and Linux use portable ZIP packages.
- Back up the project you intend to open, or use a disposable copy.
- Keep the Turboism home separate from the Cubism installation.
- Do not edit Cubism JARs, DLLs, BAT files, or licensing state.

## 2. Download and verify

1. Open [turboism.dev/download](https://turboism.dev/download) and choose a channel: **Stable**, **Beta**, or **Nightly**.
2. Download one package and its matching `.sha256` file:
   - `TurboismInstaller-<version>-full.exe` or `turboism-<version>-full.zip` for the framework plus all first-party plugins.
   - `TurboismInstaller-<version>-thin.exe` or `turboism-<version>-thin.zip` for the framework runtime only.
3. Verify the file hash, for example in PowerShell:

   ```powershell
   Get-FileHash ".\TurboismInstaller-<version>-full.exe" -Algorithm SHA256
   ```

Installers are unsigned, so the checksum is the integrity check you can perform yourself.

## 3. Install

### Windows `.exe` installer

1. Run `TurboismInstaller-<version>-full.exe` (Full) or `TurboismInstaller-<version>-thin.exe` (Thin).
2. Choose the installer language (English, Simplified Chinese, Japanese, or Korean).
3. Read the license and confirm all four required acknowledgements.
4. Choose the install directory (`%LOCALAPPDATA%\Turboism` by default). The installer no longer has mode or plugin-selection pages: Full installs all first-party plugins, and Thin installs none.
5. Decide whether to download the optional managed GraalVM / JavaScript engine component.
6. When the installer opens `configure_turboism.ps1`, select the Cubism installations to use and save. Canceling the configurator leaves a valid framework-only install.
7. Start Cubism through the managed launcher for your Cubism root (`launch-cubism-turboism.bat`).

### Portable ZIP

1. Extract the whole archive (`turboism-<version>-full.zip` or `turboism-<version>-thin.zip`) into its own folder.
2. Run `configure_turboism.ps1` from that folder and select the Cubism installations.
3. Start Cubism through the generated shortcut or `launch-cubism-turboism.bat`.

Releases before **0.67.0-beta.3** used legacy assets (`TurboismInstaller-<version>.exe`, the IzPack `.jar` installer, and `turboism-<version>-lite.zip`). The Java installer JAR is retired.

The installer language affects only the installer. The language Turboism uses at runtime comes from the runtime `locale` setting, and plugin interface language follows Cubism Editor's **File → Environment Settings → General → Language**.

## 4. Verify the first run

Check that:

- Cubism starts normally;
- the Turboism runtime reports startup;
- the runtime uses the intended Turboism home;
- the top menu is named **Turboism** (previously "插件"/Plugins);
- the **Turboism** menu lists: **Plugin Market…**, **Manage Plugins…**, **Plugin Settings…** (a dedicated two-pane window), **Check for Updates**, **Turboism Settings…**, **Keybindings…**, **Logs…**, plugin actions, and **About**;
- installed plugins appear in the plugin manager and runtime diagnostics;
- unavailable host capabilities fail closed rather than crashing Cubism;
- closing Cubism releases plugin scopes and framework-owned executors.

## 5. Add or manage plugins

The Full selection already installs all first-party plugins. For Thin installations or additional plugins:

- Open Cubism and click **Turboism → Plugin Market…** (or visit [turboism.dev/plugins](https://turboism.dev/plugins)) to browse and install plugins.
- First-party plugins auto-update in the background after signature verification. Plugins marked hot-reload apply immediately; others apply after restarting Cubism. Users can turn off automatic plugin updates in settings.
- Enable or disable installed plugins anytime from **Turboism → Manage Plugins…**; changes apply after restarting Cubism.
- Configure plugin options in the dedicated two-pane window via **Turboism → Plugin Settings…**.

### Local plugin JAR installation

To install a local or third-party plugin JAR:

1. Open Turboism and choose **Turboism → Manage Plugins…**.
2. Choose **Install from JAR…**.
3. Select the local `.jar` file.
4. Confirm the dialog that marks the JAR as a local/unverified source.
5. Restart Cubism when the operation is shown as pending.

The JAR is staged after confirmation and applies after the restart. Plugin changes do not hot-swap the currently loaded plugin instance. Plugin JARs are separate from the Turboism installer executable.

### Manual alternative

As an advanced fallback path — for example to test a locally built JAR — you can place a plugin JAR directly:

1. Fully close Cubism and Turboism.
2. Copy the trusted plugin JAR directly into the root of `<turboism.home>/plugins/`.
3. Keep at most one JAR for each plugin ID.
4. Restart with the same Turboism home.
5. Verify the plugin state and runtime logs.

Manual installation bypasses the managed safeguards. See [Plugin Management](./plugin-management) for the full procedure.

## 6. Find logs

Use the installed Turboism home's `logs/` directory, or select **Turboism → Logs…** in the top menu. Keep logs when reporting startup, JAR, dependency, permission, or Provider failures.
