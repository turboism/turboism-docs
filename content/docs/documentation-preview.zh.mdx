本站承载 Turboism 用户和开发者文档，包括托管在本站的 SDK HTML 参考文档。

## 涵盖内容

- 安装、安装器模式、首次运行、插件管理、第一方插件、更新、卸载和恢复；
- Java 17 插件开发、插件元数据 schema、GraalJS 脚本和 MCP 集成路径；
- 概念、SDK API 指南和生成的 API 参考状态；
- 安全、许可、反馈渠道和当前开发状态。

## 语言政策

英文是文档正文的权威语言。简体中文、日文和韩文页面与英文源保持语义一致。如果译文页面与英文页面不一致，请以英文页面为准，并报告该差异。

## 仍属暂定的内容

- **生成的 SDK Javadoc** — 当前托管的版本和任何未解决的阻碍，请参阅[生成的 API 参考](./reference/generated-api)。出现在生成的 Javadoc 中的方法本身并不能证明每个宿主版本都有兼容的 Provider。
- **第三方插件目录** — 目录客户端已存在，但生产激活和签名 catalog 就绪性尚未建立，因此不得将其中列表视为已发布。
- **平台覆盖** — Windows x64 是唯一受支持的 Cubism 宿主平台；macOS 打包仅处于 preview，Linux 只涵盖安装器行为。
- **按版本的就绪度** — 受支持的 Cubism Editor 版本为 5.2.03、5.3.02 和 5.3.03，但各项操作仍与版本相关。请按操作而非按框架版本核实可用性。
- **自动更新** — Turboism 会检查稳定版更新并通知你；自动安装器下载和插件自动更新不可用。

## 如何核实产品事实

- 已发布版本、安装包、大小和校验和：请参阅[更新政策](./use/update-policy)中描述的渠道信息源。
- 受支持的宿主版本和安装器行为：[安装](./use/installation)。
- 不属于发布承诺的实现状态：[开发状态](./development-status)。

不要仅凭本站、变更日志条目或生成的 API 页面就将其视为兼容性承诺。
