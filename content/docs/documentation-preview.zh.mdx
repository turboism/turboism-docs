本站现承载当前 Turboism 用户和开发者文档，包括由源代码生成的 SDK HTML 参考文档。

## 现已提供

- Windows `.exe` 与 Windows/macOS `.jar` 安装器文档，以及 Windows 首次运行指南；
- macOS 安装器的安装/卸载指南；
- 本地插件安装、替换、启用、禁用和卸载行为；
- Java 17 插件快速入门和 manifest v2 打包；
- 当前 `PluginContext`、Cubism 对象、hook、配置、存储、任务、事件和 UI API 指南；
- 生成的 `dev.turboism.sdk.*` Javadoc；
- 当前开发和就绪度边界。

## 仍属暂定或尚未发布

- 公开的安装包、签名/公证和公开下载渠道——安装器实现本身已存在；
- 稳定的独立入门模板和 Maven 坐标；
- 在线更新、市场、签名和撤销；
- 完整的安装/修复/回滚/恢复生命周期；
- 对所有 Cubism 版本的一致支持；
- 版本化的非 Preview SDK 发布契约。

页面区分已实现的 Preview 行为和未来发布承诺。出现在生成的 Javadoc 中的方法本身并不能证明每个主机版本都有兼容的 Provider。
