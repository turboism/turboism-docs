SDK Javadoc은 대응하는 Turboism 소스 트리에서 생성하며, 검토를 마친 결과만 SDK 문서 사이트에 호스팅합니다.

## 현재 호스팅 버전

| 항목 | 값 |
| --- | --- |
| 생성 출처 | Turboism `v0.43.10` 릴리스 소스 |
| 자체 표기 버전 | `sdk 0.43.10 API` |
| 공개 패키지 수 | 59 |
| 검색 가능한 공개 타입 수 | 691 |
| 호스팅 위치 | [turboism.dev/sdk/index.html](https://turboism.dev/sdk/index.html) |

## 문서 갱신 절차

공개 SDK, 그 설명 또는 버전이 바뀌면 다음 순서로 진행합니다.

1. 소스 저장소의 `:sdk:javadoc` 작업을 릴리스 버전 모드로 실행해 Javadoc을 생성합니다.
2. 정확한 버전을 확인하고 snapshot 표기가 있는 출력은 거부합니다.
3. 공개 검색 가능한 모든 패키지와 타입을 검토합니다.
4. 내부 구현 타입과 승인되지 않은 Preview API가 공개 계약으로 제시되지 않았는지 확인합니다.
5. 생성된 텍스트에 비공개 자료, 로컬 경로, 자격 증명, 호스트 로그, 구현 전용 검증 정보가 없는지 확인합니다.
6. 검토를 통과한 결과를 문서 사이트로 동기화합니다.
7. 문서 lint, 타입 검사, 프로덕션 빌드를 실행합니다.

생성에 성공한 것만으로는 게시가 승인되지 않습니다.

## 검토된 게시 예외

게시된 레퍼런스는 `v0.43.10`의 컴파일된 공개 표면을 그대로 반영하므로, 검토가 숨은 문제가 아니라 예외로 판정한 두 가지를 포함합니다. 두 항목 모두 동기화할 때마다 다시 검사하며, 이 목록에 없는 차단 요소는 계속 실행을 실패시킵니다.

### `ActiveReadProjections`는 public이지만 계약이 아닙니다

`dev.turboism.sdk.cubism.ActiveReadProjections`는 public 클래스로 컴파일됩니다. `CubismFacade`와 `CubismReadCapabilityService`의 기본 메서드가 이 클래스의 도우미를 공유하기 때문입니다. 클래스 Javadoc은 이 타입이 안정적인 플러그인 API 표면에 속하지 않는다고 명시합니다.

- 페이지를 호스팅하는 이유는 이 타입이 이미 릴리스된 바이트코드에 존재하기 때문입니다.
- 지원되는 확장 지점이 **아닙니다**. 호출하지 말고, 그 시그니처를 호환성 약속으로 취급하지 마십시오.
- 이 타입이 public으로 남아 있는 한, 본 페이지와 [SDK API 가이드](./sdk-api)에서 비계약 항목으로 계속 명시합니다.

### 복구한 constant-values 앵커

JDK Javadoc 생성기는 `constant-values.html`에 `#dev.turboism`으로 향하는 목차 링크를 기록하지만 대응하는 대상은 출력하지 않습니다. 동기화 스크립트가 누락된 앵커를 채우고 그 복구를 매번 보고합니다. 그 밖의 깨진 링크는 여전히 실패로 처리됩니다.

## Preview API 표기

일부 공개 타입은 여전히 스스로를 Preview 기여로 설명합니다. 이 표기는 해당 타입이 기능과 버전에 의존한다는 뜻이며, Stable 계열에 속한다는 의미가 아닙니다. 가용성은 여전히 권한, 기능 Provider, 정확한 Cubism Editor 버전에 따라 결정됩니다. 자세한 내용은 [SDK API 가이드](./sdk-api)를 참고하십시오.

## 이 레퍼런스 사용 방법

- 생성된 Javadoc은 현재 소스에 대한 설명으로 취급하고, 독립적인 안정성 약속으로 보지 마십시오. 호환성 판정 기준은 Turboism 소스 저장소에서 검토된 바이너리 API 베이스라인입니다.
- 동작 지침, 버전 제한, 준비 상태 경계는 [SDK API 가이드](./sdk-api)를 먼저 확인하십시오.
- 호스팅된 HTML 레퍼런스만 근거로 릴리스, 배포, 호환성을 판단하지 마십시오.
