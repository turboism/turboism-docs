## Contract status

The current reference is generated from development source and describes Preview APIs unless an API is explicitly documented as Stable.

The source repository's reviewed binary API baseline remains the compatibility gate. Generated Javadoc is generated documentation, not an independent stability promise.

Internal Runtime, Bootstrap, test-framework, mapping, Provider, and first-party plugin implementation packages are intentionally excluded from the public reference.
