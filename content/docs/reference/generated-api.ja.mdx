## 再生成の状況

候補の再生成は、現在次の 3 つの問題によりブロックされています。

- 候補 output で public に検索できる生成型の 1 つが、自身を internal かつ non-stable と説明しています。
- 生成された service の 1 つが引き続き Preview とマークされており、public reference の方針を確定する必要があります。
- 候補 output にはまだ `0.42.0-SNAPSHOT` の version identifier が含まれています。

これらの blocker が解消されるまで、ホストされている HTML reference は古いままです。release、deployment、compatibility に関する主張の根拠にしないでください。

## 利用可能なガイドを慎重に使う

- 厳選された boundary については[SDK API ガイド](./sdk-api)を読んでください。
- 候補の拡張パスについては[プラグインを作る](../build-a-plugin/overview)を読んでください。
- 現在の API に関する記述はすべて Preview かつ capability-sensitive として扱います。

このページでは local regeneration procedure を提供しません。更新された生成 reference material の公開は保留中です。
