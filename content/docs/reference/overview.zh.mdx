## 契约状态

Turboism 发布单一的公共 SDK 层级。Turboism 源代码仓库中已审查的二进制 API 基线（`sdk/api-contracts/baselines/`）是兼容性门禁：当前基线是实时确切门禁，更早的基线保留为历史审计。

可用性仍取决于若干相互独立的事实，通过其中一项并不能确立另一项：

1. SDK 中存在该 API；
2. 插件声明了所需权限；
3. Runtime 具有匹配的能力 Provider；
4. 当前活动的 Cubism Editor 版本和对象 generation 受支持。

内部 Runtime、Bootstrap、test-framework、mapping、Provider 以及第一方插件实现包会被有意排除在公共参考之外。
