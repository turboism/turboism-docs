레퍼런스 섹션은 플러그인이 대상으로 하는 SDK 경계를 문서화합니다.

## 여기서 시작하기

- [SDK API 가이드](./sdk-api) — 수명 주기, `PluginContext`, 오브젝트 API, 훅, 구성, 저장소, 작업, UI, 권한 및 준비 상태 제약.
- [생성된 API 레퍼런스](./generated-api) — 공개 SDK 패키지에 대한 소스 생성 JDK 17 Javadoc과 그 공개 상태.
- [HTML 타입 인덱스 열기](https://turboism.dev/sdk/index.html) — 패키지, 클래스, 레코드, 인터페이스 및 메서드를 직접 탐색합니다.

## 계약 상태

Turboism은 하나의 공개 SDK 등급을 제공합니다. Turboism 소스 저장소(`sdk/api-contracts/baselines/`)의 검토된 바이너리 API 기준선이 호환성 게이트입니다. 현재 기준선이 실제 적용되는 정확한 게이트이며, 이전 기준선은 과거 감사 기록으로 남습니다.

가용성은 여전히 별개의 사실에 따라 달라지며, 하나를 통과했다고 해서 다른 것이 성립하지는 않습니다:

1. API가 SDK에 존재합니다;
2. 플러그인이 필요한 권한을 선언합니다;
3. 런타임에 일치하는 기능 프로바이더가 있습니다;
4. 활성 Cubism Editor 버전과 오브젝트 세대가 지원됩니다.

내부 런타임, 부트스트랩, 테스트 프레임워크, 매핑, 프로바이더 및 기본 제공 플러그인 구현 패키지는 공개 레퍼런스에서 의도적으로 제외됩니다.
