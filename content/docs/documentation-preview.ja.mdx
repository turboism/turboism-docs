このサイトでは、ホストしている SDK HTML リファレンスを含む、Turboism のユーザー向けおよび開発者向けドキュメントを公開しています。

## 扱っている内容

- インストール、インストーラーのオプション、初回起動、プラグイン管理、ファーストパーティプラグイン、更新、アンインストール、復旧
- Java 17 プラグイン開発、プラグインメタデータスキーマ、GraalJS スクリプト、MCP 連携経路
- 概念、SDK API ガイド、生成済み API リファレンスの状況
- 安全性、ライセンス、フィードバック窓口、現在の開発状況

## 言語ポリシー

ドキュメント本文の正文(権威ある言語)は英語です。簡体字中国語、日本語、韓国語のページは、英語のソースと意味的に対応させています。翻訳ページと英語ページの内容が一致しない場合は、英語ページを正しいものとして扱い、差分を報告してください。

## まだ暫定的なもの

- **生成済み SDK Javadoc** — 現在ホストしているバージョンと未解決のブロッカーは[生成済み API リファレンス](./reference/generated-api)を参照してください。生成された Javadoc にメソッドが掲載されていることだけでは、すべてのホストバージョンに互換性のある Provider があることの証明にはなりません。
- **プラグインディレクトリの掲載** — 0.67.0 以降、Cubism 内のプラグインマーケットと [turboism.dev/plugins](https://turboism.dev/plugins) は署名済みのプラグインディレクトリを参照します。掲載は互換性の約束ではありません。各プラグインが宣言する SDK API 範囲と正確な Cubism バージョンを確認してください。プラグイン管理ではこれらが個別に表示されます。
- **プラットフォーム対応** — 対応する Cubism ホストプラットフォームは Windows x64 のみです。macOS のパッケージはプレビューのみで、Linux はランタイムの挙動のみを対象とします。
- **バージョン別の対応状況** — 現在の Stable リリース 0.67.4 は 5.0.00 から 5.3.04 までのレビュー済み全 20 の Cubism Editor バージョンに対応していますが（[互換性](/docs/use/compatibility)を参照）、個々の操作とプラグイン機能はバージョン固有のままです。フレームワークのバージョン単位ではなく、操作単位で利用可否を確認してください。
- **自動更新** — Turboism は stable のフレームワーク更新を確認して通知します。フレームワークのインストーラーが自動でダウンロードまたは実行されることはありません。0.67.0 以降、ファーストパーティプラグインは署名検証を経てバックグラウンドで自動更新され、この機能は設定で無効にできます。

## 製品情報の確認方法

- 公開バージョン、パッケージ、サイズ、チェックサム:[更新ポリシー](./use/update-policy)で説明するチャンネルフィード。
- 対応するホストバージョンとインストーラーの挙動:[互換性](/docs/use/compatibility)および[インストール](./use/installation)。
- リリースの約束ではない実装状況:[開発状況](./development-status)。

このサイト、変更履歴の記載、生成された API ページだけを、互換性の約束として扱わないでください。
