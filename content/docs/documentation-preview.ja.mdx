このサイトでは現在、ソースから生成された SDK HTML リファレンスを含む、Turboism のユーザー向けおよび開発者向けドキュメントを公開しています。

## 現在利用できるもの

- Windows `.exe` と Windows/macOS `.jar` インストーラーのドキュメント、および Windows の初回起動の案内。
- macOS インストーラーのインストール・アンインストールの案内。
- ローカルプラグインのインストール、置換、有効化、無効化、アンインストールの挙動。
- Java 17 プラグインのクイックスタートとマニフェスト v2 パッケージング。
- 現在の `PluginContext`、Cubism オブジェクト、フック、設定、ストレージ、タスク、イベント、UI API の案内。
- 生成された `dev.turboism.sdk.*` Javadoc。
- 現在の開発状況と対応準備の境界。

## まだ暫定的または未公開のもの

- 公開インストーラーパッケージ、署名・ノータリゼーション、公開ダウンロードチャネル。インストーラーの実装自体は存在します。
- Stable なスタンドアロン starter template と Maven coordinates。
- オンライン更新、マーケットプレイス、署名、失効。
- 完全なインストール、修復、ロールバック、リカバリのライフサイクル。
- すべての Cubism バージョンに対する一様なサポート。
- バージョン管理された非 Preview SDK リリース契約。

各ページでは、実装済みの Preview の挙動と将来のリリースに関する約束を区別しています。生成された Javadoc にメソッドが掲載されていることだけでは、すべてのホストバージョンに互換性のある Provider があることの証明にはなりません。
