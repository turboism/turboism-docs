---

你可以通过以下渠道报告 Bug，或提出 Turboism 框架及插件的功能需求。

报告 Bug 前请先查看[故障排查](./troubleshooting)，并确认问题在你使用的版本中仍能出现。

## Bug 报告

请尽量说明：

- Turboism 版本；
- 精确的 Cubism Editor 版本；
- 操作系统；
- 涉及的功能或插件；
- 能够重现问题的步骤；
- 预期结果和实际结果；
- 在有帮助时，附上截图或经过隐私检查的简短诊断内容。

公开分享前，请移除个人信息、凭据、连接密钥、本地文件路径、工程文件和受许可保护的 Cubism 材料。

## 功能需求

请说明需求面向 Turboism 框架还是某个具体插件，并描述想解决的问题、受益对象、预期结果以及目前采用的方法。功能需求属于提议，不代表一定会实现或进入某个版本。

## Discord

可以在 [Turboism Discord](https://discord.gg/bect4anknH) 中寻求帮助。如果你还不能确定这是否属于 Bug，或需要协助缩小问题范围，建议使用此渠道。

## GitHub

对于能够稳定重现的问题，请提交 [GitHub Issue](https://github.com/turboism/turboism/issues)。请先搜索已有 Issue，再使用清晰的标题并附上上述信息。

## 电子邮件

如果不适合一开始就在公开渠道讨论，请发送电子邮件至 [contact@turboism.dev](mailto:contact@turboism.dev)。不要通过邮件发送凭据、连接密钥或专有工程文件。
