Turboism 프레임워크 또는 플러그인의 버그를 보고하거나 기능을 요청할 때 다음 채널을 사용하세요.

버그를 보고하기 전에 [문제 해결](./troubleshooting)을 확인하고, 사용 중인 버전에서도 문제가 계속 발생하는지 확인하세요.

## 버그 보고

다음을 포함해 주세요:

- 사용 중인 Turboism 버전;
- 정확한 Cubism Editor 버전;
- 운영 체제;
- 관련된 기능 또는 플러그인;
- 문제를 재현하는 단계;
- 예상한 동작과 실제로 발생한 동작; 그리고
- 도움이 될 경우 스크린샷 또는 개인 정보를 검토한 짧은 진단 발췌.

공개적으로 공유하기 전에 개인 정보, 자격 증명, 연결 시크릿, 로컬 파일 경로, 프로젝트 파일 및 라이선스가 있는 Cubism 자료를 제거하세요.

## 기능 요청

요청이 Turboism 프레임워크에 대한 것인지 특정 플러그인에 대한 것인지 밝히세요. 해결하려는 문제, 누가 이득을 얻는지, 기대하는 결과, 현재 사용하는 기존 워크플로를 설명하세요. 요청은 제안이며 해당 기능이 구현되거나 특정 버전에 포함된다는 약속이 아닙니다.

## Discord 및 QQ

도움이 필요하면 [Turboism Discord](https://discord.gg/bect4anknH)에서 질문하세요. 동작이 버그인지 확실하지 않거나 문제 범위를 좁히는 데 도움이 필요할 때 유용합니다.

Turboism QQ 그룹(그룹 ID `726739398`, 사이트 헤더의 QQ 버튼으로도 접속 가능)은 QQ를 사용하는 커뮤니티 구성원에게 같은 역할을 합니다. 두 채널 모두에서 자격 증명, 라이선스 자료 또는 프로젝트 파일을 게시하지 마세요.

## GitHub

재현 가능한 문제는 [GitHub 이슈](https://github.com/turboism/turboism/issues)를 열어 주세요. 먼저 기존 이슈를 검색한 다음 명확한 제목을 사용하고 위의 세부 정보를 포함하세요.

## 이메일

공개 논의로 시작하기 어려운 보고는 [contact@turboism.dev](mailto:contact@turboism.dev)로 이메일을 보내 주세요. 자격 증명, 연결 시크릿 또는 독점 프로젝트 파일을 이메일로 보내지 마세요.
