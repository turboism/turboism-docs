Turboism 是面向 Live2D Cubism Editor 的 Runtime 增强工具和插件框架。

```text
Plugin -> SDK -> Runtime policy -> versioned Adapter/Provider -> Cubism/Editor
```

插件只依赖 Turboism SDK。Runtime 负责宿主访问、生命周期、安全性、线程、事务、诊断、兼容性和版本差异。

## 这对插件作者意味着什么

- 使用 Turboism 所有的 Java 类型，而不是 `com.live2d.*` 类；
- 使用 `PluginContext` 处理配置、存储、用户文件、任务、UI、事件和 Cubism 访问；
- 在 `DisposableScope` 中注册可关闭资源；
- 声明受支持的插件元数据 schema 版本，以及插件实际使用的确切权限；
- 明确处理 Provider 或宿主版本不可用的情况；
- 永远不要通过反射、原始宿主 widget、native handle 或字节码转换器绕过 Runtime。

## Cubism Editor 中的 Turboism

在运行时，Turboism 直接集成在 Live2D Cubism Editor 的顶层 **Turboism** 菜单下（0.67.0 之前的版本中名为“插件”/Plugins 菜单）：

- **插件市场…** — 在应用内市场浏览并安装第一方及收录的插件，或访问 [turboism.dev/plugins](https://turboism.dev/plugins)。
- **管理插件…** — 启用、停用和卸载插件，或从本地暂存插件 JAR。
- **插件设置…** — 在专用的双栏设置窗口中集中配置所有已安装插件的选项。
- **检查更新** — 检查最新的框架发行版。
- **Turboism 设置…**、**快捷键…**、**日志…**、活动插件操作以及**关于**。

自 0.67.0 起，第一方插件在通过数字签名验证后会在后台自动更新。标记为热更新（hot-reload）的插件即刻生效，其他插件在重启 Cubism 后生效。后台更新可在设置中关闭。

## 文档范围

Turboism 发布单一的公共 SDK 层级。源代码仓库中已审查的二进制 API 基线是兼容性门禁，[SDK API 指南](./reference/sdk-api)描述了当前接口。

本文档全程适用两项限制：

- SDK 中存在某个 API，并不意味着每个受支持的 Cubism Editor 版本都能执行它；
- 受支持的 Editor 版本，并不意味着每个插件功能在该版本上都可用。

Windows x64 是受支持的宿主平台。当前 Stable 发行版 0.67.4 支持 5.0.00 至 5.3.04 的全部 20 个已审核 Cubism Editor 版本（请参阅[兼容性](/docs/use/compatibility)）。不支持的组合会安全地失败关闭，而不是回退到未经验证的路径。

自 0.67.0 起，每个发行版只提供两个产品下载：Windows 安装器 `TurboismInstaller-<version>.exe` 和便携版 `turboism-<version>.zip`，各自附带 `.sha256` 文件。两者都包含全部内置第一方插件。仅在 0.67.0 Beta 版本中使用的 Full/Thin 四下载布局已退役，跨平台 Java 安装器 JAR 也不再发布。
