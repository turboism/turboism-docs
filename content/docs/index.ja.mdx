# Turboism ドキュメント

Turboism は、Live2D Cubism Editor 向けの Java 17 ランタイム拡張ツールおよびプラグインフレームワークです。

## 目的に応じて読む

- **Turboism を使う** — [インストール](./use/installation)、[クイックスタート](./use/quick-start)、[プラグイン管理](./use/plugin-management) から始めてください。
- **プラグインを作る** — [開発者向けクイックスタート](./build-a-plugin/quick-start) で Java プラグインを作成し、続けて [プラグインインターフェース](./build-a-plugin/plugin-interfaces) と [マニフェストとパッケージング](./build-a-plugin/manifest) を確認してください。
- **リファレンス** — [SDK API ガイド](./reference/sdk-api) を読むか、[生成済み HTML API リファレンス](/api/sdk/index.html) を開いてください。
- **プロジェクトの状況** — [開発状況](./development-status) と [ドキュメント Preview](./documentation-preview) を確認してください。

Turboism はまだ Developer Preview です。このサイトでは、リリース保証のように扱うのではなく、バージョン制限、利用不可、未検証の挙動を明示しています。
