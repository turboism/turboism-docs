# Turboism ドキュメント

これは公開待ちの候補ドキュメントです。現在の Preview の方向を説明するものであり、リリースの約束ではありません。

## パスを選ぶ

### モデリングしたい

[モデラー](./use/overview)のパスで、候補となるインストールの流れ、Turboism の開始、ローカル plugin の管理、更新または復旧の計画を確認します。[インストール](./use/installation)と[クイックスタート](./use/quick-start)から始めてください。

### 構築または拡張したい

[開発者](./build-a-plugin/overview)のパスで、contribution、プロセス内 Java SDK plugin の構築、制限された GraalJS script の境界、または Preview MCP plugin を介した外部 client の接続を確認します。[LLM コーディングコンテキスト](./build-a-plugin/llm-coding-context)は補助資料であり、別の拡張方式ではありません。

準備状況と公開範囲については、[開発状況](./development-status)と[ドキュメント Preview](./documentation-preview)を確認してください。
