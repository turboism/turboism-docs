Turboism 是独立的开源项目。您的支持可以帮助项目维护框架、文档、版本兼容工作、测试和社区服务。

## 赞助入口

- [爱发电](https://ifdian.net/a/raintrap341)

## 其他支持方式

资金赞助不是唯一的支持方式。您还可以：

- 通过 [GitHub Issues](https://github.com/turboism/turboism/issues)报告可复现的问题；
- 通过 [GitHub Pull Requests](https://github.com/turboism/turboism/pulls)提出聚焦的改进；
- 使用专门的测试资料，对获准使用的 Preview 构建进行实机测试，并报告实际环境和结果；
- 改进英文、简体中文和日文文档；
- 在公共边界内开发独立的 Java 插件、GraalJS 脚本或 MCP 集成；
- 通过 [Discord](https://discord.gg/bect4anknH)帮助其他社区成员。

如需咨询赞助，或讨论其他支持方式，请发送电子邮件至 [contact@turboism.dev](mailto:contact@turboism.dev)。

## 项目独立性

支持本项目不会使 Turboism 成为 Live2D 或 Cubism 官方产品，也不会转移属于各自权利人的权利。在对外表述涉及本项目的赞助、合作或背书前，请阅读[安全与权利说明](./safety-and-rights)。
