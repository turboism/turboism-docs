## Your files and data

Turboism must not modify, delete, back up, or upload user files without an action or permission from the user. Features that can write files, create backups, connect to a network service, or automate Cubism must remain visible, permission-controlled, and limited to the operation the user requested.

Review plugin permissions before enabling a plugin. Keep backups you control for important work, and do not grant a plugin access that it does not need. If Turboism or a plugin behaves outside these boundaries, stop using the affected feature and [report it](./report-a-bug).
