This site hosts the Turboism user and developer documentation, including a hosted SDK HTML reference.

## What is covered

- installation, installer modes, first run, plugin management, first-party plugins, updates, uninstall, and recovery;
- Java 17 plugin development, plugin metadata schemas, GraalJS scripts, and the MCP integration path;
- concepts, the SDK API guide, and the generated API reference status;
- safety, licensing, feedback channels, and the current development status.

## Language policy

English is the authoritative language for documentation body content. Simplified Chinese, Japanese, and Korean pages are kept semantically aligned with the English source. If a translated page and the English page disagree, treat the English page as correct and report the difference.

## What remains provisional

- **Generated SDK Javadoc** — see [Generated API Reference](./reference/generated-api) for the version currently hosted and any open blockers. A method appearing in generated Javadoc does not by itself prove that every host version has a compatible Provider.
- **Third-party plugin directory** — the directory client exists, but production activation and signed catalog readiness are not established, so listings must not be treated as published.
- **Platform coverage** — Windows x64 is the only supported Cubism host platform; macOS packaging is preview-only and Linux covers installer behavior only.
- **Per-version readiness** — the supported Cubism Editor versions are 5.2.03, 5.3.02, and 5.3.03, but individual operations remain version-specific. Verify availability per operation rather than per framework version.
- **Automatic updates** — not part of the current stable release; updating means rerunning an installer.

## How to check a product fact

- Published versions, packages, sizes, and checksums: the channel feeds described in [Update Policy](./use/update-policy).
- Supported host versions and installer behavior: [Installation](./use/installation).
- Implementation state that is not a release promise: [Development Status](./development-status).

Do not treat this site, a changelog entry, or a generated API page as a compatibility promise on its own.
