This site now hosts the current Turboism user and developer documentation, including a source-generated SDK HTML reference.

## Available now

- Windows `.exe` and Windows/macOS `.jar` installer documentation and Windows first-run guidance;
- macOS installer install/uninstall guidance;
- local plugin install, replacement, enable, disable, and uninstall behavior;
- Java 17 plugin quick start and manifest v2 packaging;
- current `PluginContext`, Cubism object, hook, configuration, storage, task, event, and UI API guidance;
- generated `dev.turboism.sdk.*` Javadoc;
- current development and readiness boundaries.

## Still provisional or unpublished

- public installer artifacts, signing/notarization, and a public download channel — the installer implementations themselves exist;
- stable standalone starter template and Maven coordinates;
- online update, marketplace, signing, and revocation;
- a complete install/repair/rollback/recovery lifecycle;
- uniform support across all Cubism versions;
- a versioned non-Preview SDK release contract.

Pages distinguish implemented Preview behavior from future release promises. A method appearing in generated Javadoc does not by itself prove that every host version has a compatible Provider.
