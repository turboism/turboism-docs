This site hosts the Turboism user and developer documentation, including a hosted SDK HTML reference.

## What is covered

- installation, installer options, first run, plugin management, first-party plugins, updates, uninstall, and recovery;
- Java 17 plugin development, plugin metadata schemas, GraalJS scripts, and the MCP integration path;
- concepts, the SDK API guide, and the generated API reference status;
- safety, licensing, feedback channels, and the current development status.

## Language policy

English is the authoritative language for documentation body content. Simplified Chinese, Japanese, and Korean pages are kept semantically aligned with the English source. If a translated page and the English page disagree, treat the English page as correct and report the difference.

## What remains provisional

- **Generated SDK Javadoc** — see [Generated API Reference](./reference/generated-api) for the version currently hosted and any open blockers. A method appearing in generated Javadoc does not by itself prove that every host version has a compatible Provider.
- **Plugin Directory listings** — since 0.67.0 the in-Cubism Plugin Market and [turboism.dev/plugins](https://turboism.dev/plugins) read the signed Plugin Directory. A listing is not a compatibility promise: check each plugin's declared SDK API range and exact Cubism versions, which plugin management labels separately.
- **Platform coverage** — Windows x64 is the only supported Cubism host platform; macOS packaging is preview-only and Linux covers runtime behavior only.
- **Per-version readiness** — the current Stable release, 0.67.4, supports all 20 reviewed Cubism Editor versions from 5.0.00 to 5.3.04 (see [Compatibility](/docs/use/compatibility)), but individual operations and plugin features remain version-specific. Verify availability per operation rather than per framework version.
- **Automatic updates** — Turboism checks for stable framework updates and notifies you; framework installers are never downloaded or run automatically. Since 0.67.0, first-party plugins update automatically in the background after signature verification, and this can be turned off in settings.

## How to check a product fact

- Published versions, packages, sizes, and checksums: the channel feeds described in [Update Policy](./use/update-policy).
- Supported host versions and installer behavior: [Compatibility](/docs/use/compatibility) and [Installation](./use/installation).
- Implementation state that is not a release promise: [Development Status](./development-status).

Do not treat this site, a changelog entry, or a generated API page as a compatibility promise on its own.
