Turboism은 독립적인 오픈 소스 프로젝트입니다. 후원은 프레임워크, 문서, 호환성 작업, 테스트 및 커뮤니티 서비스를 유지하는 데 도움이 됩니다.

## 후원

- [Afdian](https://ifdian.net/a/raintrap341)
- [후원 페이지](https://turboism.dev/sponsor) — 프로젝트가 안내하는 현재 후원 대상입니다.

## 프로젝트를 지원하는 다른 방법

재정적 후원만이 지원 방법은 아닙니다:

- [GitHub Issues](https://github.com/turboism/turboism/issues)를 통해 재현 가능한 문제를 보고합니다;
- [GitHub Pull Requests](https://github.com/turboism/turboism/pulls)를 통해 범위가 명확한 개선을 제안합니다;
- 전용 테스트 데이터로 베타와 나이틀리를 포함한 릴리스 빌드를 테스트하고 실제 환경과 결과를 보고합니다;
- 영어, 중국어 간체, 일본어 및 한국어 문서를 개선합니다;
- 공개 경계 안에서 독립적인 Java 플러그인, GraalJS 스크립트 또는 MCP 통합을 개발합니다; 그리고
- [Discord](https://discord.gg/bect4anknH) 또는 Turboism QQ 그룹(그룹 ID `726739398`)을 통해 다른 커뮤니티 구성원을 돕습니다.

후원 관련 질문이나 다른 형태의 지원을 논의하려면 [contact@turboism.dev](mailto:contact@turboism.dev)로 이메일을 보내 주세요.

## 독립성

후원은 Turboism을 공식 Live2D 또는 Cubism 제품으로 만들지 않으며, 각 소유자에게 속한 권리를 이전하지 않습니다. 프로젝트와 관련된 후원, 파트너십 또는 보증을 제시하기 전에 [안전 및 권리](./safety-and-rights)를 읽어 주세요.
