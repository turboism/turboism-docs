---
title: Build a Plugin
description: The future developer path for extending Turboism.
---

Turboism is designed to be extended with plugins. This path will document project
setup, the plugin manifest, lifecycle design, testing, and publication choices.

> The public SDK, example project, API contract, and build coordinates are not yet
> published as release facts. Earlier prototype notes are retained as migration material
> only and are not contractual.
