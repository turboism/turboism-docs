This is candidate documentation for publication pending. It describes current Preview boundaries rather than a released extension program.

## Choose the right path

### Contribute to Turboism

Read [Contributing](./contributing) when you want to improve Turboism itself. Contribution workflow and acceptance details remain pending.

### Build a Java plugin

Use the existing [Developer Quick Start](./quick-start), [Plugin Interfaces](./plugin-interfaces), [Plugin Manifest and Packaging](./manifest), and [Designing Plugins](./designing-plugins) pages for the Java path. A Java plugin is an in-process SDK plugin: it is a Java 17 JAR loaded by Runtime and uses the public SDK boundary.

### Add a GraalJS script

Read [GraalJS Scripts](./graaljs-scripts) for a limited script boundary. A Java caller must explicitly run a script through `ScriptService`; scripts do not run automatically and are not the full Java SDK.

### Connect an external client

Read [MCP](./mcp) for the first-party preview plugin that offers authenticated loopback Streamable HTTP to external clients. MCP is not an in-process Java plugin API.

## Supporting material

[LLM Coding Context](./llm-coding-context) helps with understanding and drafting work; it is not a fourth extension model. ACP is an internal link used only with fx, not a fourth way to extend Turboism.
