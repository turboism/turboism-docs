This is candidate documentation for publication pending. It describes current Preview boundaries.

## Contribute to Turboism

Read [Contributing](./contributing) to work on Turboism itself.

## Java plugins

Use [Quick Start](./quick-start), [Plugin Interfaces](./plugin-interfaces), [Plugin Manifest and Packaging](./manifest), and [Designing Plugins](./designing-plugins). Java plugins are Java 17 JARs loaded in process and use the public SDK lifecycle and services.

## GraalJS scripts

Read [GraalJS Scripts](./graaljs-scripts) for restricted scripting. A Java caller must explicitly run a script through `ScriptService`; discovery does not execute it automatically, and scripts do not receive the complete Java SDK.

## MCP

Read [MCP](./mcp) when a trusted external client needs authenticated loopback Streamable HTTP automation. MCP is not an in-process plugin API.

## Coding-agent context

[LLM Coding Context](./llm-coding-context) is a vendor-neutral project brief for coding agents. It is not another development approach. ACP is internal to Turboism with fx and is not a fourth interface.
