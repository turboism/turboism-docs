Turboism is designed to be extended with plugins. This section is the developer track for
plugin architecture and contribution behavior.

## Recommended path

- [Developer Quick Start](./quick-start) — scaffold a minimal plugin and validate it locally.
- [Designing Plugins](./designing-plugins) — stable design patterns and compatibility planning.
- [Plugin Interfaces (Preview)](./plugin-interfaces) — draft interface families and expected touchpoints.

## Current release boundary

> The public SDK, example project, and contractually final API signatures are not yet published.
> These pages define the intended developer workflow before a hard release contract is posted.
