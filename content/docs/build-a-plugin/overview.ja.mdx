これは公開待ちの候補ドキュメントです。リリース済みの拡張プログラムではなく、現在の Preview の境界を説明します。

## 適切なパスを選ぶ

### Turboism に貢献する

Turboism 自体を改善したい場合は[コントリビューション](./contributing)を読んでください。contribution workflow と受け入れの詳細は保留中です。

### Java plugin を作る

Java のパスには、既存の[開発者向けクイックスタート](./quick-start)、[プラグインインターフェース](./plugin-interfaces)、[プラグインマニフェストとパッケージング](./manifest)、[プラグインの設計](./designing-plugins)を使用します。Java plugin はプロセス内 SDK plugin です。Runtime にロードされる Java 17 JAR で、public SDK boundary を使用します。

### GraalJS script を追加する

制限された script boundary については[GraalJS スクリプト](./graaljs-scripts)を読んでください。Java caller が `ScriptService` を通じて script を明示的に実行する必要があります。script は自動実行されず、完全な Java SDK でもありません。

### 外部 client を接続する

外部 client には[MCP](./mcp)を読んでください。first-party Preview plugin が、authenticated loopback Streamable HTTP を提供します。MCP はプロセス内 Java plugin API ではありません。

## 補助資料

[LLM コーディングコンテキスト](./llm-coding-context)は理解と下書きに役立ちますが、第 4 の拡張モデルではありません。ACP は fx とともに使用される内部リンクであり、第 4 の拡張方法ではありません。
