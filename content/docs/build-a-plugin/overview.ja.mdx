## Turboism に貢献する

Turboism 自体を改善する場合は[コントリビューション](./contributing)を確認してください。

## まずはここから: 最初のプラグインを作る

Turboism プラグインが初めての方は、[最初のプラグインを作る](./first-plugin)に沿って進めてください。プロジェクトテンプレートから、メニューコマンド、Cubism のライブデータ、保存される設定を備えた、インストール済みでテスト済みのプラグインまでを進める 6 ステップのチュートリアルです。[主要な仕組み](./key-mechanisms/lifecycle-and-cleanup)のページでは、ライフサイクルとクリーンアップ、permission と可用性、スレッドとタスク、そして読み込まれないプラグインの診断方法を説明しています。

## Java プラグイン

[クイックスタート](./quick-start)、[プラグインインターフェース](./plugin-interfaces)、[プラグインマニフェストとパッケージング](./manifest)、[プラグインの設計](./designing-plugins)を確認してください。Java プラグインはプロセス内で読み込まれる Java 17 JAR で、public SDK のライフサイクルとサービスを使用します。

## GraalJS スクリプト

制限されたスクリプトについては[GraalJS スクリプト](./graaljs-scripts)を確認してください。Java の呼び出し元が `ScriptService` を通じて明示的に実行する必要があります。検出だけでは自動実行されず、完全な Java SDK も提供されません。

## MCP

信頼できる外部クライアントが、認証された loopback Streamable HTTP automation を必要とする場合は[MCP](./mcp)を確認してください。MCP はプロセス内の plugin API ではありません。

## コーディングエージェント向けコンテキスト

[LLM コーディングコンテキスト](./llm-coding-context)は、コーディングエージェント向けの vendor-neutral なプロジェクト概要です。別の開発方法ではありません。

ACP はファーストパーティーの ACP Agent プラグインが提供します。ユーザーがインストールした ACP 対応エージェントを起動し、ローカル stdio ブリッジで Turboism MCP に接続します。Java プラグイン API とは別で、廃止された fx ランタイムには依存しません。
