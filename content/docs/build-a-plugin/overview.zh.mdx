## 参与 Turboism 开发

请阅读[参与贡献](./contributing)，了解如何改进 Turboism 本身。

## 从这里开始：开发你的第一个插件

刚接触 Turboism 插件？请跟随[开发你的第一个插件](./first-plugin)，这是一个六步教程，带你从项目模板一路走到已安装、经过测试的插件，其中包含菜单命令、实时 Cubism 数据和一个已保存的设置。[关键机制](./key-mechanisms/lifecycle-and-cleanup)页面讲解生命周期与清理、权限与可用性、线程与任务，以及如何诊断无法加载的插件。

## Java 插件

请查看[快速入门](./quick-start)、[插件接口](./plugin-interfaces)、[插件 Manifest 与打包](./manifest)和[设计插件](./designing-plugins)。Java 插件是在进程内加载的 Java 17 JAR，使用公共 SDK 生命周期与服务。

## GraalJS 脚本

请阅读[GraalJS 脚本](./graaljs-scripts)。Java 调用方必须通过 `ScriptService` 显式运行脚本；发现脚本不会自动执行，脚本也不会获得完整 Java SDK。

## MCP

当可信外部客户端需要通过经过认证的 loopback Streamable HTTP 自动化时，请阅读[MCP](./mcp)。MCP 不是进程内插件 API。

## 编程代理上下文

[LLM 编程上下文](./llm-coding-context)是面向编程代理、供应商中立的项目说明，不是另一种开发方式。

ACP 由第一方 ACP Agent 插件提供。它启动用户安装的 ACP 兼容代理，并通过本地 stdio 桥接连接 Turboism MCP。它独立于 Java 插件 API，已不再依赖退役的 fx 运行时。
