这是待发布的候选文档，描述当前 Preview 的边界，而非已发布的扩展计划。

## 选择正确的路径

### 参与 Turboism 贡献

若想改进 Turboism 本身，请阅读[参与贡献](./contributing)。贡献流程和接收细则仍待确定。

### 构建 Java 插件

请使用现有的[开发者快速入门](./quick-start)、[插件接口](./plugin-interfaces)、[插件 Manifest 与打包](./manifest)和[设计插件](./designing-plugins)页面来走 Java 路径。Java 插件是进程内 SDK 插件：它是由 Runtime 加载的 Java 17 JAR，并使用公共 SDK 边界。

### 添加 GraalJS 脚本

受限脚本边界请参阅[GraalJS 脚本](./graaljs-scripts)。Java 调用方必须通过 `ScriptService` 显式运行脚本；脚本不会自动执行，也不是完整的 Java SDK。

### 连接外部客户端

请参阅[MCP](./mcp)：第一方 Preview 插件通过经过认证的 loopback Streamable HTTP 向外部客户端提供服务。MCP 不是进程内 Java 插件 API。

## 辅助资料

[LLM 编程上下文](./llm-coding-context)有助于理解和起草工作；它不是第四种扩展模型。ACP 是仅与 fx 一起使用的内部链路，不是第四种扩展方式。
