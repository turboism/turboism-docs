title: 개발자 빠른 시작
description: 공개 SDK를 대상으로 최소한의 Java 17 Turboism 플러그인을 만듭니다.
---

현재 소스에 근거한 개발 경로는 Turboism 저장소에 플러그인 모듈을 추가하는 것입니다. 독립 실행형 시작 템플릿과 공개된 Maven 좌표는 아직 없습니다.

## 1. 모듈 만들기

```text
plugins/hello/
├── build.gradle.kts
├── src/main/java/dev/example/plugin/HelloPlugin.java
├── src/main/resources/META-INF/turboism/plugin.json
└── src/test/java/dev/example/plugin/HelloPluginTest.java
```

소스 저장소의 `settings.gradle.kts`에 추가하세요:

```kotlin
include("plugins:hello")
```

## 2. SDK에만 의존하기

```kotlin
plugins {
    `java-library`
}

dependencies {
    compileOnly(project(":sdk"))
    testImplementation(project(":sdk"))
}
```

`compileOnly`는 의도적입니다. 런타임이 SDK를 제공합니다. 플러그인 JAR은 `dev/turboism/sdk/**` 클래스를 복사해서는 안 됩니다.

런타임, 부트스트랩, `com.live2d.*`, 다른 플러그인의 비공개 구현 패키지, 리플렉션 브리지, 호스트 위젯, 네이티브 핸들 또는 호스트 ClassLoader에 의존하지 마세요.

## 3. 진입점 구현하기

```java
package dev.example.plugin;

import dev.turboism.sdk.plugin.PluginContext;
import dev.turboism.sdk.plugin.TurboismPlugin;

public final class HelloPlugin implements TurboismPlugin {
    private PluginContext context;

    @Override
    public void init(final PluginContext context) {
        this.context = java.util.Objects.requireNonNull(context, "context");
        context.logger().info("HelloPlugin initialized");
    }

    @Override
    public void enable() {
        context.logger().info("HelloPlugin enabled");
    }

    @Override
    public void disable() {
        context.logger().info("HelloPlugin disabled");
    }

    @Override
    public void shutdown() {
        context.logger().info("HelloPlugin shutdown");
        context = null;
    }
}
```

클래스는 public이어야 하고, `TurboismPlugin` 또는 그 하위 인터페이스를 구현하며, public 무인수 생성자를 노출해야 합니다.

## 4. 플러그인 디스크립터 추가하기

`src/main/resources/META-INF/turboism/plugin.json`을 만드세요:

```json
{
  "format": "turboism.plugin.meta",
  "schemaVersion": 3,
  "id": "dev.example.plugin.hello",
  "name": "Hello Plugin",
  "version": "0.1.0",
  "description": "Minimal Turboism plugin lifecycle example.",
  "category": "workflow",
  "tags": ["example"],
  "entrypoints": [
    "dev.example.plugin.HelloPlugin"
  ],
  "turboismApi": "[0.1.0,0.2.0)",
  "authors": [
    { "name": "Example Author" }
  ],
  "license": "MIT",
  "website": "https://example.org/hello-plugin",
  "resources": [],
  "i18n": {
    "baseName": "META-INF/turboism/i18n/messages",
    "locales": []
  },
  "dependencies": [],
  "permissions": [],
  "capabilities": [],
  "environment": {
    "requiresCubism": false,
    "ui": "none"
  }
}
```

스키마 3은 필수 `category` 필드를 추가합니다. 권한, 리소스, 현지화, 종속성, 다중 진입점 또는 스키마 4의 플러그인 간 이벤트 계약을 추가하기 전에 [플러그인 매니페스트 및 패키징](./manifest)을 읽어 주세요.

## 5. 빌드 및 검증

```bash
./gradlew :plugins:hello:test :plugins:hello:jar validatePluginMeta \
  --no-daemon --console=plain
```

빌드 결과는 다음 위치에 기록됩니다:

```text
build/worktree/<worktreeId>/hello/libs/
```

`libs/`의 JAR이 플러그인 릴리스 파일이며, 배포할 때 변경하지 않고 그대로 유지하세요.

이 수명 주기 전용 예제에서는 생성자 테스트만으로 충분합니다.

플러그인이 액션, UI, 이벤트, 구성 또는 작업을 등록하면 기록/가짜 `PluginContext`를 사용해 등록, 실패 처리, 사용 안 함/종료 동작 및 스코프 정리를 검증하세요.

## 6. JAR 배포하기

빌드한 JAR을 직접 공유하세요. 래퍼 아카이브, 패키지 스크립트 또는 별도의 패키징 단계가 없습니다.

## 7. 설치하기

Turboism 플러그인 관리를 사용하고 **JAR에서 설치…**(Install from JAR…)를 선택해 빌드한 JAR을 지정하세요. JAR을 로컬/검증되지 않은 소스로 표시하는 대화 상자를 확인하세요. 변경 사항은 스테이징되며 Cubism 재시작 후에 적용됩니다.

로컬 개발이나 대체 용도로 JAR을 수동 설치할 수도 있습니다. Cubism을 완전히 종료하고, 빌드한 JAR을 `<turboism.home>/plugins/`의 루트에 복사하고, 같은 플러그인 ID를 가진 이전 JAR이 남아 있지 않은지 확인한 뒤 같은 Turboism home으로 재시작하세요.

수동 설치는 관리형 안전 장치(UI 확인, 사전 검사, 스테이징, 백업/복원)를 우회하지만, JAR은 여전히 시작 검증을 거칩니다. 전체 수동 절차와 업데이트/제거 규칙은 [플러그인 관리](../use/plugin-management)를 참고하세요.
