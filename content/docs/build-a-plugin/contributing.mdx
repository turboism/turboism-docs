## What contribution means

Contributing changes Turboism itself rather than creating a separate Java plugin, GraalJS script, or MCP client integration. Start by understanding the boundaries in [Build a Plugin](./overview) and the public plugin contract in [Plugin Interfaces](./plugin-interfaces).

## Work safely

- Keep a proposed change focused on one user or developer need.
- Preserve the Java SDK boundary for in-process plugins.
- Treat host- and version-sensitive behavior as capability-dependent.
- Describe assumptions and validation clearly without presenting Preview behavior as release-ready.

Review, submission, acceptance, public release, and deployment details are pending. Use this page only as candidate orientation until an official contribution workflow is published.
