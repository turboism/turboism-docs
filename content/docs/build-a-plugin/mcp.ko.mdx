MCP는 번들로 제공되는 기본 제공 Turboism MCP Server 플러그인이 제공합니다. 신뢰하는 로컬 외부 클라이언트를 위한 통합 경로이며, 네 번째 프로세스 내 확장 유형이 아니고 프로세스 내 SDK 수명 주기의 일부도 아닙니다.

## 연결 요구 사항

플러그인은 `127.0.0.1`에서만 수신하고 인증된 Streamable HTTP를 사용합니다. 로컬 클라이언트는 해당 연결에 발급된 베어러 시크릿을 보내야 합니다. 생성된 연결 메타데이터는 같은 머신에서 신뢰하는 클라이언트에만 제공하세요. 시크릿을 얻은 사람은 사용 가능한 MCP 기능을 통해 동작할 수 있습니다. 연결 파일을 민감한 로컬 상태로 취급하고, 그 내용을 복사, 기록, 공유, 동기화 또는 공개하지 마세요.

## 로컬 클라이언트 연결

1. Full 또는 Thin 설치를 시작하고 **Turboism MCP Server** 플러그인이 사용 설정되어 있는지 확인하세요.
2. 신뢰하는 로컬 MCP 클라이언트에서 플러그인이 보고한 루프백 엔드포인트로 Streamable HTTP 연결을 만드세요.
3. 해당 연결의 베어러 시크릿을 보내도록 클라이언트를 구성하세요.
4. 클라이언트가 `initialize`를 보내고 세션에 대해 반환된 `MCP-Session-Id`를 보관하도록 하세요.
5. 초기화 후 MCP가 요구하는 초기화 완료 알림을 보낸 다음, 설치된 플러그인이 노출하는 작업만 사용하세요.

엔드포인트, 시크릿, 사용 가능한 작업 및 클라이언트 호환성은 기능에 따라 달라지며 빌드 간에 변경될 수 있습니다. 클라이언트가 이 순서를 완료할 수 없으면 루프백이나 인증 제어를 우회하지 마세요.

## 확장 경로 분리 유지하기

외부 클라이언트가 제어된 로컬 연결을 필요로 할 때 MCP를 사용하세요. 프로세스 내부 SDK 수명 주기와 서비스에는 Java 플러그인을 사용하세요. Java 호출자가 `PluginContext.scripts()`와 `ScriptService.run`을 통해 제한된 스크립트를 명시적으로 실행하는 경우에만 [GraalJS 스크립트](./graaljs-scripts)를 사용하세요.

ACP는 내부용이며 fx에서만 사용됩니다. MCP 엔드포인트나 Turboism을 확장하는 또 다른 방법이 아닙니다.
