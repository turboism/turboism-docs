本页是待发布的候选文档。它是方向说明，并非已发布的贡献协议或部署流程。

## “贡献”的含义

贡献是更改 Turboism 本身，而不是创建独立的 Java 插件、GraalJS 脚本或 MCP 客户端集成。请先了解[构建插件](./overview)中的边界，以及[插件接口](./plugin-interfaces)中的公共插件契约。

## 安全地开展工作

- 让每项拟议更改聚焦于一个用户或开发者需求。
- 保持进程内插件的 Java SDK 边界。
- 将依赖宿主和版本的行为视为与能力相关。
- 清楚说明假设和验证，不要将 Preview 行为表述为可发布状态。

评审、提交、接收、公开发布和部署细节仍待确定。在官方贡献流程发布前，请仅将本页用作候选方向说明。
