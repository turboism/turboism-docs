---
title: 参与贡献
description: 为 Turboism 及其扩展生态参与贡献的原则与方式。
---

您可以通过改进框架，或开发扩展与插件来帮助完善 Turboism。请遵循以下原则，让贡献更可靠、安全，并能为更多人带来价值。

## 贡献原则

- 在通用框架边界内开展工作，而不是为单一主机或使用场景添加行为。
- 优先使用公共 SDK，而非内部 API、主机对象、反射或不受支持的集成路径。
- 让每项改动聚焦于一个明确的用户或开发者需求。
- 分别核对目标版本兼容性、能力可用性和所需权限。获得权限并不表示相应能力一定可用。
- 添加或更新适当的测试，保持英文、简体中文和日文文档同步；公共 SDK 或其说明发生变化时，还必须重新生成并审查 SDK Javadoc。
- 保护用户文件、个人资料和隐私。只请求和处理必要的访问权限与数据；不要在代码、日志或文档中暴露敏感信息。

## 参与方式

### 1. 改进框架

通过 [GitHub Issues](https://github.com/turboism/turboism/issues) 报告、讨论或完善框架相关工作；通过 [GitHub Pull Requests](https://github.com/turboism/turboism/pulls) 提出实现改动。

### 2. 开发扩展

根据任务选择合适的扩展方式：使用 [Java 插件](./designing-plugins)实现进程内 SDK 集成；使用 [GraalJS 脚本](./graaljs-scripts)运行显式调用且受限的脚本；或使用 [MCP](./mcp) 集成受信任的本地客户端。

### 3. 为插件商店开发插件

开发插件时可面向插件商店的分发需求进行设计。插件商店、其发布流程和公开列表尚未最终确定或上线，因此不得将其表述为已部署。当前请通过 [Turboism GitHub 仓库](https://github.com/turboism) 提交或讨论候选插件。
