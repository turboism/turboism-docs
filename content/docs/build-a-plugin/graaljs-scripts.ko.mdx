---
title: GraalJS 스크립트
description: 명시적으로 호출되는 제한된 GraalJS 스크립트를 패키징하고 실행합니다.
---

GraalJS 스크립트는 Java 플러그인이 아닙니다. Java 플러그인이 명시적으로 호출할 때만 실행되며, Java SDK가 아니라 제한된 브리지를 받습니다.

## 스크립트 패키징

스크립트 패키지는 스키마 버전 `2`와 `language`가 `js`로 설정된 `script.json` 디스크립터를 사용합니다. 디스크립터는 `entry`로 스크립트 진입점을 식별하고, `sourceSha256`으로 소스를 식별하며, 요청하는 `permissions`를 선언합니다. 디스크립터와 소스는 이를 사용하는 Java 플러그인이 기대하는 방식대로 함께 유지하세요.

```json
{
  "schemaVersion": 2,
  "id": "dev.example.script.hello",
  "name": "Hello Script",
  "version": "0.1.0",
  "language": "js",
  "entry": "main.js",
  "sourceSha256": "<SHA-256 of the source>",
  "permissions": []
}
```

`schemaVersion` 2만 허용되며, `js`가 현재 지원되는 유일한 스크립트 언어입니다.

이는 필드 수준 개요이며 완전한 권한 목록이 아닙니다. 대상으로 하는 빌드가 지원하는 권한만 사용하세요. 가용성과 정확한 의미는 기능에 따라 달라집니다.

## 검색은 실행이 아님

스크립트를 검색 가능하게 만드는 것은 그것을 실행하지 않습니다. Java 플러그인은 `PluginContext.scripts()`를 통해 스크립트를 명시적으로 얻고 `ScriptService.run`으로 명시적으로 호출해야 합니다. 자동 검색 및 실행 수명 주기는 없으며, 스크립트는 Java 플러그인의 매니페스트, 수명 주기, 권한 또는 서비스를 대체할 수 없습니다.

## 실행 경계

스크립트는 Java 호출자가 제공하는 값과 작업만 있는 제한된 JavaScript 환경에서 실행됩니다. 완전한 Java SDK가 아니라 제한된 Cubism 브리지를 받습니다. 브리지 작업, 리소스 한도 및 사용 가능한 권한은 빌드에 따라 다르므로 스크립트가 읽거나 변경하거나 요청할 수 있는 범위를 제한할 수 있습니다. 주변 호스트 접근을 가정하지 말고 사용할 수 없는 작업과 실행 실패를 처리하도록 스크립트를 설계하세요.

SDK 수명 주기와 서비스를 가진 프로세스 상주 플러그인에는 Java 경로를 사용하세요. 외부 클라이언트가 인증된 루프백 Streamable HTTP를 필요로 할 때는 [MCP](./mcp)를 사용하세요. 내부적으로 fx에서만 사용되는 ACP는 스크립팅 또는 확장 경로가 아닙니다.

## 현재 상태

스크립트 실행은 기능에 따라 달라집니다. 노출되는 브리지 작업, 리소스 한도 및 정확한 권한 집합은 빌드에 따라 다를 수 있습니다. 주변 호스트 접근을 가정하지 말고 사용할 수 없는 작업이나 실패한 실행을 처리하도록 스크립트를 설계하세요.
