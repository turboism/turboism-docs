Turboism is an open-source enhancement tool and plugin framework for Live2D Cubism Editor. It adds optional features through a public SDK, permissions, and version-specific integration boundaries while keeping Cubism separately installed and licensed.

## Documentation structure

### Basics

Start with [Basics](./use/overview) for downloads and installation, first use, plugin management, first-party plugins, release channels, uninstall, and recovery. Published packages are listed on [turboism.dev/download](https://turboism.dev/download).

### Development

Go to [Development](./build-a-plugin/overview) to contribute to Turboism or work with one of the three supported development approaches:

1. Java plugins;
2. GraalJS scripts explicitly run by a Java caller; or
3. external automation through MCP.

### Concepts

[Concepts](./concepts/architecture) explains the Turboism architecture, the mapping layer, and the automation and scripting boundaries.

### Reference

[Reference](./reference/overview) collects the SDK guide and the status of generated API documentation.
