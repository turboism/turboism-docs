# Turboism documentation

Turboism is a Java 17 runtime enhancement tool and plugin framework for Live2D Cubism Editor.

## Choose a path

- **Use Turboism** — start with [Installation](./use/installation), [Quick Start](./use/quick-start), and [Plugin Management](./use/plugin-management).
- **Build a Plugin** — create a Java plugin with the [Developer Quick Start](./build-a-plugin/quick-start), then read [Plugin Interfaces](./build-a-plugin/plugin-interfaces) and [Manifest and Packaging](./build-a-plugin/manifest).
- **Reference** — read the [SDK API Guide](./reference/sdk-api) or open the [generated HTML API reference](/api/sdk/index.html).
- **Project status** — see [Development Status](./development-status) and [Documentation Preview](./documentation-preview).

Turboism is still a Developer Preview. This site identifies version-limited, unavailable, and unverified behavior instead of presenting it as a release guarantee.
