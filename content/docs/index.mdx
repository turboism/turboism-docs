# Turboism documentation

These are candidate documents for a publication that is still pending. They describe the current Preview direction, not a release promise.

## Choose your path

### I want to model

Follow the [Modelers](./use/overview) path to understand the candidate installation flow, start with Turboism, manage local plugins, and plan updates or recovery. Start with [Installation](./use/installation) and [Quick Start](./use/quick-start).

### I want to build or extend

Follow the [Developers](./build-a-plugin/overview) path to contribute, build an in-process Java SDK plugin, learn the limited GraalJS scripting boundary, or connect an external client through the preview MCP plugin. [LLM coding context](./build-a-plugin/llm-coding-context) is supporting material, not another extension model.

For readiness and publication scope, see [Development Status](./development-status) and [Documentation Preview](./documentation-preview).
