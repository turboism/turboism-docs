Turboism is a Java Agent and plugin framework intended for Live2D Cubism Editor workflows.

This site is the authoritative home for Turboism product and developer documentation.

Documentation is organized around two equal paths: using Turboism and building a plugin.
Shared platform ideas live under **Concepts** and **Reference**.

> Preview boundary: This website is being established before public release facts, support
> commitments, and SDK contracts are finalized. Treat the material here as a preview,
> not a download, compatibility, or API guarantee.
