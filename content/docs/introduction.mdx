Turboism is a runtime enhancement tool and plugin framework for Live2D Cubism Editor.

```text
Plugin -> SDK -> Runtime policy -> versioned Adapter/Provider -> Cubism/Editor
```

Plugins depend on the Turboism SDK only. Runtime owns host access, lifecycle, safety, threading, transactions, diagnostics, compatibility, and version differences.

## What this means for plugin authors

- use Turboism-owned Java types instead of `com.live2d.*` classes;
- use `PluginContext` for configuration, storage, user files, tasks, UI, events, and Cubism access;
- register closeable resources in `DisposableScope`;
- declare a supported plugin metadata schema version and the exact permissions the plugin uses;
- handle Provider or host-version unavailability explicitly;
- never bypass Runtime with reflection, raw host widgets, native handles, or bytecode transformers.

## Turboism in Cubism Editor

At runtime, Turboism integrates directly into Live2D Cubism Editor under a top-level **Turboism** menu (previously named "插件"/Plugins in releases before 0.67.0-beta.3):

- **Plugin Market…** — discover and install first-party and curated plugins from the in-app market or [turboism.dev/plugins](https://turboism.dev/plugins).
- **Manage Plugins…** — enable, disable, and uninstall plugins, or stage local plugin JARs.
- **Plugin Settings…** — configure options for all installed plugins in a dedicated two-pane window.
- **Check for Updates** — check for the latest framework releases.
- **Turboism Settings…**, **Keybindings…**, **Logs…**, active plugin actions, and **About**.

Starting with 0.67.0-beta.3, first-party plugins auto-update in the background after signature verification. Plugins marked hot-reload apply immediately, while others apply upon restarting Cubism.

## Documentation scope

Turboism publishes one public SDK tier. The reviewed binary API baseline in the source repository is the compatibility gate, and the [SDK API Guide](./reference/sdk-api) describes the current surface.

Two limits apply throughout this documentation:

- an API that exists in the SDK does not mean every supported Cubism Editor version can execute it;
- a supported Editor version does not mean every plugin feature is available on it.

Windows x64 is the supported host platform. Supported Cubism Editor versions depend on the Turboism release: Stable 0.44.0 admits 5.2.03, 5.3.02, and 5.3.03, while Beta 0.67.0-beta.3 admits all 20 reviewed versions from 5.0.00 to 5.3.04 (see [Compatibility](/docs/use/compatibility)). Unsupported combinations fail closed rather than falling back to an unverified path.

Starting with 0.67.0-beta.3, Turboism ships four product downloads across Full and Thin variants (`TurboismInstaller-<version>-full.exe`, `TurboismInstaller-<version>-thin.exe`, `turboism-<version>-full.zip`, `turboism-<version>-thin.zip`). Releases before 0.67.0-beta.3 used legacy assets, and the cross-platform Java installer JAR is retired.
