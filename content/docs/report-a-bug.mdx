---
title: Feedback and Requests
description: Report bugs or suggest framework and plugin features through Discord, GitHub, or email.
---

Use these channels to report a bug or request a feature for the Turboism framework or a plugin.

Before reporting a bug, check [Troubleshooting](./troubleshooting) and confirm that the problem still occurs with the version you are using.

## Bug reports

Please include:

- your Turboism version;
- your exact Cubism Editor version;
- your operating system;
- the feature or plugin involved;
- steps that reproduce the problem;
- what you expected and what happened instead; and
- a screenshot or a short, privacy-reviewed diagnostic excerpt when it helps.

Remove personal information, credentials, connection secrets, local file paths, project files, and licensed Cubism material before sharing anything publicly.

## Feature requests

State whether the request is for the Turboism framework or a specific plugin. Explain the problem you want to solve, who benefits, what result you expect, and any existing workflow you use today. A request is a proposal, not a promise that the feature will be implemented or included in a particular version.

## Discord

Ask for help in the [Turboism Discord](https://discord.gg/bect4anknH). This is useful when you are unsure whether the behavior is a bug or need help narrowing it down.

## GitHub

For a reproducible problem, open a [GitHub issue](https://github.com/turboism/turboism/issues). Search existing issues first, then use a clear title and include the details above.

## Email

For a report that should not begin in a public discussion, email [contact@turboism.dev](mailto:contact@turboism.dev). Do not email credentials, connection secrets, or proprietary project files.
