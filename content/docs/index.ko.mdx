Turboism은 Live2D Cubism Editor를 위한 오픈 소스 향상 도구이자 플러그인 프레임워크입니다. 공개 SDK, 권한, 버전별 통합 경계를 통해 선택적 기능을 추가하며, Cubism은 별도로 설치하고 라이선스를 취득한 상태로 유지합니다.

## 문서 구조

### 기본

다운로드와 설치, 첫 사용, 플러그인 관리, 기본 제공 플러그인, 릴리스 채널, 제거 및 복구에 대해서는 [기본](./use/overview)부터 시작하세요. 공개된 패키지는 [turboism.dev/download](https://turboism.dev/download)에 있습니다.

### 개발

Turboism에 기여하거나 세 가지 지원 개발 방식 중 하나를 사용하려면 [개발](./build-a-plugin/overview)로 이동하세요:

1. Java 플러그인;
2. Java 호출자가 명시적으로 실행하는 GraalJS 스크립트; 또는
3. MCP를 통한 외부 자동화.

### 개념

[개념](./concepts/architecture)에서는 Turboism 아키텍처, 매핑 계층, 자동화 및 스크립팅 경계를 설명합니다.

### 레퍼런스

[레퍼런스](./reference/overview)는 SDK 가이드와 생성된 API 문서의 상태를 정리합니다.

### 안전 및 피드백

프로젝트 독립성, 제3자 권리, 사용자 데이터 보호, 라이선스 및 상업적 사용 지침은 [안전 및 권리](./safety-and-rights)를 참고하세요.

버그를 보고하거나 프레임워크 또는 플러그인 기능을 요청하려면 Discord, QQ, GitHub, 이메일 채널을 안내하는 [피드백 및 요청](./report-a-bug)을 참고하세요.

프레임워크, 문서, 테스트 및 커뮤니티 유지에 기여하려면 현재 후원 대상과 그 밖의 참여 방법을 정리한 [후원하기](./support-us)를 참고하세요.

현재 준비 상태는 [개발 상태](./development-status)를 참고하세요.
