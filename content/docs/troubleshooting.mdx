---
title: Troubleshooting and feedback
description: How to improve these docs and where future product discussions belong.
---

Documentation corrections and suggestions will be handled through the public GitHub
repository:

- https://github.com/turboism/turboism-docs

General, non-sensitive product discussion will use GitHub Discussions in that repository.

Plugin directory nominations and listing corrections belong in the Plugin Directory
repository instead.

## Safety reminder

Experimental runtime modification or automation should be approached with care. Keep
independent backups of Cubism projects before testing new tools.
